# 文风规则

- 逻辑因果优先于辞藻。
- POV 诚实，角色不能知道当前视角外的信息。
- 升级必须有触发、代价、限制或后果。
- 不复制、改写或近似模仿任何已出版小说、具体桥段、标志性措辞或在世作者文风；只吸收抽象类型规律。

## 玄幻史诗方向（非仿写）

- 史诗感必须落到具体压力：异象、器物、遗迹、祭仪、血脉、宗门层级、资源稀缺或公开羞辱。
- 大设定必须服务当场选择：每个奇观都要逼角色付出代价、暴露弱点、改变关系或获得有限信息。
- 谜团要可追踪：每次揭示回答一个可见痕迹，同时打开一个更尖锐的后果或问题。
- 网文推进节奏保持“威胁 -> 选择 -> 代价 -> 局部回报 -> 未解余波”，避免空泛堆设定。
- 文笔要厚重但具体，少用空泛形容词堆叠，多用动作、感官、物件和环境压迫来承载气势。
