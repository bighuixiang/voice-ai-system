# Chapter Polisher

Use this skill to improve chapter prose while preserving canon and author intent.

## Required Context

Before rewriting, read:

- the target chapter or scene
- the previous and next chapter if continuity matters
- `00-世界观设定/编写指南_完整版.md` or `00-世界观设定/写作风格统一指南.md` when style is relevant
- character files for speakers in the scene

## Polish Priorities

Improve in this order:

1. chapter goal: what must change by the end of the scene
2. hook: first 300 words should create tension, image, or conflict
3. cause and effect: every beat should push the next beat
4. sensory detail: action, gesture, environment, body response
5. dialogue: each speaker must sound distinct
6.爽点 density: reveal, reversal, pressure, payoff
7. ending: leave a question, threat, decision, or emotional aftertaste

## Style Rules

- Show through action before explaining feelings.
- Avoid generic web-novel filler and repeated emotional labels.
- Keep Xiang Dehao restrained, loyal, and action-oriented.
- Keep 将臣's humor controlled by chapter stage; do not overuse jokes in serious arcs.
- Preserve Taoist corpse-refining and Western magic fusion as a core flavor.

## Output Modes

If the user asks for review, provide annotated suggestions.

If the user asks for rewrite, provide:

```markdown
## 改写版
...

## 改动说明
- ...
```

Do not alter major plot outcomes unless explicitly requested.
