# 小说项目技能使用指南

本项目已内置一组小说创作技能，同时放在两个目录中：

- `.claude/skills/`：给 Claude Code 使用。
- `.codex/skills/`：给 Codex 或其他按 Codex 约定读取项目技能的代理使用。

这些技能通过各自 `SKILL.md` 顶部的 `description` 描述触发场景；协作者也可以在提示词中直接点名技能。

## 已安装技能

### `novel-continuity-editor`

用途：检查前后矛盾、设定冲突、时间线、修炼等级、道具状态、伏笔遗漏。

示例：

```text
使用 novel-continuity-editor 检查第3章和整体规划有没有矛盾。
```

### `chapter-polisher`

用途：润色章节、增强开头钩子、动作描写、对话节奏、爽点和结尾悬念。

示例：

```text
用 chapter-polisher 优化第4章，让战斗更有压迫感。
```

### `character-voice-keeper`

用途：保持角色口吻一致，尤其适合多人对话、将臣吐槽、师徒情感、双女主互动。

示例：

```text
用 character-voice-keeper 检查这段对话，看看将臣和向德豪像不像本人。
```

### `plot-arc-architect`

用途：设计卷大纲、章节节拍、反派压力、牺牲线、复活回收、感情推进。

示例：

```text
用 plot-arc-architect 规划学院篇后10章，每章给核心冲突和结尾钩子。
```

### `ai-video-consistency`

用途：把小说设定转成图片、视频、分镜、角色一致性提示词。

示例：

```text
用 ai-video-consistency 给向德豪生成一套可用于AI视频的镜头提示词。
```

## 自动触发说明

在支持项目技能的环境中，代理会根据 `SKILL.md` 的 `description` 自动匹配。例如你说“检查时间线矛盾”，会倾向触发 `novel-continuity-editor`；说“润色这一章”，会倾向触发 `chapter-polisher`。

如果当前 Codex 会话没有自动加载项目技能，可以让代理手动读取对应文件，例如：

```text
请按 .codex/skills/chapter-polisher/SKILL.md 的规则优化第2章。
```

如果自动触发不稳定，直接在提示词开头写技能名最可靠：

```text
使用 chapter-polisher：请重写第2章结尾，让悬念更强。
```

## 推荐工作流

1. 新剧情先用 `plot-arc-architect` 规划。
2. 写完章节用 `chapter-polisher` 润色。
3. 多人对话用 `character-voice-keeper` 复核。
4. 提交前用 `novel-continuity-editor` 查矛盾。
5. 做图片或短剧时用 `ai-video-consistency` 转提示词。

## 协作者注意事项

- 技能只提供工作流，不会替代仓库内设定文件。
- 修改正文章节前先读相关角色、世界观和时间线。
- 不要为了爽点随意改变已建立的修炼等级、角色关系或道具状态。
- 生成图片和视频提示词时，以文字设定为准，已有图片只作为辅助参考。
