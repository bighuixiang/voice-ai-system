# 《魔道尸祖：我带着僵尸王勇闯异界》小说项目

## 项目简介

湘西赶尸传人向德豪，随师父对战僵尸王将臣，意外穿越到西方魔法世界。

魔道双修，炼尸炼体，从魔兽岭边缘起步，点尸成器，对抗黑暗主宰，最终成就位面之主。

---

## 目录结构

```
├── 00-世界观设定/        # 世界观、修炼体系
```

## 修炼体系

- **魔法等级**：学徒→法师→大法师→魔导师→大魔导师→法圣→法神
- **炼尸等级**：行尸→铁尸→铜尸→银尸→金尸→尸王→尸皇→尸帝→尸神
- **炼体等级**：肉身境→锻骨境→锻脉境→锻脏境→金身境→不灭境→神体境
