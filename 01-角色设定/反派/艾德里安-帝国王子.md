# 艾德里安 - 帝国三王子（反派）

## 基本信息

| 项目 | 内容 |
|------|------|
| 姓名 | 艾德里安·星辰帝国 |
| 年龄 | 20岁 |
| 性别 | 男 |
| 身份 | 帝国三王子、学院天才学生 |
| 外貌 | 金发碧眼、贵族服饰、英俊但阴险 |
| 状态 | 存活→被反杀→被炼制成银尸 |
| 魔法属性 | 全系亲和，主修雷系 |

## 外貌特征

- **日常**：华丽的贵族服饰、金发碧眼、高傲神情
- **战斗**：金色法袍、法杖在手、周围环绕元素之力
- **气质**：傲慢自大、目中无人、阴险狡诈
- **死后（银尸）**：皮肤银白、双目银光、冰冷却听话

## 性格特点

**优点**：
- 实力强大（学院前五）
- 家世显赫
- 有野心（扭曲的）

**缺点**：
- 傲慢自大
- 嫉妒心强
- 阴险狡诈
- 滥用职权
- 心胸狭隘
- 占有欲极强
- "得不到就毁掉"扭曲心理

## 能力设定

### 魔法等级
- **生前**：高级法师（20岁）
- **银尸状态**：保留生前魔法+尸气加持

### 精通魔法
- **雷系**：雷霆万钧、雷霆风暴、雷电链
- **风系**：风刃、风压、风暴
- **辅助**：飞行术、护盾术

## 背景故事

### 家庭
- 帝国三王子
- 母亲是帝国皇后
- 从小娇生惯养
- 认为自己配得上任何人
- 什么东西都要最好的
- 想要的东西必须得到

### 扭曲的爱情观

**核心理念**：
- "我是王子，我想要的东西就必须是我的"
- "得不到，就毁掉"
- "与其让别人拥有，不如毁掉"

**形成原因**：
- 从小要什么有什么
- 第一次被拒绝是索菲亚
- 无法接受被拒绝
- 心理扭曲：得不到就毁掉

### 追求索菲亚

**疯狂追求**：
- 在学院遇到索菲亚
- 一见钟情（其实是占有欲）
- 各种追求：送礼、表白、公开追求
- 每天送花到宿舍
- 公开场合表白
- 但索菲亚完全无感

**被拒绝的愤怒**：
- 艾德里安："索菲亚，我是帝国王子，配得上你。"
- 索菲亚："我不喜欢你。"
- 艾德里安："为什么？我有钱有权有实力！"
- 索菲亚："但我就是不爱你。"
- 艾德里安："爱可以慢慢培养！"
- 索菲亚："我不会爱上一个我讨厌的人。"
- 艾德里安怒火中烧："你...！"

**发现索菲亚有"男朋友"**：
- 入学典礼后，看到索菲亚拉着向德豪的手
- 听到"这是我男朋友"
- 艾德里安嫉妒得发疯
- "那小子算什么东西？！"
- "我一定要除掉他！"

### 对向德豪的仇恨

**嫉妒**：
- 看到索菲亚对向德豪笑
- 看到两人"约会"（其实是演戏）
- 艾德里安："他凭什么拥有索菲亚？！"
- "我要杀了他！"

**调查向德豪**：
- 派人调查向德豪的背景
- 发现：东方人、身份不明、赶尸术
- 艾德里安："原来是蛮夷！"
- "这种人怎么配得上索菲亚！"
- "必须除掉！"

## 阴谋设计：魔兽岭杀局

### 第一步：报名参加历练

**借口**：
- "学院组织野外历练，我也想参加。"
- 真实目的：借机除掉向德豪

**准备**：
- 收买学院高手（但没人愿意）
- 联系帝国护卫
- 准备高级引兽香
- 设计完美的杀局

### 第二步：引出王级魔兽

**引兽香**：
- 帝国特供的高级引兽香
- 可以引出方圆百里内的魔兽
- 特别是高阶魔兽

**实施**：
- 在历练第三天
- 艾德里安悄悄点燃引兽香
- 铁翼龙王（王级魔兽）被引来
- 艾德里安躲在一旁观察
- "死吧，向德豪..."

**等待**：
- 看到小队与王级魔兽战斗
- 看到小队浴血奋战
- 看到小队勉强击败魔兽
- 艾德里安："什么？他们竟然赢了？"
- "没关系，他们已经重伤了..."
- "现在是我的主场。"

### 第三步：帝国护卫埋伏

**护卫阵容**：
- 8名帝国精英护卫
- 都是高级法师以上实力
- 对付重伤的小队绰绰有余

**埋伏位置**：
- 战斗结束后的必经之路
- 等待小队放松警惕
- 然后一网打尽

### 第四步：暴露真相

**现身**：
- 艾德里安从暗处走出
- 嘲讽小队："没想到你们这么能打..."
- 索菲亚："王子？你怎么在这里？"

**真相揭露**：
- 艾德里安冷笑："这王级魔兽是我引出来的。"
- 小队震惊："什么？！"
- 艾德里安："高级引兽香，帝国特供。"
- 索菲亚："你疯了？！我们会死的！"
- 艾德里安："得不到你，就毁掉你。"

**扭曲的宣言**：
- 艾德里安："索菲亚，我喜欢你。"
- 索菲亚："我不喜欢你！"
- 艾德里安："没关系，等我霸王硬上弓后，你就只能从了我！"
- 索菲亚："你妄想！"
- 艾德里安："在这个世界上，只有我王子想要的东西，没有我得不到的！"
- "既然你不愿意爱我，那我就毁掉你，然后再得到你！"

**命令护卫**：
- "动手！杀掉那四个男的，把索菲亚带回去！"
- "那个向德豪，我要亲手杀了他！"

### 第五步：被反杀

**向德豪的爆发**：
- 向德豪重伤站起
- 炼尸大典+八卦道袍+将臣大剑
- 尸气与魔素融合
- 逐一击破8名护卫

**艾德里安的震惊**：
- 艾德里安："不可能...这不可能..."
- "他明明重伤了！"
- "他是什么怪物？！"

**最终对决**：
- 向德豪走到艾德里安面前
- 艾德里安："你...你别过来！我是帝国王子！"
- 向德豪："王子又如何？"
- 艾德里安："你敢杀我？！我父皇不会放过你的！"
- 向德豪："你想要霸王硬上弓我的朋友。"
- 艾德里安："她不是你的朋友！"
- 向德豪："不管是什么，她是我保护的人。"
- "你这种人，死有余辜。"
- 一剑斩下，艾德里安头颅飞起

## 被炼制成银尸

### 炼制过程

**索菲亚的反应**：
- 索菲亚："你...你杀了他？"
- 向德豪："他该死。"

**向德豪的决定**：
- 向德豪没有停下
- 打开炼尸大典
- 开始炼制艾德里安的尸体
- 索菲亚震惊："你要...炼制他？"

**炼制原因**：
- 向德豪："他生前想要得不到就毁掉你。"
- "那我就让他死后，成为我的工具。"
- "从今天起，他就是我的银尸战斗工具。"
- "永不见天日，只在需要时放出来当炮灰。"
- 索菲亚："德豪..."

**炼制完成**：
- 艾德里安的尸体被炼制成银尸
- 银尸等级：中上等（保留了生前的魔法天赋）
- 银尸睁开眼，双目银光："主人..."

**第一个命令**：
- 向德豪："进袋子里去。"
- 银尸："是，主人。"
- 向德豪把银尸收入裹尸袋
- 向德豪对索菲亚说："你不用见他，他被关在袋子里。"
- 索菲亚："谢谢...我不想看到他。"
- 向德豪："以后只有战斗需要时才会放他出来，而且是在前线，你不用面对他。"

### 银尸能力

| 能力 | 说明 |
|------|------|
| **保留意识** | 艾德里安的意识沉睡，但能感知 |
| **听命行事** | 只能服从向德豪的命令 |
| **雷系魔法** | 保留生前的雷系魔法能力 |
| **尸气加持** | 尸气与魔法融合，威力倍增 |
| **不死不灭** | 银尸不死，可无限修复 |
| **永不见天日** | 平时关在裹尸袋，只在战斗时放出来当炮灰 |

### 银尸的心态

**意识感知**：
- 艾德里安的意识沉睡，但能感知
- 知道自己成为银尸
- 知道自己永不见天日
- 羞愧、后悔、绝望

**内心独白**：
- "我...竟然成了银尸..."
- "而且永不见天日..."
- "只有在需要当炮灰时才被放出来..."
- "连那个女孩都见不到..."
- "这就是报应吗..."
- "比保护她更残忍的惩罚..."
- "我罪有应得..."

**后期状态**：
- 意识逐渐麻木
- 只在战斗时被短暂唤醒
- 战完就被收回黑暗
- 永远沉睡在裹尸袋中

### 银尸的使用

**使用原则**：
1. 平时关在裹尸袋，永不见天日
2. 只在战斗需要时放出来
3. 放出来时，索菲亚避开不看
4. 战斗结束立即收回
5. 索菲亚从不需要面对他

**兽潮时**：
- 战斗需要肉盾
- 向德豪："我需要一个人挡在前面。"
- 掏出裹尸袋，放出艾德里安银尸
- 向德豪："去挡住前面。"
- 银尸："是，主人。"
- （银尸冲向魔兽群，承受攻击）
- 向德豪（对索菲亚）："你往后面站，别看他。"
- 索菲亚："嗯...谢谢。"
- （索菲亚转身，不看那个方向）
- 战斗结束后，向德豪："回来。"
- （把银尸收回裹尸袋）
- 索菲亚："收起来了吗？"
- 向德豪："收起来了。"
- 索菲亚："呼...那就好。"

**清理杂兵时**：
- 遇到大量杂兵需要清理
- 放出银尸横扫
- 清理完立即收回
- 索菲亚不在场时使用

**探险开路时**：
- 需要探路踩陷阱
- 索菲亚不在小队时才使用
- 用完即收

- 使者："而且...王子被反杀后，尸体被炼制成银尸..."

- 帝国发布追杀令
- 悬赏向德豪的人头
- "谁杀了向德豪，赏金千万！"
- 学院拒绝交人

### 学院vs帝国

**帝国施压**：
- 帝国使者来到学院
- "向德豪杀害帝国王子，必须交出来！"

**伊莎贝拉的回应**：
- 伊莎贝拉挡在向德豪面前
- "他是我学生，谁也别想动他！"
- 使者："院长，他是杀人犯！"
- 伊莎贝拉："是他先设计的杀局！"
- "是艾德里安想要霸王硬上弓！"
- "自作自受，死有余辜！"
- 使者："但炼成银尸...太过分了！"
- 伊莎贝拉："那又怎样？王子就可以为所欲为？"
- 使者："您要为了一个学生和帝国为敌？"

**向德豪的回应**：
- 向德豪站出来
- "是我杀了艾德里安。"
- "是我炼成了银尸。"
- "有本事，就来找我。"
- "不要牵连学院。"
- 使者震惊："你..."
- 向德豪："回去告诉皇帝，我等着他。"
- 使者灰溜溜地离开

## 总结

艾德里安是一个典型的"变态反派"——傲慢自大、占有欲极强、"得不到就毁掉"的扭曲心理。他的存在为前期故事提供了冲突和爽点（被反杀），死后被炼制成银尸继续发挥作用，既增加了讽刺意味，也为主角提供了强力助力。他的故事线完成度高，从嚣张王子到认命银尸，体现了"善恶终有报"的主题。

**讽刺点**：
- 生前想要霸王硬上弓索菲亚
- 死后成为银尸，必须保护她
- 生前的执念，死后的枷锁
- 这就是他的报应
