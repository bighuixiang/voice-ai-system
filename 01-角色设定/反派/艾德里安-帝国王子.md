# 艾德里安 - 帝国王子（反派）

## 基本信息

| 项目 | 内容 |
|------|------|
| 姓名 | 艾德里安·星辰帝国 |
| 年龄 | 20岁 |
| 性别 | 男 |
| 身份 | 帝国三王子、学院天才学生 |
| 外貌 | 金发碧眼、贵族服饰、英俊但阴险 |
| 状态 | 存活→被反杀→被炼制成银尸 |

## 外貌特征

- **日常**：华丽的贵族服饰、金发碧眼、高傲神情
- **战斗**：金色法袍、法杖在手、周围环绕元素之力
- **气质**：傲慢自大、目中无人、阴险狡诈

## 性格特点

**优点**：
- 实力强大（学院前五）
- 家世显赫
- 有野心

**缺点**：
- 傲慢自大
- 嫉妒心强
- 阴险狡诈
- 滥用职权
- 心胸狭隘

## 能力设定

### 天赋
- **元素天赋**：全系亲和，主修雷系
- **魔法等级**：高级法师（20岁）
- **战斗风格**：雷系魔法轰炸

### 精通魔法
- **雷系**：雷霆万钧、雷霆风暴、雷电链
- **风系**：风刃、风压、风暴
- **辅助**：飞行术、护盾术

## 背景故事

### 家庭
- 帝国三王子
- 母亲是帝国皇后
- 从小娇生惯养
- 认为自己配得上任何人

### 入学
- 以特殊身份入学
- 被称为学院天才
- 父亲是帝国皇帝
- 权势滔天

### 与索菲亚的关系

**追求索菲亚**：
- 在学院遇到索菲亚
- 一见钟情
- 各种追求
- 但索菲亚不理他

**被拒绝**：
- 艾德里安："晴晴，我是帝国王子，配得上你。"
- 索菲亚："我不喜欢你。"
- 艾德里安："为什么？"
- 索菲亚："因为你不是我喜欢的类型。"
- 艾德里安怒火中烧

### 对向德豪的嫉妒

**入学典礼**：
- 看到索菲亚主动接近向德豪
- 嫉妒得发疯
- 决定除掉向德豪

**暗中观察**：
- 发现向德豪天赋极高
- 更是嫉妒
- "凭什么这小子比我厉害？"
- 开始设计陷害

## 阴谋设计

### 第一步：野外历练

**设计借口**：
- "学院组织野外历练"
- 实际上是杀局
- "向德豪，你敢去吗？"
- 向德豪："去就去。"

**暗中准备**：
- 收买学院高手
- 联系帝国刺客
- 准备在魔兽岭除掉向德豪
- "做得干净点。"

### 第二步：魔兽岭杀局

**行动**：
- 进入魔兽岭
- 艾德里安露出獠牙
- "向德豪，去死吧！"
- 暗杀队伍围攻

**结果**：
- 向德豪魔道双修
- 轻松反杀所有暗杀者
- 艾德里安震惊："怎么可能？"
- 向德豪："就这？"

### 第三步：被反杀

**战斗过程**：
- 艾德里安亲自出手
- 雷系魔法轰炸
- 向德豪轻松闪避
- 将臣变成剑，配合攻击

**对话**：
- 艾德里安："你是什么怪物？！"
- 向德豪："我只是比你强而已。"
- 艾德里安："我不服！我是帝国王子！"
- 向德豪："王子又如何？招惹我，就要付出代价。"

**死亡**：
- 向德豪秒杀艾德里安
- 索菲亚看到全过程
- "做得好，德豪！"
- 向德豪："正好缺个材料..."

## 被炼制成银尸

### 炼制过程

**现场炼尸**：
- 向德豪用炼尸大典
- 当场炼制艾德里安的尸体
- 索菲亚震惊："你要炼他？"
- 向德豪："他不是要我死吗？我让他换种方式活着。"
- 艾德里安尸体被炼制成银尸

### 银尸能力

| 能力 | 说明 |
|------|------|
| **保留意识** | 艾德里安的意识沉睡，但能感知 |
| **听命行事** | 必须服从向德豪的命令 |
| **雷系魔法** | 保留生前的雷系魔法能力 |
| **尸气加持** | 尸气与魔法融合，威力倍增 |
| **不死不灭** | 银尸不死，可无限修复 |

### 成为向德豪的助力

**后期使用**：
- 兽潮时，艾德里安银尸参战
- 横扫魔兽
- 索菲亚看到："是他...但他现在是我们的人了。"
- 向德豪："对，他是我的武器。"
- 艾德里安银尸："主人，需要我出手吗？"
- 向德豪："去吧。"

**艾德里安的心态**：
- 意识沉睡，但能感知
- 知道自己成为银尸
- 羞愧、后悔
- 但也认命了
- "这是我应得的。"

## 帝国震怒

### 消息传回

**皇帝大怒**：
- 消息传回帝国
- 皇帝："谁杀了我儿子？！"
- "是...向德豪。"
- "我儿子只是去历练！"
- "他...他挑衅在先，然后被反杀了..."
- "而且...尸体被炼制成银尸..."

**追杀令**：
- 帝国发布追杀令
- 悬赏向德豪的人头
- "谁杀了向德豪，赏金千万！"
- 学院拒绝交人

### 帝国vs学院

**学院态度**：
- 伊莎贝拉："他是我学生，谁敢动？"
- 帝国："他杀了我儿子！"
- 伊莎贝拉："是他先挑衅的。"
- 帝国："那是误会！"
- 伊莎贝拉："那他的尸体为什么被炼制？"
- 帝国："..."

**僵持**：
- 帝国不罢休
- 学院不妥协
- 向德豪："我的事，我自己解决。"
- 出面应对帝国

## 人物定位

- **前期反派**：学院篇的主要反派
- **嫉妒担当**：因为嫉妒而作恶
- **爽文靶子**：被主角碾压反杀
- **炼尸材料**：死后成为银尸，继续发挥作用
- **讽刺意味**：生前王子，死后银尸，讽刺了阶级差距

---

## 总结

艾德里安是一个典型的"反派配角"——傲慢自大、嫉妒心强、心胸狭隘。他的存在为前期故事提供了冲突和爽点（被反杀），死后被炼制成银尸继续发挥作用，既增加了讽刺意味，也为主角提供了强力助力。他的故事线完成度高，从嚣张王子到认命银尸，体现了"善恶终有报"的主题。
