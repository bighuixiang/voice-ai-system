# 索菲亚 - 学院校花

## 基本信息

| 项目 | 内容 |
|------|------|
| 姓名 | 索菲亚·星辰帝国 |
| 年龄 | 18岁（与向德豪同岁） |
| 性别 | 女 |
| 身份 | 学院校花、新生代表、帝国贵族之女 |
| 外貌 | 金发碧眼、娇小可爱、学院制服 |
| 魔法属性 | 全系亲和，主修光系 |

## 外貌特征

- **日常**：学院制服、金发披肩、碧眼如星
- **战斗**：魔法长袍、法杖在手、可爱但致命
- **气质**：活泼灵动、元气满满、甜美可爱

## 性格特点

**优点**：
- 活泼开朗，充满活力
- 直率坦诚，心口如一
- 勇敢坚强，不畏强权
- 对喜欢的人坚定不移

**缺点**：
- 容易吃醋，傲娇
- 有时候太直白，让人尴尬
- 争强好胜，不服输
- 对"老女人"有执念（叫伊莎贝拉）
- 对王子追求感到困扰

## 背景故事

### 家庭
- 帝国贵族之女
- 父亲是帝国大臣
- 从小受到良好教育
- 但不喜欢贵族的虚伪
- 更讨厌王子的纠缠

### 入学
- 以第一名成绩入学
- 被选为新生代表
- 被称为"校花"
- 但她不喜欢这个称号
- 更讨厌艾德里安王子的追求

### 被艾德里安追求的困扰

**艾德里安的追求**：
- 艾德里安（三王子）疯狂追求索菲亚
- 每天送花、送礼、公开表白
- 但索菲亚完全无感

**索菲亚的烦恼**：
- "这王子怎么这么烦人..."
- "我都拒绝了一百次了..."
- "他为什么听不懂人话..."

**父亲的压力**：
- 父亲："索菲亚，王子是认真的，你考虑一下？"
- 索菲亚："我不喜欢他！"
- 父亲："可是他是王子啊..."
- 索菲亚："王子又怎样？我不喜欢就是不喜欢！"

### 与向德豪的初遇（挡箭牌事件）

**第14章：入学典礼后的"偶遇"**

**背景**：

- 艾德里安又来纠缠

**后续"挡箭牌"日常**：

**经典对话**：

### 感情升温：魔兽岭历练被救

**第19章：魔兽岭历练事件**

**历练出发**：
- 学院组织野外历练
- 向德豪、索菲亚、弗拉姆、格蕾丝、凯尔一组
- 目的地：魔兽岭深处
- 艾德里安也报名参加了（目的不纯）

**王级魔兽出现**：
- 历练进行到第三天
- 小队深入魔兽岭
- 突然，一股恐怖的气息出现
- 凯尔："这是...王级魔兽？!"
- 弗拉姆："我们才中级实力，王级魔兽不是我们能对付的！"
- 格蕾丝："撤退！"
- 但王级魔兽已经锁定了他们

**浴血奋战**：
- 王级魔兽：铁翼龙王
- 实力远超小队
- 凯尔："我来挡住它！你们快撤！"
- 索菲亚："不！我不会丢下朋友的！"
- 向德豪："我们一起战斗！"
- 小队浴血奋战
- 弗拉姆燃烧魔力的火焰
- 格蕾丝全力治疗
- 凯尔用身体挡下攻击
- 索菲亚光系魔法轰炸
- 向德豪魔尸双修全力输出
- 所有人都受了重伤

**艰难击败**：
- 经过两小时的苦战
- 小队终于勉强击败铁翼龙王
- 所有人都倒在地上，无力再战
- 索菲亚："我们...赢了？"
- 弗拉姆："是啊...终于..."
- 格蕾丝："但我们都快不行了..."
- 凯尔："先恢复一下魔力..."

**三王子出现**：
- 这时，艾德里安从暗处走出来
- 艾德里安："没想到你们这么能打..."
- 索菲亚："王子？你怎么在这里？"
- 艾德里安冷笑："当然是为了...你。"

**真相揭露**：
- 艾德里安："这王级魔兽是我引出来的。"
- 小队震惊："什么？！"
- 艾德里安："高级引兽香，帝国特供。"
- 索菲亚："你疯了？！我们会死的！"
- 艾德里安："得不到你，就毁掉你。"
- 索菲亚："你..."
- 艾德里安："现在你们都重伤，正是我想要的状态。"

**帝国强者现身**：
- 艾德里安拍了拍手
- 八名帝国强者从暗处现身
- 都是高级法师以上实力
- 艾德里安："他们是我的护卫。"
- 向德豪："你早有预谋..."
- 艾德里安："当然。从你冒充索菲亚男朋友那天起，你就该死了。"
- 艾德里安看向索菲亚："现在，没人能救你了。"
- 索菲亚："你敢！"
- 艾德里安："我有什么不敢？你是我的！"
- 索菲亚："我永远不会喜欢你！"
- 艾德里安："没关系，等我霸王硬上弓后，你就只能从了我！"
- 索菲亚脸色苍白...

**绝望时刻**：
- 小队重伤无力
- 帝国强者围住他们
- 索菲亚绝望地看着向德豪
- 索菲亚："德豪...对不起...是我连累了你..."
- 向德豪摇头："不是你的错。"
- 艾德里安："别演深情了，你们马上就要死了。"

**向德豪爆发**：
- 向德豪缓缓站起来
- 索菲亚："德豪！你重伤了！"
- 向德豪："我还有最后一招。"
- 艾德里安："垂死挣扎？"
- 向德豪掏出炼尸大典
- 向德豪："将臣！"
- 将臣（小僵尸）："来了！"
- 血契共鸣，将臣变身

**逐一击破**：
- 向德豪爆发全部力量

- 尸气与魔素融合
- 向德豪："第一个，是你！"

- 向德豪逐个击破
- 每一击都精准致命

- 向德豪："王子又如何？"

- 艾德里安："不！！！"

**炼成银尸**：
- 索菲亚："你...你杀了他？"

- 但向德豪没有停下

- 向德豪："你不用见他，他被关在袋子里。"

- 艾德里安银尸睁开眼："主人..."
- 向德豪："进袋子里去。"
- 银尸："是，主人。"
- 向德豪把银尸收入裹尸袋
- 向德豪对索菲亚说："以后只有战斗需要时才会放他出来，而且是在前线，你不用面对他。"

**后续对话**：
