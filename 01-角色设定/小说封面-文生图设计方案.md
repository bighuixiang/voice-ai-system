## 四、即梦AI提示词方案

### 方案一：经典玄幻封面（青色调）⭐ 推荐

**【风格特点】**
- 青色调为主，符合道术主题
- 主角C位，其他成员环绕
- 炼尸大典古籍虚影作为背景
- 底部留白用于书名排版

**【即梦AI提示词】**
```
玄幻小说封面，正中央是英俊的东方少年向德豪上半身像，18岁，黑色微长发，剑眉星目眼神坚毅，身穿青灰色改良短道袍东西方融合风格，右手平举持古铜色金钱剑，身后黄色符咒漂浮发光，左肩蹲着巴掌大小的青绿色可爱小僵尸将臣，左侧后方是银发翠眼绝美精灵族女子伊莎贝拉高贵典雅穿深蓝色星辰长袍，右侧后方是金发碧眼可爱校花索菲亚穿淡蓝色魔法长袍，更后方是红发热血少年弗拉姆穿红色战斗服、银甲剑士凯尔持巨剑、淡金长发温柔少女格蕾丝穿白色治疗长袍、戴厚眼镜金发天然呆少女艾米莉亚，所有主角团成员侧身半环绕主角，背景是半透明的古朴线装书《炼尸大典》虚影，书页上金色符咒纹路流转，东方道术与西方魔法融合氛围，底部留白区域，高清，细节丰富，8k画质，玄幻史诗风格，书名排版区留白
```

### 方案二：暗黑史诗封面（金绿色调）

**【风格特点】**
- 金绿色调，突出史诗感
- 主角散发金绿光晕
- 黑暗背景中浮现古籍虚影
- 适合暗黑篇使用

**【即梦AI提示词】**
```
暗黑史诗风格小说封面，中央C位是东方少年向德豪上半身，18岁，黑色微长发飘逸，深邃黑色眼睛散发金绿光芒，身穿青灰色道袍东西方融合风格，手持古铜色金钱剑剑尖发光，周身缭绕金绿色光晕和黄色符咒，右肩蹲着青绿色小僵尸将臣，左侧是银长发精灵族美女伊莎贝拉深紫色星眸穿深蓝战斗法袍，右侧是金发碧眼校花索菲亚穿白色战斗法师袍，后方是主角团成员红发战士弗拉姆、银甲骑士凯尔、温柔治疗师格蕾丝、戴眼镜呆萌少女艾米莉亚半环绕站立，背景是黑暗中浮现的半透明古籍《炼尸大典》虚影，书页散发金色符咒光芒，东方道术神秘氛围，底部留白区域用于书名排版，高清，8k画质，玄幻暗黑史诗风格
```

### 方案三：热血战斗封面（红色调）

**【风格特点】**
- 红色调为主，突出战斗感
- 所有主角团战斗姿态
- 战场背景
- 适合战斗高潮篇使用

**【即梦AI提示词】**
```
热血玄幻小说封面，中央C位是东方少年向德豪上半身战斗姿态，18岁，黑色微长发飞扬，眼神凌厉坚毅，身穿青灰色改良道袍，右手斜持古铜色金钱剑指向前方，身后黄色符咒如火焰般飘动，左肩青绿色小僵尸将臣做出战斗姿势，左侧是银发精灵族女子伊莎贝拉施放星辰魔法，右侧金发校花索菲亚凝聚光系法术，后方红发火法师弗拉姆全身火焰缭绕，银甲剑士凯尔持巨剑，淡金发治疗师格蕾丝散发治愈光芒，戴厚眼镜少女艾米莉亚念咒，所有主角团成员战斗姿态，背景是半透明的古朴古籍《炼尸大典》虚影和战场硝烟，东方道术与西方魔法融合战斗氛围，底部留白区域，高清，8k画质，热血战斗风格
```

### 方案四：简约大气封面（留白设计）

**【风格特点】**
- 大量留白，极简设计
- 主角特写，其他成员半脸/轮廓
- 适合文艺版/精装版

**【即梦AI提示词】**
```
简约大气玄幻小说封面，中央C位是东方少年向德豪上半身特写，18岁，黑色微长发，清秀东方脸型剑眉星目，眼神坚毅深邃，身穿青灰色改良短道袍，右手竖持古铜色金钱剑，身后漂浮三张黄色符咒发光，左肩蹲着青绿色小僵尸将臣，左侧露出银发精灵族女子伊莎贝拉半脸和肩膀，右侧露出金发校花索菲亚半脸和肩膀，更后方隐约可见其他主角团成员轮廓，背景大量留白，只有淡淡的古籍《炼尸大典》轮廓虚影，极简设计，东方道术神秘氛围，底部大面积留白用于书名排版，高清，8k画质，简约玄幻风格
```

## 八、生成参数建议

### 即梦AI推荐参数
- **图片比例**：3:4（竖版，适合封面）
- **画质**：8k/超高清
- **风格强度**：中等（保持角色特征）
- **细节增强**：开启

### 生成次数
- 每个方案建议生成 3-5 张
- 选择最佳效果进行后期处理
