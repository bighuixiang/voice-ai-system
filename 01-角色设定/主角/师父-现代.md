# 师父（现代）——向守一

## 基本信息

| 项目 | 内容 |
|------|------|
| 姓名 | 向守一（师父） |
| 年龄 | 45岁（穿越时） |
| 性别 | 男 |
| 职业 | 湘西赶尸派第36代掌门 |
| 外号 | 守一真人 |
| 状态 | 穿越→异界死亡→尸体在裹尸袋中→被复活 |

## 外貌特征

- 身材挺拔，肌肉紧实，常年修炼的精壮体格
- 黑发中夹杂几缕花白，更显成熟稳重
- 剑眉星目，目光如电，不怒自威
- 常穿青布道袍，行动利落干练
- 战时披黄色八卦披风，气势如虹

## 性格特点

**优点**：
- 正直善良，坚守道德底线
- 疼爱徒弟，视如己出
- 坚定信念，对传承负责
- 舍己为人，大义凛然

**缺点**：
- 过于固执，不愿变通
- 对某些真相隐瞒不告
- 过于保护徒弟

## 背景故事

### 早年
- 出身湘西赶尸世家
- 年轻时游历天下，寻访僵尸踪迹
- 坚信僵尸存在，代代相传的预言

### 收徒
- 30岁收养孤儿向德豪（荒山捡到）
- 倾囊相授，严师慈父
- 禁止修炼《练尸大典》，称"有违天理"
- 实际上是知道向德豪身世不凡，希望他正常成长

### 预言之夜
- 月圆之夜，僵尸王将臣现世
- 穿上祖传道袍给徒弟
- 身披八卦披风，迎战将臣
- 与将臣大战，双方力竭
- 三方能量碰撞，爆炸
- 向守一在爆炸前被吸入裹尸袋（随身物品）
- **与将臣一起被吸入**
- 与向德豪一起穿越回异界

### 穿越后的状态（向德豪不知道）

**穿越瞬间**：
- 向守一力竭，被空间漩涡吸入裹尸袋
- 将臣重伤，也被吸入裹尸袋
- 裹尸袋保护两人，穿越到异界
- 向守一因力竭而死亡，意识进入沉睡
- 将臣重伤，也进入沉睡

**在裹尸袋中**：
- 向守一的尸体保持完好（裹尸袋功能）
- 意识处于特殊的"沉睡"状态
- 能够感知外界，但无法行动
- 能够"看到"向德豪的成长
- 能够"听到"向德豪的自言自语

**向守一的"视角"**：
- 看到向德豪醒来发现裹尸袋
- 看到向德豪滴血认主
- 看到向德豪发现自己和将臣
- 看到向德豪震惊、悲伤、恐惧
- 想告诉徒弟"师父在这"，但无法沟通
- 为徒弟的成长感到骄傲

### 异界苏醒后（向德豪的视角）

**发现真相**：
- 向德豪滴血认主裹尸袋
- 袋子打开，发现两物：
  - 师父的尸体，完好无损
  - 将臣，苏醒但虚弱
- 向德豪震惊："师父...您...您怎么会..."

**复杂的情感**：
- 震惊：师父在袋子里
- 悲伤：师父已经死了
- 困惑：将臣也在袋子里
- 恐惧：面对师父的尸体
- 逃避：不敢面对

**向德豪的反应**：
- 每天带着裹尸袋
- 像是带着师父的灵魂
- 偶尔对着袋子说话
- 暗暗发誓："一定要变强，复活师父"

## 人物结局

- **异界初期**：穿越后寻找徒弟，遭遇魔兽战死
- **尸体状态**：在裹尸袋中不腐，意识沉睡
- **向德豪视角**：一直怀疑但不敢打开，带着裹尸袋前行
- **复活方式**：向德豪用炼尸大典"炼制"师父，利用"卡bug"方式
- **最终结局**：被完全复活，恢复如初
- **余生**：与向德豪一起过"没羞没躁"的生活

## 裹尸袋中的岁月

### 向守一的"意识"
- 不是死亡，而是特殊的沉睡
- 能够模糊感知外界
- 能听到向德豪的声音
- 能感受到向德豪的成长
- 想回应但无法行动

### 关键时刻的"陪伴"

**向德豪第一次修炼魔法时**：
- 向守一："好小子，学得挺快..."

**向德豪受伤时**：
- 向守一："傻孩子，要小心啊..."

**向德豪想念师父时**：
- 向守一："师父在这...师父一直在..."

**向德豪立誓要复活师父时**：
- 向守一："德豪...师父等你..."

## 幕后故事

师父其实知道很多秘密：
1. 玉佩的真正来历（异界父母炼制，但不知是主宰）
2. 穿越的必然性（祖师托梦预言）
3. 《练尸大典》的真正用途（救世）
4. 向德豪的身世不凡（但不知具体是主宰之子）
5. 但他选择隐瞒，让徒弟自然成长

## 复活细节

### 复活方式
向德豪利用炼尸大典的"卡bug"方式：
1. 不是"复活"，而是"炼制"
2. 炼制的尸体保留意识
3. 向德豪用生命之力滋养
4. 逐步让师父"苏醒"
5. 最终完全复活

### 复活时对话
向德豪："师父...我终于...终于能见到您了..."
向守一："德豪...我都知道了...你做得很好..."
向德豪："师父...对不起...我...我不敢打开裹尸袋..."
向守一："傻孩子...师父不怪你...师父一直看着你成长..."
