# 师父（现代）

## 基本信息

| 项目 | 内容 |
|------|------|
| 姓名 | 向守一（师父） |
| 年龄 | 60岁左右 |
| 性别 | 男 |
| 职业 | 湘西赶尸派第36代掌门 |
| 外号 | 守一真人 |

## 外貌特征

- 身材精瘦，精神矍铄
- 白须飘飘，仙风道骨
- 常穿青布道袍
- 目光如电，不怒自威
- 战时披黄色八卦披风

## 性格特点

**优点**：
- 正直善良，坚守道德底线
- 疼爱徒弟，视如己出
- 坚定信念，对传承负责
- 舍己为人，大义凛然

**缺点**：
- 过于固执，不愿变通
- 对某些真相隐瞒不告
- 过于保护徒弟

## 背景故事

### 早年
- 出身湘西赶尸世家
- 年轻时游历天下，寻访僵尸踪迹
- 坚信僵尸存在，代代相传的预言

### 收徒
- 30岁收养孤儿向德豪
- 倾囊相授，严师慈父
- 禁止修炼《练尸大典》，称"有违天理"

### 预言之夜
- 月圆之夜，僵尸王将臣现世
- 穿上祖传道袍给徒弟
- 身披八卦披风，迎战将臣
- 与将臣同归于尽，爆炸穿越

## 能力设定

### 赶尸术
- **炼尸等级**：可炼制金尸
- **控尸术**：可同时控制十具铜尸
- **符咒**：精通各类符咒，画符如神
- **阵法**：布阵困敌，八卦阵

### 道术
- **驱鬼辟邪**：桃木剑、符纸、糯米
- **占卜**：梅花易数，推演天机
- **医术**：湘西苗医，毒术

### 装备
| 物品 | 说明 |
|------|------|
| 金钱剑 | 祖传法器，桃木剑身铜钱剑刃 |
| 八卦镜 | 辟邪法器，可反射邪祟 |
| 糯米 | 辟邪之物，克制僵尸 |
| 道袍 | 祖传道袍，护身符 |
| 八卦披风 | 战时披挂，增强法力 |

## 经典台词

1. "德豪，记住，炼尸可炼己，但不可失人性。"
2. "僵尸王将臣终将现世，这是我们向家的使命。"
3. "这道袍是你师祖留下的，今日传给你。"
4. "德豪，活下去！"

## 人物结局

- **中期结局**：在异界找到徒弟后，为保护徒弟而牺牲
- **最终结局**：被成为位面之主的向德豪复活
- **余生**：与向德豪一起过"没羞没躁"的生活

## 幕后故事

师父其实知道很多秘密：
1. 玉佩的真正来历（上古神器）
2. 穿越的必然性（预言）
3. 《练尸大典》的真正用途（救世）
4. 但他选择隐瞒，让徒弟自然成长
