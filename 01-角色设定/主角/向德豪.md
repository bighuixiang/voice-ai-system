# 向德豪

## 基本信息

| 项目 | 内容 |
|------|------|
| 姓名 | 向德豪 |
| 年龄 | 18岁（穿越时） |
| 性别 | 男 |
| 职业 | 湘西赶尸传人 → 魔道双修 → 位面之主 |
| 身份 | 向氏赶尸派第37代传人 |

## 外貌特征

- **穿越前**：清秀少年，常穿青布长衫，眼神坚毅
- **穿越后**：身披道袍，手持金钱剑，周身尸气缭绕
- **后期**：一袭黑袍，尸帝气息，魔神之威

## 性格特点

**优点**：
- 孝顺敬师，对师父言听计从
- 重情重义，对朋友极讲义气
- 心思缜密，善于分析局势
- 坚韧不拔，永不言弃

**缺点**：
- 对师父过于依赖，初期缺乏主见
- 心软，该杀之人时常留手
- 对感情迟钝，不明白师父的心意

## 背景故事

### 童年
- 自幼父母双亡，被师父收养
- 3岁开始学习赶尸术
- 10岁炼成第一具行尸
- 师父教导：炼尸先炼己，道德为重

### 少年
- 15岁炼成铁尸
- 18岁炼成铜尸
- 师父严禁修炼《练尸大典》，称"有违道德"

### 穿越之夜
- 月圆之夜，僵尸王将臣现世
- 师父与将臣大战，天昏地暗
- 天狗食日，三方正对，爆炸穿越
- 醒来只剩金钱剑、练尸大典、裹尸袋

## 能力设定

### 初期能力（穿越时）
- **炼尸**：可炼制铜尸
- **炼体**：锻脉境
- **道术**：基础符咒、驱鬼辟邪
- **装备**：金钱剑、八卦镜、糯米、道袍

### 中期发展
- **魔法**：师从异界美女师父，主修暗、雷双系
- **炼尸**：可炼制金尸、尸王
- **炼体**：金身境
- **绝招**：魔尸融合，尸气魔法轰炸

### 后期巅峰
- **魔法**：法神级别，全元素精通
- **炼尸**：炼成将臣尸帝，可融合
- **炼体**：神体境
- **终极招式**：位面降临，尸帝法神双临
