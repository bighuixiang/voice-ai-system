# 向德豪

## 基本信息

| 项目 | 内容 |
|------|------|
| 姓名 | 向德豪 |
| 年龄 | 18岁（穿越时） |
| 性别 | 男 |
| 职业 | 蓝星赶尸传人 → 魔道双修 → 位面之主 |
| 表面身份 | 向氏赶尸派第37代传人 |
| 真实身份 | **生命主宰与光明主宰之子** |

## 外貌特征

- **穿越前**：清秀少年，常穿青布长衫，眼神坚毅
- **穿越后**：身披道袍，手持金钱剑，周身尸气缭绕
- **觉醒后**：偶尔眼中闪过金光（光明之力）或绿光（生命之力）
- **后期**：一袭黑袍，尸帝气息，魔神之威

## 性格特点

**优点**：
- 孝顺敬师，对师父言听计从
- 重情重义，对朋友极讲义气
- 心思缜密，善于分析局势
- 坚韧不拔，永不言弃

**缺点**：
- 对师父过于依赖，初期缺乏主见
- 心软，该杀之人时常留手
- 对感情迟钝，不明白伊莎贝拉的心意
- 对自己身世一无所知（前期）

## 异界称号与认知

### 被误认为"死灵法师"
- **异界人的视角**：向德豪操控尸体战斗，被视为"死灵法师"
- **文化差异**：异界没有"赶尸术"概念，只能用"死灵法师"理解
- **向德豪的解释**："我不是死灵法师！我是赶尸传人！这是道术！"
- **伊莎贝拉的反应**："呃...这不就是死灵法师吗？"
- **将臣的吐槽**："死灵法师？那些弱鸡哪能跟我们比！他们操控的是愚蠢的骷髅，本大爷可是上古僵尸王！"

**战斗方式的区别**：
| 对比项 | 死灵法师 | 赶尸传人 |
|--------|----------|----------|
| 尸体类型 | 骷髅、僵尸 | 行尸、铁尸、铜尸、金尸、尸王 |
| 智力水平 | 无/低 | 保留生前意识（高级） |
| 控制方式 | 黑暗魔法 | 尸气+符咒 |
| 尸体强化 | 骷髅战士 | 炼体强化 |
| 特殊能力 | 亡者复生 | 点尸成兵 |

**误会带来的情节**：
- 学院学生躲避向德豪："他是死灵法师！别靠近！"
- 向德豪无奈："我真的不是..."
- 伊莎贝拉解释："他只是...用不同的方式做同样的事"
- 兽潮时，向德豪的"点尸成兵"让众人震惊："这才是真正的死灵魔法？！"
- 向德豪："这是赶尸术！点尸成兵！"

## 背景故事

### 身世之谜（向德豪不知道，读者前期也不知道）

**真实身份**：
- 父亲：光明主宰·奥瑞尔
- 母亲：生命主宰·盖亚
- 出生于异界艾兰大陆，主宰之子

**为何被送到现代世界**：
- 黑暗主宰暗中布局，污染所有主宰
- 光明主宰和生命主宰相爱，诞下向德豪
- 为保护孩子，**炼制玉佩**（耗费大量主宰之力）
- 将还是婴儿的向德豪送往现代世界
- 交托给可靠的人保护（向氏先祖）
- **玉佩设定**：当向德豪濒死时，自动触发传送回异界（父母身边）
- **这是保护机制，不是预言**

**玉佩的作用**：
1. **护主**：致命攻击时自动护体
2. **传送**：濒死时传送回异界（父母身边）
3. **封印**：封印向德豪的主宰之力，避免暴露
4. **融合入体**：启动后融入身体，默默守护
5. **力量传承**：封存的海量主宰之力随境界提升逐步解锁

**穿越时玉佩的真相（主角前期不知）**：
- 玉佩启动后**没有消失**，而是**融入了向德豪的身体**
- 主角以为玉佩在穿越时丢失了
- 实际上玉佩在他体内默默发挥作用
- 后期血脉觉醒时，玉佩会从体内浮现

### 童年（向德豪的记忆）

**被师父捡到**：
- 师父年轻时在荒山赶尸
- 四周狼嚎虎啸，可这婴儿躺在襁褓里，连只野狗都不敢靠近
- 师父觉得邪门，走近一看，孩子胸口挂着一块玉佩
- 婴儿不哭不闹，安安静静地睡着
- 师父心生怜悯，把婴儿捡回来了，玉佩也一直让他戴着
- 于是取名为"向德豪"，收为徒弟，视如己出

**成长**：
- 3岁开始学习赶尸术
- 10岁炼成第一具行尸
- 展现惊人的修炼天赋（血脉原因）
- 师父教导：炼尸先炼己，道德为重
- 玉佩从小戴在脖子上，从未取下

### 少年
- 15岁炼成铁尸
- 18岁炼成铜尸
- 师父严禁修炼《练尸大典》，称"有违道德"
- 师父其实知道一些秘密，但选择隐瞒

### 穿越之夜
- 月圆之夜，僵尸王将臣现世
- 师父与将臣大战，天昏地暗
- 天狗食日，三方正对
- 师父力竭，将臣重伤
- 三方能量碰撞，爆炸
- **关键时刻**：向德豪濒死，玉佩感应，启动传送
- 空间扭曲，产生漩涡
- 三人被传送到异界不同位置
- **三人一起穿越，但失散了**
- **玉佩在传送时融入向德豪体内（主角此时不知）**

### 异界苏醒

**醒来地点**：魔兽岭（东部危险区域）

**醒来**：
- 向德豪独自醒来
- 身边只有金钱剑、炼尸大典、八卦道袍、裹尸袋
- 师父和将臣都不见了
- **玉佩不见了**：主角以为玉佩在穿越时丢失了
- **实际情况**：玉佩已融入他胸口，默默守护
- **裹尸袋**：师父的随身物品，现在在向德豪身边
- "师父...将臣...你们在哪里？玉佩...也不见了..."

**初次危机**：
- 魔兽岭的初阶魔兽袭击
- 向德豪用炼尸大典的炼体方式战斗
- 力量不足，受伤

**血滴裹尸袋**：
- 鲜血滴到裹尸袋上
- 裹尸袋发热，激活了
- 向德豪感应到里面有一具"尸体"
- 打开一看：是将臣！

**发现将臣**：
- 将臣此时青面獠牙，沉睡中，看起来很可怕
- 向德豪看到没反应（在沉睡）
- 想到将臣不死不灭，身体应该很结实
- "拿你当武器用用！"

**认主将臣**：
- 把将臣拿出来抡起来砸魔兽
- 过程中鲜血滴到将臣眉心
- **血契绑定，被迫认主**
- 将臣苏醒："吾乃将臣，万尸之...等等，你能听见我说话？！"
- 向德豪："你能说话？"
- 将臣："千年了！终于能说话了！你知道我有多憋屈吗？我那不是想吃人！我手向前一伸是想好好聊聊，嘴巴张开是想说'你好'，结果只能嗷嗷嗷！那些道士一个个上来就打，你说这冤不冤？！"
- 向德豪："...从今天起，你就是我的兵器了。"
- 将臣："...等等，剧本不对吧？我不要当兵器！"
- （契约生效）
- 将臣："...行吧，当兵器就当兵器。但这小僵尸是个什么鬼？"

**将臣的形态**：
- 认主后发现可以随意变化
- **平时形态**：可爱的小僵尸（巴掌大小，青绿皮肤，萌萌的）
- **战斗形态**：可随意变成任意武器（剑、刀、枪、锤等）
- 平时蹲在向德豪肩膀上，打架时秒变武器
- 变成小僵尸后继续话痨吐槽，外表可爱嘴巴毒

**寻找师父**：
- 裹尸袋里只有将臣，没有师父
- 师父一定也在异界某个地方
- "师父...您在哪里？我一定会找到您的！"
- 暗暗发誓：变强，寻找师父

**向德豪的复杂情感**：
- 震惊：袋子里只有将臣，师父不在
- 担忧：师父生死未卜
- 困惑：穿越时发生了什么？
- 希望：将臣说"那老道士应该也穿越来了"
- 决心：一定要找到师父！

**与裹尸袋的羁绊**：
- 每天都带着裹尸袋（里面是变小的将臣）
- 有时候会对着袋子说话："师父，我一定会变强的"
- "师父，您一定还在某个地方...等我..."
- 裹尸袋是师父留给我的，我要带着它找到师父

**最初的变强动力**：
- 想要找到师父（前期）✅
- 师徒重逢后，想要保护师父（中期）✅
- 师父牺牲后，想要复活师父（后期）✅
- 想要复活所有人（小伙伴牺牲后）✅

## 血脉觉醒

### 第一阶段：封印期（穿越前-异界初期）
- 玉佩封印主宰之力
- 向德豪表现为赶尸传人
- 特殊体质：尸气与魔素双修完美契合

### 第二阶段：松动期（魔法学院时期）
- 玉佩在异界逐渐松动
- 向德豪修炼速度惊人
- 偶尔眼中闪过金光或绿光
- 但他自己不知道原因

### 第三阶段：觉醒期（师父牺牲后）
- 师父为保护他而牺牲
- 向德豪悲愤交加，濒死爆发
- 玉佩彻底激活
- 父母的力量开始觉醒

### 第四阶段：主宰期（位面之战）
- 与将臣融合后，完全觉醒
- 发现自己真实身份
- 光明与生命之力觉醒
- 成为超越主宰的存在——位面之主

## 能力设定

### 初期能力（穿越时）
- **炼尸**：可炼制铜尸
- **炼体**：锻脉境
- **道术**：基础符咒、驱鬼辟邪
- **装备**：金钱剑、八卦镜、糯米、八卦道袍
- **特殊**：炼尸大典
- **隐藏**：主宰之力（被封印）

### 抵御黑暗侵蚀
- **炼尸大典**：自带净化之力，但**只能净化被污染的尸体**，对活人效果有限
- **八卦道袍**：只能"延缓"污染，不能免疫；长期暴露仍会被污染
- **玉佩（在体内）**：封印血脉，避免主角被黑暗发现；不是主动防护，是被动隐藏
- **前期状态**：主角没有特殊抗性，靠的是低调不暴露
- **觉醒后的风险**：血脉觉醒后反而会吸引黑暗主宰的注意
- **完全觉醒**：主宰之力完全觉醒后，才能真正净化黑暗

### 中期发展
- **魔法**：师从伊莎贝拉，主修暗、雷双系
- **炼尸**：可炼制金尸、尸王
- **炼体**：金身境
- **血脉**：光明之力、生命之力开始觉醒
- **绝招**：魔尸融合，尸气魔法轰炸

### 后期巅峰
- **魔法**：法神级别，全元素精通
- **炼尸**：炼成将臣尸帝，可融合
- **炼体**：神体境
- **血脉**：光明主宰之力+生命主宰之力
- **终极招式**：位面降临，尸帝法神双临

### 觉醒后的能力
| 能力 | 来源 | 效果 |
|------|------|------|
| 光明之瞳 | 光明主宰血脉 | 看破一切虚妄，净化黑暗 |
| 生命之愈 | 生命主宰血脉 | 极速恢复，滴血重生 |
| 光生合一 | 父母双血脉 | 光明与生命融合，创造之力 |
| 位面主宰 | 超越父母 | 位面之力，创世灭世 |

## 特殊物品

### 赶尸派三大神器

| 物品 | 来源 | 用途 |
|------|------|------|
| **玉佩** | 父母所炼 | 传送回异界，护主，封印血脉，**已融入体内** |
| **炼尸大典** | 师父传承，异界带来 | 炼尸秘籍，**能抵御黑暗侵蚀** |
| **八卦道袍** | 师父祖传 | **防护+净化，能抵御黑暗污染** |

### 玉佩的状态（重要伏笔）

**主角的认知**：
- 穿越后以为玉佩丢失了
- 不知道玉佩已经融入体内

**真实情况**：
- 玉佩融入向德豪胸口位置
- 默默守护，随时可以护主
- 封存的力量逐步解锁
- 后期会从体内浮现，与主角融合

**关键时刻的表现**：
- 师父牺牲时，胸口会发热
- 濒死时，玉佩轮廓会短暂浮现
- 觉醒时，玉佩完全显现

### 炼尸大典详解
- **外表**：古朴的书籍，不知什么材质
- **异界发现**：其实是某种高科技/魔法结晶
- **特殊能力**：自带净化之力，能抵御黑暗侵蚀
- **记载内容**：从行尸到上古僵尸王的完整炼制方法
- **战斗作用**：能净化被黑暗污染的尸体，炼成可控的尸军

### 八卦道袍详解
- **外表**：青布道袍，绣着八卦图案
- **特殊能力**：布料中融入符文和净化之力
- **防护效果**：自动抵御黑暗污染
- **异界表现**：在黑暗环境中散发淡淡光芒
- **重要性**：是向德豪在异界初期不受黑暗影响的关键

### 三大神器的作用
- **抵御黑暗**：炼尸大典+八卦道袍，双重防护
- **净化之力**：能净化被黑暗侵蚀的存在
- **向德豪独特**：他是唯一能同时在黑暗和光明中行走的人
- **关键优势**：在黑暗主宰的棋局中，向德豪是唯一的变数
