# 向德豪

## 基本信息

| 项目 | 内容 |
|------|------|
| 姓名 | 向德豪 |
| 年龄 | 18岁（穿越时） |
| 性别 | 男 |
| 职业 | 湘西赶尸传人 → 魔道双修 → 位面之主 |
| 表面身份 | 向氏赶尸派第37代传人 |
| 真实身份 | **生命主宰与光明主宰之子** |

## 外貌特征

- **穿越前**：清秀少年，常穿青布长衫，眼神坚毅
- **穿越后**：身披道袍，手持金钱剑，周身尸气缭绕
- **觉醒后**：偶尔眼中闪过金光（光明之力）或绿光（生命之力）
- **后期**：一袭黑袍，尸帝气息，魔神之威

## 性格特点

**优点**：
- 孝顺敬师，对师父言听计从
- 重情重义，对朋友极讲义气
- 心思缜密，善于分析局势
- 坚韧不拔，永不言弃

**缺点**：
- 对师父过于依赖，初期缺乏主见
- 心软，该杀之人时常留手
- 对感情迟钝，不明白伊莎贝拉的心意
- 对自己身世一无所知（前期）

## 背景故事

### 身世之谜（向德豪不知道，读者前期也不知道）

**真实身份**：
- 父亲：光明主宰·奥瑞尔
- 母亲：生命主宰·盖亚
- 出生于异界艾兰大陆，主宰之子

**为何被送到现代世界**：
- 黑暗主宰暗中布局，污染所有主宰
- 光明主宰和生命主宰相爱，诞下向德豪
- 为保护孩子，**炼制护界玉佩**（耗费大量主宰之力）
- 将还是婴儿的向德豪送往现代世界
- 交托给可靠的人保护（向氏先祖）
- 玉佩会在向德豪生死攸关时启动，送回异界

**玉佩的作用**：
1. **护主**：致命攻击时自动护体
2. **传送**：生死关头传送回异界（父母身边）
3. **封印**：封印向德豪的主宰之力，避免暴露
4. **引导**：在异界引导他觉醒

### 童年（向德豪的记忆）

**被师父捡到**：
- 师父年轻时在荒山赶尸
- 深夜发现一道天光降在山间
- 走过去发现一个婴儿，胸口挂着玉佩
- 婴儿不哭不闹，只是静静看着师父
- 师父祖师爷托梦说"此子与你有缘，善养之"
- 于是取名为"向德豪"，收为徒弟

**成长**：
- 3岁开始学习赶尸术
- 10岁炼成第一具行尸
- 展现惊人的修炼天赋（血脉原因）
- 师父教导：炼尸先炼己，道德为重
- 玉佩从小戴在脖子上，从未取下

### 少年
- 15岁炼成铁尸
- 18岁炼成铜尸
- 师父严禁修炼《练尸大典》，称"有违道德"
- 师父其实知道一些秘密，但选择隐瞒

### 穿越之夜
- 月圆之夜，僵尸王将臣现世
- 师父与将臣大战，天昏地暗
- 天狗食日，三方正对
- 师父力竭，将臣重伤
- 三方能量碰撞，爆炸
- **关键时刻**：向德豪濒死，玉佩感应，启动传送
- 空间扭曲，产生漩涡
- 师父和将臣被吸入随身携带的裹尸袋
- **三人一起穿越回异界**

### 异界苏醒

**醒来**：
- 向德豪独自醒来
- 身边只有金钱剑、炼尸大典、裹尸袋
- 师父和将臣都不见了
- **裹尸袋**：师父的随身物品，现在在向德豪身边

**发现裹尸袋**：
- 向德豪知道这是师父的随身物品
- 师父曾经说过："这袋子能让尸体保持不腐"
- 向德豪拿着裹尸袋，感觉沉甸甸的
- "师父...将臣...你们在哪里？"

**滴血认主**：
- 向德豪受伤，血液滴在裹尸袋上
- 裹尸袋发热，血认主完成
- 袋中两物同时认主：
  - **将臣**：苏醒，但无法离开裹尸袋
  - **师父**：保持死亡状态，但意识沉睡

**真相揭晓**：
- 向德豪："这是...师父？！还有...将臣？"
- 师父的尸体在裹尸袋中，完好无损
- 将臣在裹尸袋中苏醒："吾...吾在何处？"
- 向德豪震惊："师父...您...您怎么会..."

**向德豪的复杂情感**：
- 震惊：师父在袋子里
- 悲伤：师父已经死了
- 困惑：将臣也在袋子里
- 恐惧：师父死了，我该怎么办？
- 逃避：不敢面对师父的尸体
- 向德豪内心开始怀疑：师父在里面吗？
- 但他害怕面对，不敢打开

**复杂的情感**：
- 每天都带着裹尸袋
- 像是带着师父的灵魂
- 有时候会对着袋子说话："师父，我一定会变强的"
- 暗暗发誓："一定要找到复活的方法"

**最初的变强动力**：
- 想要找到师父（前期）
- 想要复活师父（中期，了解复活规则后）
- 想要复活所有人（后期，小伙伴牺牲后）

## 血脉觉醒

### 第一阶段：封印期（穿越前-异界初期）
- 玉佩封印主宰之力
- 向德豪表现为赶尸传人
- 特殊体质：尸气与魔素双修完美契合

### 第二阶段：松动期（魔法学院时期）
- 玉佩在异界逐渐松动
- 向德豪修炼速度惊人
- 偶尔眼中闪过金光或绿光
- 但他自己不知道原因

### 第三阶段：觉醒期（师父牺牲后）
- 师父为保护他而牺牲
- 向德豪悲愤交加，濒死爆发
- 玉佩彻底激活
- 父母的力量开始觉醒

### 第四阶段：主宰期（位面之战）
- 与将臣融合后，完全觉醒
- 发现自己真实身份
- 光明与生命之力觉醒
- 成为超越主宰的存在——位面之主

## 能力设定

### 初期能力（穿越时）
- **炼尸**：可炼制铜尸
- **炼体**：锻脉境
- **道术**：基础符咒、驱鬼辟邪
- **装备**：金钱剑、八卦镜、糯米、八卦道袍
- **特殊**：炼尸大典
- **隐藏**：主宰之力（被封印）

### 抵御黑暗侵蚀
- **八卦道袍**：祖传宝物，能抵御黑暗污染
- **炼尸大典**：自带净化之力，净化被黑暗侵蚀的尸体
- **血脉之力**：暗藏光明与生命之力，黑暗克星
- **三者结合**：向德豪是唯一能在黑暗环境中保持清醒的人

### 中期发展
- **魔法**：师从伊莎贝拉，主修暗、雷双系
- **炼尸**：可炼制金尸、尸王
- **炼体**：金身境
- **血脉**：光明之力、生命之力开始觉醒
- **绝招**：魔尸融合，尸气魔法轰炸

### 后期巅峰
- **魔法**：法神级别，全元素精通
- **炼尸**：炼成将臣尸帝，可融合
- **炼体**：神体境
- **血脉**：光明主宰之力+生命主宰之力
- **终极招式**：位面降临，尸帝法神双临

### 觉醒后的能力
| 能力 | 来源 | 效果 |
|------|------|------|
| 光明之瞳 | 光明主宰血脉 | 看破一切虚妄，净化黑暗 |
| 生命之愈 | 生命主宰血脉 | 极速恢复，滴血重生 |
| 光生合一 | 父母双血脉 | 光明与生命融合，创造之力 |
| 位面主宰 | 超越父母 | 位面之力，创世灭世 |

### 炼尸大典详解
- **外表**：古朴的书籍，不知什么材质
- **异界发现**：其实是某种高科技/魔法结晶
- **特殊能力**：自带净化之力，能抵御黑暗侵蚀
- **记载内容**：从行尸到尸神的完整炼制方法
- **战斗作用**：能净化被黑暗污染的尸体，炼成可控的尸军

### 八卦道袍详解
- **外表**：青布道袍，绣着八卦图案
- **特殊能力**：布料中融入符文和净化之力
- **防护效果**：自动抵御黑暗污染
- **异界表现**：在黑暗环境中散发淡淡光芒
- **重要性**：是向德豪在异界初期不受黑暗影响的关键

### 三大神器的作用
- **抵御黑暗**：炼尸大典+八卦道袍，双重防护
- **净化之力**：能净化被黑暗侵蚀的存在
- **向德豪独特**：他是唯一能同时在黑暗和光明中行走的人
- **关键优势**：在黑暗主宰的棋局中，向德豪是唯一的变数
