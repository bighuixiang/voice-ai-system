# 伊莎贝拉——异界美女师父

## 基本信息

| 项目 | 内容 |
|------|------|
| 姓名 | 伊莎贝拉·星辰 |
| 年龄 | 外表25岁左右，实际300+ |
| 性别 | 女 |
| 职业 | 星辰魔导师 → 大魔导师 |
| 所属 | 星辰魔法学院院长 |
| 魔法属性 | 星辰、暗、空间 |

## 外貌特征

- 银色长发如瀑布般垂至腰际
- 星眸璀璨，眼眸深处仿佛有星辰流转
- 高挑身材，凹凸有致
- 常穿深蓝色魔法长袍，绣着星辰图案
- 气质清冷高傲，但对自己人会温柔

## 性格特点

**优点**：
- 外冷内热，心地善良
- 聪慧过人，魔法天赋卓绝
- 责任感强，护短
- 对认定的人极为信任

**缺点**：
- 高傲毒舌，不善表达感情
- 过于理性，初期不懂爱
- 对陌生人冷漠

## 背景故事

### 早年
- 出身帝国皇室，天赋卓绝
- 10岁展现魔法天赋，被誉为天才
- 15岁进入魔法学院，18岁成为魔导师
- 20岁拒绝无数追求者，一心修炼

### 成为院长
- 30岁成为星辰魔法学院院长
- 创立星辰魔法体系
- 桃李满天下，弟子遍布大陆

### 遇见向德豪
- 在魔兽岭边缘救下重伤的向德豪
- 发现他的特殊体质（尸气+魔素）
- 收为弟子，倾囊相授
- 日久生情，不自知

## 能力设定

### 魔法等级
- **穿越时**：大魔导师
- **后期**：法圣，接近法神

### 魔法特色

**星辰魔法**（自创）
- 星辰陨灭：召唤星辰之力轰炸
- 星辰领域：领域内星辰之力加护
- 星辰转移：短距离空间传送

**暗系魔法**
- 暗影束缚：困敌
- 暗影之刃：攻击
- 暗影降临：大范围暗系魔法

**空间魔法**
- 空间裂缝：切割敌人
- 空间储物：储物空间
- 空间封锁：禁锢敌人

## 情感细节

### 暧昧期
- 夜晚辅导魔法时，靠得很近
- 为向德豪缝补道袍
- 在危险时本能地挡在他前面
- 吃醋别的女生靠近向德豪

### 表白
- 兽潮来袭，向德豪拼死守护
- 伊莎贝拉冲入敌阵救他
- 两人并肩作战，生死时刻
- 伊莎贝拉："如果还能活着，我想告诉你..."

### 相守
- 向德豪成为位面之主后
- 伊莎贝拉选择留在身边
- 不在乎地位，只在乎人
- 现代师父复活后，三人和谐相处
