# 艾米——治愈之光

## 基本信息

| 项目 | 内容 |
|------|------|
| 姓名 | 艾米·晨露 |
| 年龄 | 18岁 |
| 性别 | 女 |
| 职业 | 治疗师 |
| 魔法属性 | 生命、水 |
| 等级（终） | 大魔导师 |

## 外貌特征

- 金色长发，温柔美丽
- 翠绿眼眸，充满生机
- 身穿白色法袍，带绿色纹路
- 周身散发着淡淡的生命气息

## 性格特点

**优点**：
- 温柔善良，医者仁心
- 细心体贴，照顾队友
- 坚强勇敢，危机时挺身而出
- 纯净无暇，如水晶般透明

**缺点**：
- 过于善良，有时候心软
- 不善于表达感情

## 背景故事

- 出身治疗师世家
- 从小立志救死扶伤
- 以第一名进入星辰魔法学院
- 与向德豪同期，暗恋但从未说出口

## 与向德豪的关系

**初遇**：
- 向德豪在训练中受伤
- 艾米主动为他治疗
- "你的伤...很特别，需要时间恢复。"
- "谢谢。"向德豪第一次感受到异界的温暖

**相处**：
- 艾米经常偷偷多给向德豪准备药水
- 向德豪受伤时艾米总是第一个到
- 两人之间有淡淡的好感，但谁都没说破
- 艾米知道向德豪心在伊莎贝拉身上，选择默默祝福

**经典对话**：
- 艾米："小心点，我不想再看到你受伤。"
- 向德豪："有你在，我不怕。"
- 艾米：（脸红）"笨蛋..."

## 能力设定

### 治疗/生命魔法
- **治愈之光**：基础治疗
- **生命之泉**：大范围治疗
- **生命守护**：护盾+持续恢复
- **生命献祭**：燃烧生命，换取强大力量（终招）

### 战斗风格
- 后方支援，治疗队友
- 危机时会冲上前线保护
- "我不会让任何人受伤！"

## 牺牲场景

### 兽潮之战

**背景**：
- 防线崩溃，大量伤员
- 艾米已经连续治疗三天三夜
- 魔力即将耗尽

**关键时刻**：
- 兽潮突破最后一道防线
- 冲向伤员和平民
- 艾米挡在最前面
- "我不会让你们伤害任何人！"

**艾米的选择**：
- 燃烧生命之力
- 展开生命守护，保护所有人
- "向德豪...答应我...一定要活下去..."
- 生命献祭：以生命为代价，创造绝对防护

**最后的话**：
- "向德豪...我喜欢你...但我知道...你喜欢的是院长..."
- "没关系...只要...你能...活下去..."
- 生命之光绽放，阻挡兽潮

**向德豪的反应**：
- "艾米！！！"
- 终于明白艾米的心意
- "对不起...我应该早点知道的..."
- 泪水与愤怒交织

## 后续影响

- 向德豪时常想起艾米的温柔
- 生命之力觉醒时有艾米的影子
- 最终位面之主时复活艾米
- 艾米："我就知道...你一定可以..."
