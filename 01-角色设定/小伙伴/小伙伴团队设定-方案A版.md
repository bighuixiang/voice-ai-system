## 经典组合场景

### 1. 一起吃饭

```
学院食堂。

向德豪坐在中间。
左边是格蕾丝，右边是艾米莉亚。

格蕾丝把水果推给他："这个...你吃..."
艾米莉亚把蛋糕推给他："这个...也好吃..."

向德豪看着两大堆食物。
"我...我吃不完..."

格蕾丝："没关系的...我..."
艾米莉亚："我也..."

弗拉姆（远处）："啧，这两个女娃..."

凯尔："她们很用心。"

将臣："啧啧，年轻人的世界。"
```

### 2. 一起训练

```
训练场。

向德豪在练剑。
格蕾丝在旁边偷偷看，手里拿着急救包。
艾米莉亚在旁边...迷路了。

艾米莉亚："德豪...训练场在哪里..."
向德豪："...你就在训练场中央。"

艾米莉亚："啊？！是这里吗？"
"我找了半小时..."
"这里怎么有这么多树..."

向德豪叹气，捏了捏她的脸。
"下次我牵着你好不好？"

艾米莉亚脸红："好...好的..."
呆毛卷成小卷。

格蕾丝在远处看着，温柔地笑。
```

### 3. 一起保护向德豪

```
战斗中。

敌人偷袭向德豪。

格蕾丝第一时间挡在前面。
"不能让德豪受伤！"

艾米莉亚也挡过来。
"我也...我也要保护德豪！"

向德豪："你们两个，退后！"

格蕾丝："不行...你是战斗主力..."
艾米莉亚："对...你不能受伤..."

两人被击倒。

向德豪抱起她们，眼中闪过怒火。
"我不会让你们再受伤了！"

将臣："啧，这小子开窍了。"
```

## 总结

### 优化亮点

1. **角色减少**：删除艾伦，避免功能重叠
2. **牺牲分散**：四人的牺牲分散在不同阶段，情感冲击更强
3. **感情线清晰**：双女主 + 单恋姐妹会，层次分明
4. **喜剧元素丰富**：艾米莉亚的迷糊属性 + 将臣的吐槽

### 下一步计划

1. 更新整体规划文件，替换艾伦为艾米莉亚
2. 调整牺牲场景，确保四个小伙伴的牺牲有差异化
3. 增加"单恋姐妹会"的互动场景
