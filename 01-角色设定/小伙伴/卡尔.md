# 卡尔——正义之剑

## 基本信息

| 项目 | 内容 |
|------|------|
| 姓名 | 卡尔·铁壁 |
| 年龄 | 20岁 |
| 性别 | 男 |
| 职业 | 剑士 |
| 魔法属性 | 土、强化 |
| 等级（终） | 大魔导师（剑圣） |

## 外貌特征

- 棕发棕眼，坚毅面容
- 身材魁梧，肌肉结实
- 身穿重甲，手持巨剑
- 战斗时如铜墙铁壁

## 性格特点

**优点**：
- 正义凛然，保护弱小
- 坚定不移，永不退缩
- 沉稳可靠，团队之盾
- 严师益友，指导向德豪

**缺点**：
- 过于死板，不懂变通
- 有时候太较真

## 背景故事

- 出身骑士世家
- 从小以骑士为榜样
- 进入学院学习，成为学生会长
- 与向德豪亦师亦友

## 与向德豪的关系

**初遇**：
- 向德豪刚入学，被欺负
- 卡尔挺身而出
- "学院禁止欺凌。"
- 从此成为向德豪的大哥

**相处**：
- 卡尔教向德豪战斗技巧
- 向德豪教卡尔一些道术
- 两人经常切磋，互有胜负
- 卡尔像大哥一样照顾向德豪

**经典对话**：
- 卡尔："德豪，记住，剑是用来保护人的。"
- 向德豪："我会的，卡尔大哥。"
- 卡尔："叫我大哥就行。"

## 能力设定

### 土系+剑术
- **大地之盾**：土系防护
- **剑意**：剑气攻击
- **大地堡垒**：巨大防护
- **剑圣·不屈**（终招）：燃烧生命，不死不灭

### 战斗风格
- 防御为主，反击为辅
- 团队的铜墙铁壁
- "只要我还站着，没人能伤害我的朋友！"

## 牺牲场景

### 兽潮之战

**背景**：
- 防线即将崩溃
- 大量平民需要撤离
- 需要有人断后

**关键时刻**：
- 兽潮大军压境
- 平民还未完全撤离
- 卡尔主动请缨断后

**卡尔的选择**：
- 站在撤离通道口
- 展开大地堡垒
- "德豪，带大家走！这里交给我！"
- 剑圣·不屈：燃烧生命，不死不灭

**战斗**：
- 一人挡住千军万马
- 巨剑挥舞，兽尸遍地
- 但兽潮无穷无尽
- 卡尔的身体开始崩溃

**最后的话**：
- "德豪...记住...剑是用来...保护人的..."
- "我不后悔...能...和你们...并肩作战..."
- 巨剑插入大地，身体化为堡垒
- "保护...大家..."

**向德豪的反应**：
- "卡尔大哥！！！"
- 泪水模糊双眼
- "我会...会替你...保护所有人..."
- 悲痛化为力量

## 后续影响

- 向德豪继承了卡尔的剑意
- 炼尸时融入土系力量
- 最终位面之主时复活卡尔
- 卡尔："德豪，你已经成为真正的剑圣了。"
