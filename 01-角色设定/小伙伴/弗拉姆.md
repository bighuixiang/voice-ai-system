# 弗拉姆——火焰之友

## 基本信息

| 项目 | 内容 |
|------|------|
| 姓名 | 弗拉姆·伊格尼斯 |
| 年龄 | 19岁 |
| 性别 | 男 |
| 职业 | 火系魔法师 |
| 魔法属性 | 火 |
| 等级（终） | 大魔导师 |

## 外貌特征

- 红发如火，热情洋溢
- 身材健壮，笑容灿烂
- 常穿红色法袍，绣火焰图案
- 战斗时双目燃起火焰

## 性格特点

**优点**：
- 热血冲动，重情重义
- 勇敢无畏，永远冲在前面
- 乐观开朗，团队的开心果
- 忠诚可靠，为朋友可以牺牲

**缺点**：
- 过于冲动，不够冷静
- 有时候太讲义气，不计后果

## 背景故事

- 出身平民，魔法天赋惊人
- 靠奖学金进入星辰魔法学院
- 与向德豪同期，成为室友和好友
- 称向德豪为"兄弟"，形影不离

## 与向德豪的关系

**初遇**：
- 学院分配宿舍，两人成为室友
- 弗拉姆："嘿兄弟，我看你骨骼惊奇，一定是个练火法的好苗子！"
- 向德豪："我赶尸的..."
- 弗拉姆："那也行啊！咱们互补！"

**相处**：
- 弗拉姆经常带向德豪去食堂"加餐"
- 向德豪教弗拉姆一些道术
- 两人经常一起训练，互相切磋
- 弗拉姆是向德豪在异界第一个真朋友

**经典对话**：
- 弗拉姆："兄弟，以后有我罩着你！"
- 向德豪："谢谢，但我可能比你强..."
- 弗拉姆："哈哈，谦虚了！"

## 能力设定

### 火系魔法
- **烈火术**：基础火焰攻击
- **爆裂火球**：强力爆炸
- **火焰风暴**：大范围火焰
- **炎龙降临**：召唤火龙（终极招式）

### 战斗风格
- 正面硬刚，火力全开
- "让火焰净化一切！"
- 团队的主力输出

## 牺牲场景

### 兽潮之战

**背景**：
- 兽潮来袭，大军压境
- 向德豪的点尸成器还未完全成型
- 防线即将崩溃

**关键时刻**：
- 一只兽王突破防线
- 目标直指后方的平民和向德豪
- 向德豪正在炼尸，无法移动

**弗拉姆的选择**：
- 挡在兽王面前
- "兄弟，专心炼尸！这里交给我！"
- 燃烧生命，释放最强招式
- "炎龙...终式...自爆！！！"

**最后的话**：
- "向德豪...活下去...替我...看看...没有兽潮的...世界..."
- 火焰吞噬一切，与兽王同归于尽

**向德豪的反应**：
- "弗拉姆！！！"
- 悲愤交加，血脉觉醒的前兆
- "我会替你...让这兽潮付出代价！"

## 后续影响

- 向德豪时常梦到弗拉姆
- 炼尸时会想起弗拉姆的火焰
- 最终位面之主时复活弗拉姆
- 弗拉姆："嘿嘿，我就知道兄弟你肯定行！"
