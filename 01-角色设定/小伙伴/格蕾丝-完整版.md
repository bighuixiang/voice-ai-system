## 早期暗恋铺垫（新增核心内容）

### 第8章：初遇向德豪 - 心动的开始

**场景：学院花园**

```
格蕾丝在花园里散步，看到一个人独自坐在树下。

她走近一看，是一个东方面孔的少年。

他看着天空，眼神很孤独。

格蕾丝想起自己小时候——

"孤儿院里，我也是这样一个人坐着..."

她走过去。

"你好...我叫格蕾丝·晨露。"

少年转头，眼神里有一丝警惕。

"...向德豪。"

"你一个人？"

"...嗯。"

格蕾丝在他旁边坐下。

"那我陪你坐会吧。"

两人静静地坐着，没有说话。

但向德豪感觉心里暖洋洋的。

这是他来到异界后，第一次有人主动靠近。

格蕾丝看着他侧脸。

（心里：他的眼神...和曾经的我一模一样...）
```

### 第8.5章：第一次治疗 - 心跳加速

**场景：训练场**

```
向德豪训练时受伤了。

格蕾丝正好路过，立刻冲过去。

"你的伤...让我看看！"

她蹲下来，检查伤口。

"还好...不深...我帮你治疗..."

向德豪："不用麻烦..."

"不麻烦的！"格蕾丝打断他，"我...我是治疗师，这是我的职责..."

她开始施展治疗术。

柔和的光芒从她手中流出。

向德豪感觉伤口温暖而舒适。

"谢谢你..."

格蕾丝的手指在颤抖。

（心里：为什么我手在抖？我明明治疗过那么多人...）

向德豪："怎么了？你的手..."

格蕾丝脸红："没...没什么！可能...可能累了吧..."

她快速治疗完，站起来。

"那...那你小心点..."

转身就走，心跳如鼓。

（心里：天啊...我在干什么...心跳怎么这么快...）
```

### 第9章：深夜训练场 - 默默守护

**场景：深夜**

```
格蕾丝在宿舍里睡不着。

她想起向德豪那天的眼神。

"不知道他现在怎么样了..."

她穿上衣服，走向训练场。

远远地，她看到一个人影。

是向德豪。

他还在训练。

格蕾丝躲在远处看着。

他一次次挥剑。

一次次倒下。

又一次次爬起来。

格蕾丝的心揪在一起。

"他...为什么要这么拼命..."

她看着看着，眼眶湿润。

向德豪终于练完了，满身是汗。

格蕾丝想走出去，但又犹豫了。

（心里：如果我出去，会不会打扰他...）

最后，她决定离开。

但她不知道，向德豪在她转身时，感应到了什么。

向德豪："有人...？"

他望向格蕾丝离开的方向。

"那是...格蕾丝？"

他心中升起一股暖意。
```

### 第10章：食堂偶遇 - 小小的关心

**场景：学院食堂**

```
格蕾丝端着餐盘找座位。

她看到向德豪独自一人吃饭。

她的心跳加速。

"我...我可以坐这里吗？"

向德豪抬头，愣了一下。

"...当然。"

格蕾丝坐下，不知道说什么。

她看到向德豪的餐盘里只有简单的面包和水。

"你...你就吃这些？"

向德豪："我...我在省钱..."

格蕾丝咬了咬嘴唇。

她把自己的水果推到他面前。

"这个...你吃吧..."

向德豪惊讶："这..."

格蕾丝脸红："我...我吃不完...浪费不好..."

（心里：其实我特意多买的...）

向德豪犹豫了一下，接过来。

"谢谢。"

格蕾丝的心跳漏了一拍。

"不...不用谢..."

她低头吃饭，掩饰脸上的红晕。

将臣在向德豪肩膀上小声说：
"那女娃，看你的眼神不太对。"

向德豪："？"

将臣："啧，年轻人，慢慢享受吧。"

向德豪："你话太多了。"

格蕾丝不知道他们在说什么，只是感到很幸福。

（心里：能这样坐在他旁边...就好...）
```

### 第11章：治疗时的温柔 - 勇敢的触碰

**场景：治疗室**

```
向德豪在任务中受伤，被送来治疗室。

格蕾丝主动要求负责。

"让我来吧。"

她开始为他治疗。

伤口在胸口。

格蕾丝的手指轻轻触碰他的皮肤。

向德豪能感觉到她的体温。

格蕾丝的脸越来越红。

"疼吗？"她轻声问。

"不疼。"向德豪说。

"骗人..."格蕾丝小声说，"伤口这么深..."

她一边治疗，一边轻轻吹气。

"这样...会好一点..."

向德豪愣住。

他从未被人这样温柔对待过。

师父对他很好，但那是长辈的关爱。

而格蕾丝的温柔，是不同的。

向德豪："谢谢你...一直这样对我..."

格蕾丝的手指顿了一下。

"我...我只是..."

她抬起头，正好对上向德豪的眼睛。

两人的距离很近。

格蕾丝能闻到他身上的气息。

她的脸彻底红了。

"我...我继续治疗..."

她低下头，手指颤抖得厉害。

向德豪没有说话，只是静静地看着她。

（心里：她...在紧张什么...）

格蕾丝的心跳如雷。

（心里：天啊...他离我太近了...我...我不能...）

治疗完成后，格蕾丝快速站起。

"治...治疗好了！"

她几乎是逃跑般离开。

向德豪看着她的背影，有些疑惑。

"她...怎么了？"

将臣："啧，傻小子。"

"人家对你有意思，你居然看不出来？"

向德豪："..."

将臣："赶尸派第37代传人，感情方面果然是白痴。"
```

### 第12章：月下长谈 - 心与心的靠近

**场景：学院花园，月夜**

```

格蕾丝在花园里散步。

她看到向德豪也在。

他坐在长椅上，看着月亮。

格蕾丝想离开，但向德豪先看到了她。

"格蕾丝。"

格蕾丝停住脚步。

"院...院长好..."

向德豪笑了："这里不是学院，叫名字就好。"

"...德豪。"

"坐吗？"

格蕾丝犹豫了一下，坐下。

两人看着月亮。

格蕾丝："你在想什么？"

向德豪："我在想...我师父..."

"他现在在哪里...是否安好..."

格蕾丝转头看他。

他的眼里有悲伤。

格蕾丝的心揪了一下。

"你一定很想念他..."

向德豪点头："嗯...我们相依为命十八年..."

"穿越时失散了...我一定要找到他..."

格蕾丝的手伸出去，想要拍拍他的肩膀。

但又缩了回来。

（心里：我...我凭什么安慰他...）

向德豪突然说："格蕾丝..."

"嗯？"

"谢谢你..."

"谢我什么？"

"谢谢你...愿意陪我坐在这里..."

"谢谢你...从不把我当成什么'死灵法师'..."

格蕾丝摇头："我从来没有那样想过..."

"你是德豪，这就够了..."

向德豪转头看她。

月光下，格蕾丝的侧脸温柔如水。

向德豪心中一动。

"格蕾丝...你为什么对我这么好？"

格蕾丝愣住。

"我...我..."

她能说什么？

说"我喜欢你"？

不...不可以...

他心里有别人...

格蕾丝低下头。

"因为...我们是朋友啊..."

向德豪沉默了一会儿。

"...朋友...吗？"

格蕾丝的心在痛。

（心里：是朋友...只能是朋友...）

"是...朋友..."格蕾丝的声音有些颤抖。

向德豪没有再说话。

但格蕾丝知道，他也感觉到了什么。

两人静静地坐着，直到深夜。

月光洒在两人身上。

格蕾丝知道，这是她最幸福的夜晚。

也是她最悲伤的夜晚。

幸福，因为他就在身边。

悲伤，因为他永远不会有同样的感觉。
```
