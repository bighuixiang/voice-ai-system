# 生命主宰·盖亚

## 基本信息

| 项目 | 内容 |
|------|------|
| 名号 | 生命主宰·盖亚 |
| 称号 | 生命之源、万物之母 |
| 等级 | 主宰（位面最强之一） |
| 属性 | 纯粹生命 |
| 状态 | 轻度污染（向德豪需净化） |
| 家庭 | 光明主宰·奥瑞尔（爱人）、向德豪（儿子） |

## 外貌特征

- **正常形态**：绿发飘逸，身穿绿色长裙，美丽高贵
- **战斗形态**：绿光环绕，生机盎然
- **污染后**：绿色中带黑气

## 性格特点

- **温柔慈爱**：如大地母亲般包容
- **热爱生命**：守护万物生灵
- **深爱家人**：对奥瑞尔和向德豪深爱
- **坚韧不拔**：为了家人可以承受一切

## 背景故事

### 诞生
- 位面初开时诞生
- 成为生命主宰
- 统治生命神域

### 与奥瑞尔相爱
- 遇见光明主宰奥瑞尔
- 两人相爱，违反"主宰不近情感"的"规则"
- 诞下向德豪

### 察觉阴谋
- 与奥瑞尔一同发现黑暗主宰的阴谋
- 知道自己也被盯上

### 炼制玉佩
- 与奥瑞尔联手炼制"玉佩"
- 耗费大量主宰之力
- 注入光明与生命双重守护
- 只为保护儿子

### 送走儿子
- 痛苦但必要的决定
- "活下去，孩子，无论在哪里"
- 泪别婴儿
- 期待重逢之日

### 被污染与自我封印
- 对抗黑暗时被轻度污染
- 自我封印，等待儿子归来

### 重逢与净化
- 向德豪觉醒时现身
- 一家团聚
- 被儿子净化
- 见证儿子成为位面之主

## 能力设定

### 主宰之力
- **生命领域**：领域内生机勃勃，恢复力大增
- **生命治愈**：治疗一切伤势
- **生命创造**：创造生命
- **不死不灭**：生命无处不在

### 母子之力
- 向德豪继承了生命血脉
- 极强的恢复能力
- 后期超越母亲

- 一家三口团聚
- 盖亚是最宠向德豪的
- 经常给向德豪"加餐"（生命能量）
- 向德豪："妈，我真的吃不下了..."
