# 光明主宰·奥瑞尔

## 基本信息

| 项目 | 内容 |
|------|------|
| 名号 | 光明主宰·奥瑞尔 |
| 称号 | 光明之源、晨曦之主 |
| 等级 | 主宰（位面最强之一） |
| 属性 | 纯粹光明 |
| 状态 | 轻度污染（向德豪需净化） |
| 家庭 | 生命主宰·盖亚（爱人）、向德豪（儿子） |

## 外貌特征

- **正常形态**：高大金发男子，身穿白色长袍，周身光晕
- **战斗形态**：纯光能量体，双目如日
- **污染后**：光明中带黑气，双目偶尔变暗

## 性格特点

- **光明磊落**：行事光明正大，不屑阴谋
- **温柔爱人**：对盖亚深情，对向德豪愧疚
- **守护者**：守护位面光明，对抗黑暗
- **父爱**：虽送走儿子，但一直守护

## 背景故事

### 诞生
- 位面初开时诞生
- 成为光明主宰
- 统治光明神域

### 与盖亚相爱
- 遇见生命主宰盖亚
- 两人相爱，违反"主宰不近情感"的"规则"
- 诞下向德豪

### 察觉阴谋
- 发现黑暗主宰的异常
- 暗中调查，发现污染计划
- 知道自己也可能被污染

### 送走儿子
- 为保护向德豪
- 与盖亚炼制"玉佩"
- 将婴儿时期的向德豪送往现代世界
- 玉佩戴在婴儿胸口，跟随一起传送
- **无法预知谁会捡到**，只能相信命运的安排
- 约定：玉佩会在向德豪最危险时启动
- 师父在荒山发现婴儿，野兽不敢靠近，觉得邪门
- 师父捡到婴儿，玉佩也一直让他戴着
- **师父不知道异界和主宰之事**，只以为玉佩是某种上古法器

### 被污染
- 长时间对抗黑暗
- 不知不觉被轻度污染
- 但察觉到后自我封印
- 等待儿子归来净化

### 与儿子重逢
- 向德豪觉醒时现身
- 告知真相
- 一起对抗黑暗主宰
- 被儿子净化
- 一家团圆

## 能力设定

### 主宰之力
- **光明领域**：领域内一切黑暗退散
- **光明净化**：净化黑暗污染
- **光明之眼**：看破一切虚妄
- **不死不灭**：光明无处不在

### 父子之力
- 向德豪继承了光明血脉
- 可以父子联手，威力倍增
- 后期向德豪超越父亲

## 人物关系

| 角色 | 关系 | 说明 |

| 向德豪 | 儿子 | 深爱但无奈送走，愧疚 |
| 黑暗主宰 | 宿敌 | 察觉其阴谋，被其污染 |

- "向守一大师，感谢您照顾德豪十八年。"
- "您虽非他生父，但胜似生父。"
- "我们欠您的，永生难忘。"
- "请您继续像父亲一样照顾他。"

## 一家团圆

### 净化后
- 光明与生命主宰被向德豪净化
- 一家三口团聚
- 向守一也在，和谐相处
- 父母感谢师父，师父视如己出

### 日常互动
- 奥瑞尔："德豪，这是光明神域的修炼法..."
- 向德豪："师父教过我赶尸术..."
- 奥瑞尔："..."（内心：赶尸术是什么？）
- 盖亚："各有各的好处嘛。"
