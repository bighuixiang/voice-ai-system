# 将臣——僵尸王

## 基本信息

| 项目 | 内容 |
|------|------|
| 名称 | 将臣 |
| 称号 | 僵尸始祖、万尸之祖 |
| 等级 | 尸神（穿越时）→ 裹尸袋沉睡 → 重见天日 |
| 属性 | 极阴尸气、月之精华 |
| 状态 | 穿越时重伤→被封印裹尸袋→被炼成尸帝 |

## 外貌特征

- **穿越时**：红袍披发，獠牙外露，周身黑煞
- **裹尸袋中**：沉睡状态，尸气内敛
- **认主后**：可作为兵器使用，坚硬如神铁
- **尸帝形态**：帝袍加身，尸帝威压，万尸俯首

## 性格特点

- **高傲**：僵尸之王，不屑与弱者为伍
- **凶残**：嗜血好杀
- **忠诚**：一旦认主，誓死追随
- **傲娇**：对向德豪态度从不屑到依赖

## 背景故事

### 上古时期
- 诞生于上古洪荒
- 吸收日月精华成尸王
- 统率万尸，横行天下

### 沉睡
- 被道术封印千年
- 等待月圆之夜破封

### 现世
- 月圆之夜，天狗食日
- 破封而出，吸收日月精华
- 与向守一大战，同归于尽

### 异界
- 被裹尸袋装着穿越
- 沉睡不知岁月
- 被向德豪滴血认主
- 前期当武器用，中期被炼成尸帝
- 最终与向德豪融合

## 能力设定

### 尸神期（穿越时）
- **尸气爆破**：尸气化形，爆破四方
- **月华吸取**：吸收月亮精华恢复
- **不死不灭**：尸神不灭，极难杀死

### 兵器期（认主后）
- **坚硬无比**：尸神之躯，万法不破
- **尸气加持**：挥动时释放尸气
- **自动护主**：危急时刻自动保护
- **重量变化**：向德豪心意控制重量

### 尸帝期（炼成后）
- **尸帝威压**：震慑万尸，低阶尸直接臣服
- **空间穿梭**：短距离瞬移
- **时光逆流**（小范围）：逆转局部时间
- **尸帝领域**：领域内万尸听令

## 认主细节

### 发现
- 向德豪受伤，血液滴在裹尸袋上
- 裹尸袋发热，血认主完成
- 将臣苏醒，但不敌认主契约
- 被迫臣服，当"兵器"用

### 使用方式
1. **兵器模式**：变成大剑/长枪，挥舞杀敌
2. **护盾模式**：展开保护主人
3. **坐骑模式**：巨大化，骑乘飞行
4. **合体模式**：最终融合，尸帝降临

## 融合设定

### 融合条件
- 向德豪炼体达到神体境
- 将臣被炼成尸帝
- 双方意愿一致
- 月圆之夜，血祭融合

### 融合效果
- **尸帝法神**：向德豪同时拥有尸帝和法神力量
- **万尸听令**：所有僵尸自动臣服
- **不死不灭**：滴血可重生
- **位面之力**：可借用位面之力

### 融合外貌
- 向德豪本体
- 一只眼睛变成血红
- 周身尸帝威压
- 背后浮现将臣虚影
- 手持尸帝剑（将臣化身）

## 有趣细节

1. **傲娇性格**：嘴上不爽，身体很诚实地保护主人
2. **吃醋**：向德豪炼别的尸时会闹脾气
3. **护短**：只有将臣能欺负向德豪，别人不行
4. **吐槽担当**：经常吐槽向德豪的操作
5. **老祖宗架子**：自称"吾"，瞧不起其他僵尸
