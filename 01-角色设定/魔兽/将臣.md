# 将臣——万年冤种僵尸王

## 基本信息

| 项目 | 内容 |
|------|------|
| 名称 | 将臣 |
| 称号 | 僵尸始祖、万尸之祖（自称）、万年冤种（实锤） |
| 等级 | 上古僵尸王→重伤休眠→兵器→尸帝→融合 |
| 属性 | 极阴尸气、月之精华、嘴炮MAX |
| 状态 | 冤种→兵器→打工人→尸帝→本体 |
| 定位 | 搞笑担当、吐槽担当、傲娇兵器、萌宠 |

## 外貌特征

| 形态 | 描述 |
|------|------|
| **破封时** | 红袍披发，獠牙外露，试图装逼但被打 |
| **裹尸袋中** | 沉睡状态，偶尔梦话吐槽 |
| **认主后-平时** | **可爱的小僵尸**（巴掌大小，青绿皮肤，萌萌的，蹲在肩膀上） |

| **尸帝形态** | 帝袍加身，但依然是逗比 |
| **融合后** | 背影像模像样，说话原形毕露 |

## 性格特点

**核心性格：逗比 + 傲娇 + 话痨**

**逗比属性**：
- 内心戏极其丰富，经常自言自语
- 喜欢装逼，但总被打脸
- 对新鲜事物好奇，容易被打岔
- 吐槽犀利，一针见血
- 脑回路清奇，想法天马行空

**傲娇属性**：
- 嘴上"我才不想救你"，身体诚实地护主
- 被夸了会暗爽，但嘴硬不承认
- 吃醋其他僵尸，但说"只是嫌弃它们弱"
- 明明在乎，非要说"才不是担心你"

**话痨属性（压抑千年后爆发）**：
- 战斗时不停吐槽
- 睡觉时说梦话吐槽
- 当兵器时还在吐槽
- 被当成物品时还在吐槽
- **变成小僵尸后继续吐槽**
- 变身时吐槽"别把我变这么丑啊"

## 背景故事

### 上古时期——被冤枉的万年

**诞生**
- 上古洪荒，吸收日月精华自然诞生
- 从未害过人，只是找个地方吸收日月精华修炼
- 修炼枯燥，偶尔下山看戏（就是看热闹，时常引起民众恐慌，流传将臣每隔一段时间就要吸血）
- 因为长得吓人，被人误会成吃人僵尸

**被封印**
- 一群道士找上门，说他要吃人
- 将臣："我没吃过人！"（手向前一伸，嘴巴张开）
- 道士："你看你，手伸过来要抓人，嘴张开要吃人！封印！"
- 将臣："嗷嗷嗷！！！"（内心：我只是想解释啊！）
- 被十八道封印镇压，一睡千年

**无法发声的设定**：
- 本地无法说话，有灵智但只能"嗷嗷嗷"
- 每次想解释，手向前一伸一伸，嘴巴张开
- 道士以为是在挑衅和准备发动攻击
- 所以每次都打得很惨
- 将臣内心："我千年冤啊！"

**内心独白**：
> "我堂堂上古僵尸王，食的是日月精华，这帮道士非说我要吃人。我吃过吗？没有！我只是长得不帅而已...不对，我也挺帅的啊？为什么被冤枉？而且为什么我说不出话来？只能嗷嗷嗷的？!"

### 现代部分——刚醒又睡

**破封**
- 千年等待，终于等到月圆之夜
- 天狗食日，绝佳突破时机
- 破封而出，准备装个逼
- 刚说了一句"吾乃将臣"，就被师父打断
- 还没来得及吸收日月精华，就被打了

**大战**
- 本想速战速决，结果发现师父挺能打
- "嗷嗷嗷！"（手下向师父，表示想好好聊聊）
- 师父："你这只僵尸王还挺嚣张！"
- 将臣："嗷...嗷..."（内心：我只是在打招呼啊）
- 准备放大招，玉佩突然搞事
- 空间扭曲，被打包带走

**内心独白**：
> "我睡了千年，刚醒，还没吸够日月精华，就要打架？我招谁惹谁了？而且为什么我还是说不出人话？只能嗷嗷嗷？那老道士还以为我在挑衅！还有那玉佩什么鬼？我上古僵尸王的脸面啊！"

### 异界部分——打工生涯

**沉睡**
- 裹尸袋里黑漆漆的
- 一睡不知多少年
- 梦里还在吐槽被冤枉的事

**认主过程**（魔兽岭）
- 向德豪穿越到魔兽岭，被初阶魔兽袭击
- 用炼尸大典炼体方式战斗，受伤
- 鲜血滴到裹尸袋，激活了裹尸袋
- 向德豪感应到里面有两具"尸体"
- 发现将臣：青面獠牙，沉睡中，看起来很可怕
- 向德豪想到将臣不死不灭，身体结实
- 把将臣拿出来当武器砸魔兽
- 过程中鲜血滴到将臣眉心
- **血契绑定，被迫认主**

**认主后的第一次对话**
- 将臣苏醒，发现自己能说话了
- 将臣："吾乃将臣，万尸之——等等，你能听见我说话？！"
- 向德豪："你能说话？"
- 将臣："千年了！终于能说话了！你知道我有多憋屈吗？"
- 向德豪："从今天起，你就是我的兵器了。"
- 将臣："...等等，剧本不对吧？而且...为什么我变成了这么个小东西？"

**打工人阶段**
- 发现一荣俱荣，一损俱损
- 主人死了自己也要挂
- "行吧，打工就打工，至少活着"
- 被当成兵器使用
- 每天被挥来挥去
- "我堂堂上古僵尸王，沦落到当兵器？我的尸生啊..."
- 变身时吐槽："别把我变这么丑啊！"

**逐渐适应**
- 发现当兵器也挺好，不用自己动脑
- 主人虽然菜，但对自己还行
- 偶尔还能吐槽几句
- "算了，这小子顺眼多了"
- 从被动接受到主动护主
- 平时变成小僵尸蹲在肩膀上卖萌
- 打架时秒变武器，战斗结束变回萌宠

**炼成尸帝**
- "终于不用当兵器了！"
- "等等，还是要融合？"
- "算了，这小子值得"
- 融合时还在吐槽："你轻点啊，我这是第一次..."

## 能力设定

### 上古僵尸王期（穿越时）
- **尸气爆破**：尸气化形，爆破四方
- **月华吸取**：吸收月亮精华恢复
- **不死不灭**：上古僵尸王不灭，极难杀死
- **无法发声**：只能嗷嗷嗷，手向前伸想解释

### 认主后-平时形态
- **可爱小僵尸**：巴掌大小，萌萌的外表
- **肩膀宠物**：蹲在向德豪肩膀上
- **话痨吐槽**：外表可爱，嘴巴毒舌
- **内心戏丰富**：继续当吐槽担当

### 认主后-战斗形态
- **随意变形**：可变成任意武器（剑、刀、枪、锤等）
- **坚硬无比**：上古僵尸王之躯，万法不破
- **尸气加持**：挥动时释放尸气
- **自动护主**：危急时刻自动保护（嘴上说"我才不想"）
- **重量变化**：向德豪心意控制重量
- **吐槽功能**：当兵器时不停吐槽
- **变身吐槽**："别把我变这么丑啊！"

### 尸帝期（炼成后）
- **尸帝威压**：震慑万尸，低阶尸直接臣服
- **空间穿梭**：短距离瞬移
- **时光逆流**（小范围）：逆转局部时间
- **尸帝领域**：领域内万尸听令
- **依然话痨**：当尸帝也忍不住吐槽

## 契约设定

### 血契绑定
- **一荣俱荣**：主人实力提升，将臣实力提升
- **一损俱损**：主人受伤，将臣也会痛
- **寿元共享**：主人活得久，将臣就能活得更久
- **距离限制**：离太远会虚弱，必须跟着主人

## 搞笑小习惯

1. **睡觉说梦话**：被冤枉的事念叨了一千年
2. **当兵器时还会打哈欠**：是的，兵器会打哈欠
3. **战斗中聊天**：一边打一边吐槽对手
4. **偷看八卦**：经常偷听向德豪和伊莎贝拉对话
5. **给自己起外号**：上古僵尸王、尸帝、本大爷、老子...
6. **看热闹不嫌事大**：有热闹必看，边看边吐槽
7. **记仇**：谁打过他，记得一清二楚
8. **记恩**：谁对他好，也记得一清二楚
9. **卖萌**：变成小僵尸后偶尔会卖萌，但马上就吐槽自己
10. **变身吐槽**：每次变身都要吐槽一下"别把我变这么丑"

## 角色定位

**队伍中的角色**：
- 搞笑担当：负责插科打诨
- 吐槽担当：毒舌点评一切
- 战力担当：后期实力强劲
- 智囊担当：有时候会有意外的好主意
- 暖心担当：嘴上不饶人，行动很护主
- 萌宠担当：平时是可爱小僵尸

**与其他角色的互动**：
- 向德豪：损友 + 兄弟 + 一体
- 伊莎贝拉：八卦搭档 + 吐槽对象
- 现代师父：心心念念的对手（想再打一次）
- 小伙伴们：老大哥姿态，喜欢调侃他们
- 敌人们：嘲讽拉满，实力打脸
