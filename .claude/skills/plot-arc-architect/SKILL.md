# Plot Arc Architect

Use this skill to design plot structure before drafting.

## Inputs To Check

Read the highest-level plan first:

- `02-故事大纲/主线剧情/整体规划.md`
- `02-故事大纲/主线剧情/整体规划_优化版v1.md` if relevant
- `05-事件年表/时间线.md`
- relevant world and character files

## Planning Frame

For each arc or chapter group, define:

- external goal: what the protagonist is trying to do
- pressure: what blocks him now
- escalation: what gets worse
- character change: what belief, bond, or wound shifts
-爽点/payoff: what reader reward lands
- cost: what is lost, damaged, or delayed
- hook: why the reader turns the page

## Guardrails

Preserve established endgame unless the user asks to re-plan it. Do not solve every problem in the same arc; leave pressure for future payoff.
