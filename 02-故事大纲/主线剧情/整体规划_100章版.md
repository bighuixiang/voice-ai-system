# 《魔道尸祖：我带着僵尸王勇闯异界》- 小说大纲（100章完整版）

## 一句话简介

湘西赶尸传人穿越魔法世界，以东方尸道对抗西方黑暗，终成位面之主复活所爱。

---

## 核心设定

### 世界观

| 设定 | 内容 |
|------|------|
| **现代世界** | 湘西赶尸派隐世传承，等待僵尸王将臣现世 |
| **异界** | 艾兰大陆，魔法与神格体系，至高神与主宰并存 |
| **黑暗阴谋** | 黑暗主宰万年布局，通过黑死气污染所有主宰 |
| **时间偏移** | 异界千年 ≈ 蓝星18年，穿越时空乱流导致 |

### 黑暗污染设定（优化版）

| 阶段 | 症状 | 表现 |
|------|------|------|
| 初期 | 脑海中的声音 | 偶尔听到一丝丝声音，不知不觉影响心智 |
| 中期 | 心智被控制 | 变成散发黑气的行尸走肉 |
| 后期 | 爆炸传染 | 方圆十里无一幸免，成为新感染源 |

### 主角身世

| 身份 | 说明 |
|------|------|
| **表面身份** | 湘西赶尸派第37代传人，18岁孤儿 |
| **真实身份** | 光明主宰与生命主宰之子（主宰之子） |
| **穿越原因** | 千年前父母为保护婴儿，炼制玉佩送走；18岁时濒死触发玉佩传送 |
| **时间偏移** | 父母等了千年（异界时间），主角才18岁（蓝星时间） |
| **父母状态** | 一直在抵御黑暗侵袭，靠规则之力勉强抵抗 |

### 独特力量体系

| 力量 | 来源 | 表现 |
|------|------|------|
| **道法炼体** | 湘西赶尸派 | 主体系，炼体是核心，炼尸是技能 |
| **西方魔法** | 主宰血脉 | 副体系，天生魔素亲和，魔量巨大，瞬发无咒 |
| **魔尸双修** | 主宰血脉 | 尸气与魔素完美融合 |
| **炼尸大典** | 赶尸派秘籍 | 自带净化之力，到异界后得到魔素强化 |
| **八卦道袍** | 祖传宝物 | 自动防护，净化污染 |
| **玉佩** | 父母炼制 | **穿越后融入体内**，封存海量主宰之力逐步解锁 |

## 六卷结构（100章）

### 第一卷：穿越前夕（1-8章）

**核心事件**：现代日常、师徒羁绊、将臣破封、穿越异界

**章节扩展**：从5章扩展到8章，增加现代世界生活细节，让师徒感情更深厚

#### 第1章：湘西赶尸派

**场景：赶尸派日常**
```
湘西深山，一座古朴的道观。
这是第37代传人向德豪的家。

向德豪在后院练剑。
金钱剑在他手中舞动，剑气四溢。
师父向守一坐在一旁，捋着胡须微笑。

"德豪，你的剑法又精进了。"
向德豪收剑，擦汗："都是师父教得好。"

师父摇头："不，是你自己努力。"
"你是我见过最有天赋的弟子。"
"假以时日，定能超越为师。"

向德豪坐下，给师父倒茶。
"师父，您总说将臣是僵尸王..."
"它...真的存在吗？"

师父眼神变得深邃。
"存在。"
"而且...它很快就会现世。"
"我们向家世代等待，就是为了这一天。"

向德豪："那...现世之后呢？"
师父："降服它，或者...被它降服。"

【将臣传说铺垫】
师父讲述将臣的传说：
上古洪荒，吸收日月精华诞生
统率万尸，横行天下
被道术封印，等待月圆破封
```

#### 第2章：山中岁月

**场景：师徒日常**
```
清晨，向德豪随师父练功。
站桩吐纳，吸收月之精华。

师父："炼尸先炼己，己强方可炼尸。"
"这句话，你要记住。"

向德豪点头："弟子记住了。"

白天，学习道术。
画符、念咒、炼丹、炼器。
师父倾囊相授，向德豪勤学苦练。

晚上，师徒俩坐在院子里看星星。
向德豪："师父，您收了我之后，"
"就没有想过...成家吗？"

师父笑了："我？"
"有你就够了。"
"你是我捡来的，也是我养大的。"
"对我来说，你就是家人。"

向德豪眼眶湿润。
师父拍拍他的肩膀。
"傻孩子，哭什么。"
"为师还打算看你长大，"
"看你超越我，"
"看你成为真正的赶尸传人。"

【师徒情深铺垫】
这一章展示师徒如父如子的关系
为后续重逢和牺牲埋下情感伏笔
```

#### 第3章：铜尸大成

**场景：突破境界**
```
向德豪闭关炼尸。
这次他炼制的是一具武者的尸体。
武者生前意志坚定，是炼制铜尸的好材料。

四十九天。
向德豪全程守在旁边，不断注入尸气。
将臣的传闻在脑海里浮现——

师父说，将臣是最强的僵尸王。
如果能降服它，自己的实力将大增。
但也可能...被它吃掉。

"不管怎样，我都要试一试。"
向德豪咬牙坚持。

终于，第四十九天夜里。
尸体表面泛起铜光。
铜尸，炼成了！

师父走进来，欣慰地点头。
"好，很好。"
"十八岁就能炼成铜尸，"
"你是历代弟子中最优秀的。"

向德豪："师父，我还差得远。"
师父："不，你已经很优秀了。"
"但记住，越优秀，责任越大。"
"将来如果将臣现世..."
"你，就是对抗它的主力。"
```

#### 第4章：月圆之夜

**场景：将臣破封**
```
月圆之夜。
湘西深山，阴气最盛的时候。

向德豪和师父在山顶等待。
他们感应到了——
将臣，要破封了。

大地开始颤抖。
黑色的雾气从地下涌出。
一个高大的身影缓缓浮现。

"桀桀桀..."
"我，将臣，终于出来了！"
"千年了...你们这些该死的道士，"
"竟然封印了我整整千年！"

师父脸色凝重。
"德豪，退后。"
"这不是你能对付的。"

向德豪摇头："师父，我不走。"
"我们师徒二人，联手！"

师父看着徒弟，眼中闪过一丝欣慰。
"好，那就联手！"

【大战开启】
师徒大战将臣，场面激烈
道术与尸气碰撞，日月无光
```

#### 第5章：天狗食日

**场景：穿越开始**
```
战斗中，异变突生。
天空出现日食，天狗食月。

三股力量在空中碰撞——
师父的道术
将臣的尸气
向德豪玉佩中的光明之力

空间开始扭曲。
"不好！是空间裂缝！"
师父大喊。

但已经来不及了。
三股能量引发的空间波动，
将三人同时吸入。

向德豪在最后一刻看到——
师父被吸入另一股漩涡。
将臣被吸入裹尸袋。

"师父！！！"
向德豪伸手去抓，
但只抓到一片虚空。

玉佩在他胸口发出耀眼的光芒。
那是父母留下的最后保护——
空间传送。
```

#### 第6章：异界苏醒

**场景：新世界**
```
向德豪醒来。
陌生的天空，陌生的气息。

"这是...哪里？"
他爬起来，环顾四周。
一片森林，但不是他熟悉的森林。
空气中弥漫着一种奇怪的能量。

"这是...魔素？"
他脑海中冒出这个词。
但他从未学过魔法，
怎么会知道？

玉佩已经消失不见。
取而代之的，是胸口的一股暖流。
"玉佩...融合了？"

将臣在裹尸袋里沉睡。
向德豪不知道，这只僵尸王，
会成为他异界之旅的最大助力。

【异界初印象】
向德豪探索周围环境
发现这里的能量比蓝星浓郁百倍
```

#### 第7章：初遇魔兽

**场景：第一战**
```
一只野兽向向德豪扑来。
不是普通的狼，是...魔狼！

向德豪掏出金钱剑。
炼体法门开启。
尸气与魔素融合——

他惊异地发现，
自己的力量比在蓝星时强了数倍！
"这里的能量...真的不一样！"

一剑。
魔狼倒地。
向德豪从魔狼体内取出一块发光的晶体。
"这是...魔晶？"

【将臣苏醒】
向德豪的血滴在裹尸袋上。
将臣的气息浮现。
"小家伙，你醒了？"

一个声音在他脑海里响起。
"本大爷...是谁？"
"你...又是谁？"

向德豪震惊："僵尸王...会说话？！"
```

#### 第8章：血滴认主

**场景：将臣认主**
```
将臣的声音继续：
"本大爷不是会说话。"
"是你在和本大爷...心灵沟通。"
"还有，你的血...有特殊的味道。"

向德豪："什么味道？"
将臣："光明与生命...两种主宰之力？"
"有意思，有意思。"
"你这个小家伙，来头不小啊。"

向德豪："你...到底是谁？"
将臣："本大爷叫将臣。"
"上古僵尸王，万尸之祖。"
"不过现在...很弱。"
"被你小子血滴认主，只好认栽了。"

向德豪："血滴认主？"
将臣："就是字面意思。"
"你滴血在本大爷的...尸气上。"
"从此以后，本大爷就是你的...兵器？"
"不对，应该是伙伴。"

向德豪笑了。
"伙伴？听起来不错。"

【伙伴关系建立】
将臣成为向德豪的第一个伙伴
虽然嘴上不饶人，但已经认主
```
