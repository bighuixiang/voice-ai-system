### 八、写作风格统一指南（四不原则）

```
┌─────────────────────────────────────────────────────────────┐
│                  四不原则                                    │
├─────────────────────────────────────────────────────────────┤
│  1. Show, Don't Tell（展示而非讲述）                        │
│     → 用动作/细节表达情感，不要直接贴标签                    │
│     → ❌ "他哭了一整夜" → ✅ "他坐在崖边，从天黑坐到天明"     │
│                                                             │
│  2. 不滥用省略号                                            │
│     → 用动作代替"......"                                     │
│     → ❌ "师父......" → ✅ 师父拍了拍他的背："好了，好了..." │
│                                                             │
│  3. 不过度煽情                                              │
│     → 最悲伤的时候往往是无声的                              │
│     → ❌ "师父——！！" → ✅ 握着师父的手，眼泪滴落            │
│                                                             │
│  4. 不使用网络用语                                          │
│     → 使用符合世界观的语言                                  │
│     → ❌ "高端操作" → ✅ "精妙的战术"                       │
└─────────────────────────────────────────────────────────────┘
```
