# 《魔道尸祖：我带着僵尸王勇闯异界》- 小说大纲（完整版v3）

## 一句话简介

湘西赶尸传人穿越魔法世界，以东方尸道对抗西方黑暗，终成位面之主复活所爱。

---

## 核心设定

### 世界观

| 设定 | 内容 |
|------|------|
| **现代世界** | 湘西赶尸派隐世传承，等待僵尸王将臣现世 |
| **异界** | 艾兰大陆，魔法与神格体系，至高神与主宰并存 |
| **黑暗阴谋** | 黑暗主宰万年布局，通过黑死气污染所有主宰 |
| **时间偏移** | 异界千年 ≈ 蓝星18年，穿越时空乱流导致 |

### 黑暗污染设定（优化版）

| 阶段 | 症状 | 表现 |
|------|------|------|
| 初期 | 脑海中的声音 | 偶尔听到一丝丝声音，不知不觉影响心智 |
| 中期 | 心智被控制 | 变成散发黑气的行尸走肉 |
| 后期 | 爆炸传染 | 方圆十里无一幸免，成为新感染源 |

**传播途径**：
- 空间裂缝（主要途径）
- 神格传播
- 直接接触
- 间接传播
- 环境侵蚀

**下界保护**：有位面规则保护，黑暗主宰无法直接降临，侵蚀速度较慢

**神界现状**：
- 四大主宰：光明/生命靠规则之力勉强抵抗（轻度污染）
- 其他主宰（火、水、冰、风、雷、土）：已被污染，成为敌人
- 至高神：大部分已被暗中污染
- 危局：整个神界处于崩溃边缘

### 主角身世

| 身份 | 说明 |
|------|------|
| **表面身份** | 湘西赶尸派第37代传人，18岁孤儿 |
| **真实身份** | 光明主宰与生命主宰之子（主宰之子） |
| **穿越原因** | 千年前父母为保护婴儿，炼制玉佩送走；18岁时濒死触发玉佩传送 |
| **时间偏移** | 父母等了千年（异界时间），主角才18岁（蓝星时间） |
| **父母状态** | 一直在抵御黑暗侵袭，靠规则之力勉强抵抗 |

### 独特力量体系

| 力量 | 来源 | 表现 |
|------|------|------|
| **道法炼体** | 湘西赶尸派 | 主体系，炼体是核心，炼尸是技能 |
| **西方魔法** | 主宰血脉 | 副体系，天生魔素亲和，魔量巨大，瞬发无咒 |
| **魔尸双修** | 主宰血脉 | 尸气与魔素完美融合 |
| **炼尸大典** | 赶尸派秘籍 | 自带净化之力，到异界后得到魔素强化 |
| **八卦道袍** | 祖传宝物 | 自动防护，净化污染 |
| **玉佩** | 父母炼制 | **穿越后融入体内**，封存海量主宰之力逐步解锁 |

### 快速晋级原因

| 来源 | 说明 |
|------|------|
| 玉佩 | 父母封存的海量主宰之力，随境界提升逐步解锁 |
| 炼尸大典 | 异界魔素持续强化，炼制效率大幅提升 |
| 将臣吸收 | 将臣天然吸收魔素，实力快速恢复 |
| 主宰血脉 | 天赋卓绝，修炼速度是常人的十倍 |
| 双道同修 | 尸气与魔素完美融合，相互促进 |

### 击败黑暗主宰的关键

**炼体练到极致**：
- 向德豪炼体练到神体境，肉身成圣
- 可硬抗黑暗主宰的致命一击
- 近身肉搏，斩杀黑暗主宰
- 这是他能击败黑暗主宰的核心原因

## 六卷结构（69章）

### 第一卷：穿越前夕（1-5章）

**核心事件**：师父与将臣大战，三人穿越失散，异界苏醒遇险

**故事梗概**：
湘西赶尸派第37代传人向德豪，18岁炼成铜尸。月圆之夜，僵尸王将臣现世，师父与将臣展开生死对决。天狗食日，三方能量碰撞，濒死的向德豪触发玉佩传送，三人被传送到异界不同位置。向德豪在魔兽岭苏醒，遭遇魔兽袭击，血滴认主将臣。王级魔兽暴动引来星辰学院院长伊莎贝拉（调查魔兽异动），皇级魔兽出现，伊莎贝拉重伤，向德豪背着院长逃离。

**关键场景**：
- 第1章：月圆之夜，将臣破封
- 第2章：天狗食日，三方能量碰撞，空间扭曲
- 第3章：异界苏醒，击杀初阶魔兽（主角高光），血滴认主将臣
- 第4章：王级魔兽暴动，伊莎贝拉救场（调查魔兽异动），皇级魔兽出现，主角背着院长逃离
- 第5章：洞穴独处，建立师徒关系，前往学院

**情感铺垫**：
- 向德豪对师父的依赖（从小相依为命）
- 师父对向德豪的保护欲（"德豪，退后"）
- 穿越前的最后一个眼神交流
- 异界与伊莎贝拉的初次相遇（互相救赎）

向德豪随伊莎贝拉进入星辰魔法学院，正式成为她的弟子。学院生活中展现惊人的魔尸双修天赋，遭遇学院歧视但当场打脸。结识热血室友弗拉姆、温柔治疗师格蕾丝、正义剑士凯尔，以及被帝国三王子纠缠的校花索菲亚。
