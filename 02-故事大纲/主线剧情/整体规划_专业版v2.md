# 《魔道尸祖：我带着僵尸王勇闯异界》- 小说大纲（完整版v3）

## 一句话简介

湘西赶尸传人穿越魔法世界，以东方尸道对抗西方黑暗，终成位面之主复活所爱。

---

## 核心设定

### 世界观

| 设定 | 内容 |
|------|------|
| **现代世界** | 湘西赶尸派隐世传承，等待僵尸王将臣现世 |
| **异界** | 艾兰大陆，魔法与神格体系，至高神与主宰并存 |
| **黑暗阴谋** | 黑暗主宰万年布局，通过黑死气污染所有主宰 |
| **时间偏移** | 异界千年 ≈ 蓝星18年，穿越时空乱流导致 |

### 黑暗污染设定（优化版）

| 阶段 | 症状 | 表现 |
|------|------|------|
| 初期 | 脑海中的声音 | 偶尔听到一丝丝声音，不知不觉影响心智 |
| 中期 | 心智被控制 | 变成散发黑气的行尸走肉 |
| 后期 | 爆炸传染 | 方圆十里无一幸免，成为新感染源 |

**传播途径**：
- 空间裂缝（主要途径）
- 神格传播
- 直接接触
- 间接传播
- 环境侵蚀

**下界保护**：有位面规则保护，黑暗主宰无法直接降临，侵蚀速度较慢

**神界现状**：
- 四大主宰：光明/生命靠规则之力勉强抵抗（轻度污染）
- 其他主宰（火、水、冰、风、雷、土）：已被污染，成为敌人
- 至高神：大部分已被暗中污染
- 危局：整个神界处于崩溃边缘

### 主角身世

| 身份 | 说明 |
|------|------|
| **表面身份** | 湘西赶尸派第37代传人，18岁孤儿 |
| **真实身份** | 光明主宰与生命主宰之子（主宰之子） |
| **穿越原因** | 千年前父母为保护婴儿，炼制玉佩送走；18岁时濒死触发玉佩传送 |
| **时间偏移** | 父母等了千年（异界时间），主角才18岁（蓝星时间） |
| **父母状态** | 一直在抵御黑暗侵袭，靠规则之力勉强抵抗 |

### 独特力量体系

| 力量 | 来源 | 表现 |
|------|------|------|
| **道法炼体** | 湘西赶尸派 | 主体系，炼体是核心，炼尸是技能 |
| **西方魔法** | 主宰血脉 | 副体系，天生魔素亲和，魔量巨大，瞬发无咒 |
| **魔尸双修** | 主宰血脉 | 尸气与魔素完美融合 |
| **炼尸大典** | 赶尸派秘籍 | 自带净化之力，到异界后得到魔素强化 |
| **八卦道袍** | 祖传宝物 | 自动防护，净化污染 |
| **玉佩** | 父母炼制 | **穿越后融入体内**，封存海量主宰之力逐步解锁 |

### 快速晋级原因

| 来源 | 说明 |
|------|------|
| 玉佩 | 父母封存的海量主宰之力，随境界提升逐步解锁 |
| 炼尸大典 | 异界魔素持续强化，炼制效率大幅提升 |
| 将臣吸收 | 将臣天然吸收魔素，实力快速恢复 |
| 主宰血脉 | 天赋卓绝，修炼速度是常人的十倍 |
| 双道同修 | 尸气与魔素完美融合，相互促进 |

### 击败黑暗主宰的关键

**炼体练到极致**：
- 向德豪炼体练到神体境，肉身成圣
- 可硬抗黑暗主宰的致命一击
- 近身肉搏，斩杀黑暗主宰
- 这是他能击败黑暗主宰的核心原因

## 六卷结构（69章）

### 第一卷：穿越前夕（1-4章）

**核心事件**：师父与将臣大战，三人穿越失散

**故事梗概**：
湘西赶尸派第37代传人向德豪，18岁炼成铜尸。月圆之夜，僵尸王将臣现世，师父与将臣展开生死对决。天狗食日，三方能量碰撞，濒死的向德豪触发玉佩传送，三人被传送到异界不同位置。

**关键场景**：
- 第1章：月圆之夜，将臣破封
- 第2章：师父备战，传授护身符咒
- 第3章：天狗食日，三方正对
- 第4章：玉佩发光，空间扭曲

**情感铺垫**：
- 向德豪对师父的依赖（从小相依为命）
- 师父对向德豪的保护欲（"德豪，退后"）
- 穿越前的最后一个眼神交流

### 第二卷：异界求生（5-13章）

**核心事件**：孤身异界，发现将臣认主，师父失踪

**故事梗概**：
向德豪在魔兽岭边缘独自醒来，身边只有金钱剑、炼尸大典、八卦道袍、裹尸袋。滴血认主后，发现袋子里只有僵尸王将臣，师父下落不明。将臣被迫认主，变形成可爱小僵尸依附向德豪。

**第8章：师父失踪**（无声的悲伤）
```
向德豪打开裹尸袋，发现只有将臣。
他没有哭，没有喊，只是静静看着空荡荡的袋子。
将臣："那老道士应该也穿越来了...不过不在袋子里"
向德豪没有回应，只是默默系紧裹尸袋的绳结。
那天晚上，他坐在崖边，裹尸袋放在膝盖上，从天黑坐到天明。
第二天起，他的眼神变了。
```

**第9章：将臣发现魔素**（实力暴涨）
```
将臣从沉睡中苏醒，感应到周围的环境。
将臣（内心）："这里是什么地方？空气中的能量...怎么这么浓郁？"
（尝试吸收周围魔素）
将臣（震惊）："卧槽？！这是什么能量？比日月精华浓郁万倍啊！"
（实力快速恢复，伤势迅速愈合）
将臣："哈哈！恢复得差不多了！小家伙，本大爷罩着你！"
向德豪："你能说话？"
将臣："废话！本大爷是上古僵尸王，怎么会不能说话？倒是你，这什么地方？"
向德豪："异界。"
将臣："异界？管他什么界，有能量就行！"
```

**第10-12章：魔兽岭历练**
- 向德豪在魔兽岭边缘求生
- 将臣吸收魔素，实力快速恢复

**第13章：伊莎贝拉救场**（双女主线开启）

## 情感表达原则

### 去掉的内容
- ❌ "我发誓要复活你"之类的直白台词
- ❌ 频繁的"泪流满面""相拥而泣"
- ❌ 省略号过多的对话
- ❌ 重复的情感宣泄

### 替代方案

| 原表达 | 新表达 |
|--------|--------|
| "我发誓要复活师父" | 每天夜里都要摸一摸裹尸袋 |

## 黑暗污染详细设定

### 污染症状

| 阶段 | 症状 | 表现 |

### 被污染者

| 类型 | 状态 |
|------|------|
| 其他主宰 | 火、水、冰、风、雷、土等主宰已被污染，成为敌人 |

- 中后期主要敌人
- 主角需要击败并净化他们
- 净化后恢复神智，成为盟友

- 收割所有黑死气
- 成就位面之主（主宰之上的境界）
- 成为位面唯一的统治者
