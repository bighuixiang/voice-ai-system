## 第176-177章：师父的复活（2章）

**【场景：向德豪的修炼室】**

```

```

**【场景：复活仪式】**

```

"师父...醒来吧！"

涌入师父的身体。

时间一分一秒过去。

一滴滴。
```

---

**【章末悬念】**

向德豪握着师父的手。

```

## 复活分量感的五个原则

### 1. 不能"秒复活"

每个角色至少1章，重要角色2-3章。
师父2章、格蕾丝1章、凯尔1章、弗拉姆2章、艾米莉亚2章。

### 2. 要有"代价"

用炼尸大典炼制的高品质尸体抵消复活代价。
需要大量时间准备和材料收集。

### 3. 要有"等待"

读者等待了很久（小伙伴在第81-95章牺牲，复活在第176-193章）。
这个等待本身就有分量。

### 4. 要有"情感闭环"

每个角色复活后，要有之前的伏笔回收。
- 师父："我找到您了"
- 格蕾丝："我喜欢你"
- 弗拉姆："不见不散"
- 艾米莉亚："嘿嘿...没念错..."

### 5. 不能"复活一切"

艾米莉亚只能转世，不能原身复活。
这增加了庄重感。

## 写作技巧

### 展示而非讲述

**【错误示范】**
```
向德豪复活了师父。
```

**【正确示范】**
```
向德豪握着师父的手。
眼泪滴落在师父的手背上。

"师父...求您了..."
"醒醒吧..."
"我...我还没来得及...告诉您..."

"我...我想您..."
"我...很想您..."

师父的手指...微微动了。

向德豪的心跳加速。

"师父...？"

师父的眼睛...缓缓睁开。

"德...豪...？"

向德豪的眼泪瞬间流下。
"师父——！"
```
