# 《魔道尸祖：我带着僵尸王勇闯异界》 - 编写指南

## 文档说明

本文档是《尸帝魔尊》的小说编写指南，规定了情感表达、对话优化、场景描写等核心写作原则，用于指导后续章节创作，避免AI味、口水文，保持小说质感。

---

## 一、核心写作原则

### 1.1 情感表达原则

**核心理念**：Show, Don't Tell（展示而非讲述）

| 禁止 | 推荐 |
|------|------|
| 直白煽情 | 细节暗示 |
| 长篇独白 | 动作描写 |
| 口头发誓 | 默默行动 |
| 泪流满面 | 一个眼神 |
| "我发誓..." | 从天黑坐到天明 |

---

### 1.2 对话优化原则

**核心理念**：少而精，每句话都有意义

| 禁止 | 推荐 |
|------|------|
| 过多省略号"..." | 用动作代替停顿 |
| 重复的情感宣泄 | 一次表达，就够了 |
| 网络用语 | 符合世界观的语言 |
| 直白的"我喜欢你" | 含蓄的暗示和留白 |
| 说明性对话 | 推动情节的对话 |

---

### 1.3 去AI味原则

| AI味特征 | 去除方法 |
|----------|----------|
| 频繁的省略号 | 删除或用动作代替 |
| 过多的感叹号 | 平静地表达激烈情感 |
| 直白的情感标签 | 用场景和细节暗示 |
| 重复的套路 | 每次情感表达要有新意 |
| 话说三分 | 留白七分 |

## 二、情感表达技巧

### 2.1 无声的悲伤（核心技巧）

**原则**：最悲伤的时候，往往是无声的。

#### 技巧1：用动作代替语言

```
❌ 错误示范：
"师父！！！我终于找到您了！！！"向德豪大喊。
"德豪...你长大了..."师父流泪。
两人抱头痛哭。

✅ 正确示范：
向德豪冲向师父。
师徒对视。
向德豪的手在颤抖。
师父："德豪...？"
向德豪终于开口："师父...我...我终于找到您了..."
师父拍着他的背："好了，好了...师父在..."
向德豪的眼泪终于流了下来。
```

#### 技巧2：用道具承载情感

```
❌ 错误示范：
向德豪看着弗拉姆牺牲的地方，心中悲痛万分。
"我一定会复活你的！"他大喊。

✅ 正确示范：
战斗结束后，向德豪来到焦土前。
蹲下，捡起一块烧焦的护身符。
那是弗拉姆送他的生日礼物。
他没有说话，只是把符咒收进怀里。
转身，继续炼尸。
```

#### 技巧3：用时间流逝体现悲伤

```
❌ 错误示范：
向德豪发现师父不在袋子里，非常伤心。
他哭了一整夜，发誓一定要找到师父。

✅ 正确示范：
向德豪打开裹尸袋，发现只有将臣。
他没有哭，没有喊，只是静静看着空荡荡的袋子。
那天晚上，他坐在崖边，裹尸袋放在膝盖上。
从天黑坐到天明。
第二天起，他的眼神变了。
```

---

### 2.2 情感递进原则

**原则**：情感要有层次，不能一次性宣泄完毕。

#### 层次设计

| 层次 | 表达方式 | 示例 |
|------|----------|------|
| 第一层 | 压抑 | 默默忍受，不发一言 |
| 第二层 | 细节 | 手抖、眼神变化、动作停顿 |
| 第三层 | 爆发 | 一句话，一个动作 |
| 第四层 | 后续影响 | 行为改变，性格变化 |

#### 示例：弗拉姆牺牲

```
层次1（压抑）：
向德豪看着火焰，没有说话。

层次2（细节）：
他的手在颤抖。
握着炼尸大典的指节发白。

层次3（爆发）：
他没有大喊。
只是继续炼尸。
一具接一具，不知疲倦。

层次4（后续）：
战斗结束后，他捡起弗拉姆的护身符。
从那天起，他的眼神变得冰冷。
```

---

### 2.3 留白艺术

**原则**：不说出来的，往往更有力量。

#### 技巧1：用沉默表达震撼

```
❌ 错误示范：
凯尔："德豪，你要好好活下去！我会想你的！"
然后他牺牲了。

✅ 正确示范：
凯尔："德豪...带大家走。"
向德豪不肯。
凯尔："德豪...记住...剑是用来...保护人的..."
然后他转身冲向敌军。
向德豪握紧拳头，指节发白。
但他没有回头。
因为他知道凯尔要的，是他活下去。
```

#### 技巧2：用留白引发想象

```
❌ 错误示范：
格蕾丝看着向德豪，心中充满不舍。
她想说"我爱你"，但说不出口。
最后她说："只要你...能活下去..."

✅ 正确示范：
格蕾丝挡在最前面。
燃烧生命之力，展开绝对防护。
她回头看了向德豪一眼。
那个眼神里有歉意，有不舍，还有...
然后是光芒绽放。
向德豪没有喊她的名字。
他只是静静看着。
光芒消散后，他走上前。
捡起格蕾丝掉落的法杖。
法杖上还残留着她的体温。
```

## 三、对话优化指南

### 3.1 对话简洁原则

**原则**：能用一个字，不用两个字；能用一句话，不用两句话。

#### 优化示例

| 场景 | 冗长版 | 简洁版 |
|------|--------|--------|
| 师徒重逢 | "师父！！！我终于找到您了！！！" | "师父..."（颤抖的手） |
| 拒绝 | "我真的很不喜欢你，请你不要再纠缠我了" | "我不喜欢你。"（平静） |
| 确认 | "我是认真的，我说的都是真心话" | "那...如果我说，我不想只是骗人呢？" |
| 感谢 | "非常感谢你，你对我的恩情我永远不会忘记" | 一个眼神，一个点头 |

---

### 3.2 对话差异化原则

**原则**：每个角色的对话风格应该不同。

#### 角色对话风格

| 角色 | 风格 | 示例 |
|------|------|------|
| 向德豪 | 简短、内敛、行动派 | "我去做。" |
| 师父 | 威严、温和、长辈感 | "好了，好了..." |
| 伊莎贝拉 | 成熟、理性、偶尔毒舌 | "就这？" |
| 索菲亚 | 直球、活泼、有点傲娇 | "那...如果我说..." |
| 弗拉姆 | 热血、直率、兄弟情 | "兄弟，这事交给我！" |
| 格蕾丝 | 温柔、害羞、内心细腻 | "小心点..." |
| 凯尔 | 正义、沉稳、话少 | "保护...大家..." |
| 将臣 | 话痨、吐槽、毒舌 | "弱！太弱了！" |

---

### 3.3 省略号使用规范

**禁止滥用的场景**：
- ❌ 用省略号代替动作描写
- ❌ 用省略号表示情绪波动
- ❌ 连续使用省略号...

**可以使用但需谨慎的场景**：
- ✅ 说话停顿思考（不超过一次）
- ✅ 欲言又止（用动作配合）
- ✅ 故意隐瞒（语境明确）

#### 优化示例

```
❌ 错误（滥用省略号）：
向德豪："师父...您在哪里......我好担心您......"
将臣："这...这是什么情况......"

✅ 正确（动作代替）：
向德豪系紧裹尸袋的绳结。
向德豪："师父。"
将臣挑眉。

❌ 错误（连续省略号）：
向德豪："我...我只是想说......那个......"
索菲亚脸红："你......你......"

✅ 正确（简洁表达）：
向德豪："我..."
索菲亚转头。
```

## 四、AI味识别与消除

### 4.1 AI味特征清单

| 特征 | 示例 | 消除方法 |
|------|------|----------|
| 频繁省略号 | "......""..." | 用动作代替 |
| 过多感叹号 | "！！！" | 平静表达 |
| 直白情感标签 | "他心中悲痛万分" | 用细节暗示 |
| 重复套路 | 每次都"泪流满面" | 每次要有新意 |
| 网络用语 | "高端操作""老女人" | 用符合世界的语言 |
| 长篇独白 | 心理活动过多 | 用行动代替 |
| 说明性对话 | "让我来解释一下" | 让读者自己理解 |
| 过度煽情 | 每次都要哭一遍 | 留白更有力量 |

---

### 4.2 网络用语替换表

| 禁止 | 替换 |
|------|------|
| 高端操作 | 他们做不到的 |
| 老女人 | 那个女人/院长 |
| 弱鸡 | 太弱 |
| 666 | （不使用） |
| 233 | （不使用） |
| 傻娇 | （用动作描写） |
| 么么哒 | （不使用） |
| 萌化了 | （不使用） |
| 破防 | （用动作描写） |
| 心累 | （用场景暗示） |

## 五、场景描写技巧

### 5.1 战斗场景

**原则**：简洁有力，重点突出

#### 结构

```
1. 局势描写（一句话）
2. 关键动作（3-5句）
3. 结果（一句话）
4. 影响（简短）

示例：
兽王突破防线。
向德豪正在炼尸，无法移动。
弗拉姆挺身而出。
燃烧生命，炎龙自爆。
与兽王同归于尽。
向德豪看着火焰，握紧拳头。
```

---

### 5.2 情感场景

**原则**：少说多做，用细节打动

#### 结构

```
1. 铺垫（环境、气氛）
2. 触发点（一个动作、一句话）
3. 反应（压抑、细节）
4. 爆发（一句话、一个动作）
5. 余韵（后续影响）

示例（师父失踪）：
向德豪打开裹尸袋。
里面只有将臣。
他没有哭，没有喊。
只是默默看着空荡荡的袋子。
那天晚上，他坐在崖边。
从天黑坐到天明。
第二天起，他的眼神变了。
```

---

### 5.3 感情场景

**原则**：含蓄、留白、渐进

#### 双女主感情线

**伊莎贝拉（日久生情）**：
- 不说"我喜欢你"
- 用行动表达：夜晚辅导、缝补道袍、危险时挡在前面
- 表白也简单："我...我喜欢你。"
- 点到为止

**索菲亚（假戏真做）**：
- 从"挡箭牌"到"真心"
- 不说"我爱上你了"
- 用眼神、心跳、沉默来表达
- 关键台词："那...如果我说，我不想只是骗人呢？"

## 六、角色塑造要点

### 6.1 主角向德豪

**核心特质**：
- 内敛、行动派、话少
- 对师父的深厚感情（用行动表达）
- 对朋友的重情重义（用牺牲回应）
- 对敌人的冷酷无情（用战斗证明）

**对话风格**：
- 简短有力
- 不解释，只做
- 被问才答

**行为模式**：
- 遇到困难：默默解决
- 遇到悲伤：压在心里
- 遇到愤怒：用行动发泄
- 遇到感动：沉默、点头

---

### 6.2 伊莎贝拉（女主之一）

**核心特质**：
- 成熟、理性、护短
- 外冷内热
- 不善表达感情
- 对自己人极其保护

**对话风格**：
- 冷静、理性
- 偶尔毒舌
- 对向德豪时温和
- 对外人时高冷

**情感表达**：
- 不说"我爱你"
- 用行动：夜深辅导、缝补道袍、危险时挡在前面
- 表白时也简单："我...我喜欢你。"
- 不解释，不留退路

---

### 6.3 索菲亚（女主之二）

**核心特质**：
- 活泼、直球、有点傲娇
- 对喜欢的人勇敢表达
- 对讨厌的人毫不留情

**对话风格**：
- 直白、活泼
- 有点口吃（害羞时）
- 偶尔傲娇："那...如果..."

**情感表达**：
- 从"挡箭牌"到真心
- 不绕弯子
- 表白时："那...如果我说，我不想只是骗人呢？"
- 转身跑开

---

### 6.4 将臣（尸神）

**核心特质**：
- 话痨、吐槽、毒舌
- 萌萌外表下的尸神威严
- 对向德豪从不满到认命

**对话风格**：
- 吐槽向德豪的操作
- 评论异界的魔法
- 偶尔透露上古信息

**吐槽示例**：
- "这算什么魔法？跟没吃饭一样。"
- "骷髅兵？弱！太弱了！"
- "那老道士的本事...还凑合。"

**注意**：
- 去除网络用语
- 吐槽要符合上古尸神的身份
- 不要过于现代

## 八、常见问题与解决

### Q1：如何平衡情感表达和简洁原则？

**A**：用"一个动作+一句话"模式。

```
❌ 错误：
向德豪非常悲伤，他想念师父，他哭了很久，他发誓一定要找到师父。

✅ 正确：
向德豪摸着裹尸袋。
从天黑坐到天明。
```

---

### Q2：如何让读者感受到角色情感，不说"悲伤"两个字？

**A**：用细节暗示。

```
❌ 错误：
他感到很悲伤。

✅ 正确：
他的手在颤抖。
握着炼尸大典的指节发白。
```

---

### Q3：对话太少会不会影响代入感？

**A**：不会。简洁有力的对话更有代入感。

```
❌ 错误：
向德豪："师父，我好想念您啊，我真的好想您，我每天都在想您，我发誓我一定会找到您的，师父您到底在哪里啊？我..."

✅ 正确：
向德豪系紧裹尸袋的绳结。
第二天起，他的眼神变了。
```

---

### Q4：如何让角色不死板？

**A**：每个角色独特的说话方式和行为模式。

```
向德豪：沉默、行动
伊莎贝拉：理性、偶尔毒舌
索菲亚：直球、害羞时口吃
弗拉姆：热血、直率
格蕾丝：温柔、犹豫
凯尔：正义、话少
将臣：吐槽、毒舌
```

## 十、总结

### 核心原则（记住这四条）

1. **Show, Don't Tell**（展示而非讲述）
2. **少而精**（每句话都有意义）
3. **无声胜有声**（最悲伤的时候是无声的）
4. **留白艺术**（不说出来的更有力量）

### 避免清单

- ❌ "我发誓""我保证""我一定会"
- ❌ 频繁的省略号
- ❌ "泪流满面""痛哭流涕"
- ❌ 长篇内心独白
- ❌ 网络用语

### 推荐清单

- ✅ 动作暗示情感
- ✅ 道具承载情感
- ✅ 时间流逝体现悲伤
- ✅ 细节暗示变化
- ✅ 留白引发想象
