## 二、新增有趣设定

### 设定1：将臣的"见证者"支线
**核心概念**：从被冤枉者到为他人辩护

| 内容 | 说明 |
|------|------|
| 上古真相 | 从未害人，只求修炼，被误解 |
| 被误解原因 | 不会说话，"嗷嗷嗷"被当成挑衅 |
| 异界发现 | 向德豪在遗迹中发现石碑记载 |
| 见证契机 | 后期为被误解者辩护 |
| 角色弧光 | 被冤枉者→为他人辩护者→见证者 |

**搞笑对话示例**：
```
向德豪："你真的从未害人？"
将臣："我吃那玩意儿干嘛？我吸的是日月精华！吃人？掉价！"
向德豪："那你为什么不解释？"
将臣："解释个屁！我说过话吗？"
```

- 天生治疗力超强，被称为"圣女"

## 四、故事趣味性提升点

### 1. 角色更有趣
- 将臣：从冤种→有深度的冤种→为他者辩护
- 风之主宰：被污染者中的反抗者，增加敌人阵营层次
- 小伙伴：每个人都有家族背景和未说出口的情感

### 2. 系统更丰富
- 特殊变异尸种：增加炼尸的趣味性和策略性
- 玉佩隐藏功能：逐步解锁，像游戏成就系统
- 炼体隐藏境界：给主角更多成长空间

### 3. 节奏更平衡
- 学院趣味事件：调节紧张战斗节奏
- 生活化场景：让角色更立体
- 搞笑与悲情交替：情感体验更丰富

### 4. 世界观更完整
- 现代世界后续：为番外埋伏笔
- 被污染主宰阵营：有反抗者，不全是坏人
- 异界物品回流：灵气复苏征兆
