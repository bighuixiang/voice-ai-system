## 一、组队背景：学院大比新规

### 1.1 大比规则公布（第15章）

```
【学院大礼堂】

院长伊莎贝拉站在台上。

"同学们，今年的学院大比有重大变革。"

"往年都是个人赛，但今年...我们增加了团队赛。"

全场哗然。

"团队赛？"学生议论纷纷。

"是的，团队赛。"伊莎贝拉继续说，"因为现实中的战斗，从来不是一个人的事。"

"你们需要学会配合，学会信任，学会...生死与共。"

"团队赛规则：每队5人，自由组队。"

"如果找不到队友，学院会随机分配。"

"但我不建议你们随机分配..."她笑了笑，"因为你们需要默契。"

【这宣告了组队期的开始】
```

### 1.2 向德豪的困境（第15章）

```
【学院食堂】

向德豪独自吃饭。

将臣蹲在旁边："啧，小鬼，你不组队吗？"

向德豪："我...一个人也挺好。"

将臣："你确定？一个人对战五人团队？"

"你不是被虐得吧？"

向德豪："......"

向德豪确实在考虑组队的事。

但该找谁呢？

他来学院不久，认识的人不多。

而且...他是东方人，修炼赶尸术，很多人对他有偏见。

将臣："啧，看来小鬼要孤独终老了..."

向德豪："你闭嘴。"

【向德豪的孤独，为后续组队做铺垫】
```

## 二、第一个队友：弗拉姆的主动邀请

### 2.1 弗拉姆的人物档案

| 设定 | 内容 |
|------|------|
| **全名** | 弗拉姆·烈焰（Flam Blaze） |
| **年龄** | 19岁（比向德豪大一岁） |
| **种族** | 人族 |
| **身份** | 学院二年级，火系天才 |
| **性格** | 热血、直率、讲义气、有点冲动 |
| **外貌** | 红发红眼，身材高大，笑容阳光 |
| **梦想** | 成为最强火系法师，开一家"兄弟酒馆" |

### 2.2 初遇场景（第16章）

```
【学院训练场】

向德豪独自练习炼尸术。

他操控一內行尸，让它做出各种动作。

"左转，右转，前进，攻击..."

周围有学生窃窃私语。

"就是那个赶尸的..."

"听说他修炼邪术..."

"离他远点..."

向德豪假装没听见，继续练习。

忽然，一个声音响起：

"喂！小兄弟！"

向德豪转头，看到一个红发青年。

红发青年冲过来，完全不在意周围人的目光。

"我叫弗拉姆！火系法师！"

"我看你练习很久了，你的炼尸术很厉害啊！"

向德豪："...谢谢。"

弗拉姆咧嘴一笑："你想参加学院大比吗？"

向德豪："我..."

弗拉姆："我看了你刚才的练习！你的炼尸术很有意思！"

"如果可以的话...我想邀请你加入我的队伍！"

向德豪愣住："你的队伍？"

弗拉姆挠了挠头："呃...其实还没有队伍..."

"但我在找人！我觉得你很合适！"

向德豪："为什么选我？"

弗拉姆："因为...你看起来很孤独啊！"

"而且...你的炼尸术很酷！"

"火+尸，无敌组合啊！"

向德豪："......"

将臣在旁边："啧，这小子还挺单纯的..."

【弗拉姆的热血和直率，第一印象很深】
```

### 2.3 加入的契机（第16章）

```
【训练场角落】

弗拉姆继续说："我看过你的战斗！一枪制敌！"

弗拉姆："那有什么关系！"

"你是个好人！"

向德豪："......"

弗拉姆："而且...你也没队伍吧？"

确实没有。

弗拉姆眼睛一亮："那就这么定了！"

"我们是队友了！"

"以后就是兄弟了！"

他伸出拳头。

向德豪看着他的拳头，犹豫了一下。

"那...好吧。"

两人碰拳。

将臣："啧，小鬼，你这么容易被骗吗..."

【弗拉姆的热血感染了向德豪】
```

## 七、时间线修正：终极配合技的使用时机

### 7.1 原设定的问题

```
原设定：
→ 第81-95章：小伙伴牺牲
→ 第96-110章：孤狼作战
→ 终极配合技"五元合一·位面之阵"在后期使用

问题：
→ 小伙伴都牺牲了，怎么施展终极配合技？
→ 逻辑错误！
```

### 7.2 修正后的时间线

```
【修正后的终极配合技使用时机】

第50章：第一次兽潮
→ 五人首次施展"五元合一·位面之阵"
→ 成功击退兽潮
→ 这是五人默契的巅峰

第70章：师徒并肩作战
→ 向德豪+师父+小伙伴
→ 施展"六元合一"（加入师父）
→ 最后的温馨时光

第70章：师父牺牲
→ 从此，再也没有"五元合一"

第81-95章：小伙伴陆续牺牲
→ 每次牺牲，都是单独的场景
→ 无法施展团队配合技

第96-110章：孤狼作战
→ 向德豪独自一人
→ 只能靠自己+将臣

第111章及以后：新的伙伴
→ 不会再有"五元合一"
→ 因为...原来的五人，已经不完整了

【修正：终极配合技只能在第50-80章之间使用】
```
