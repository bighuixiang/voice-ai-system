# 写作风格统一指南（四不原则）

## 核心原则

```
┌─────────────────────────────────────────────────────────────┐
│                  四不原则                                   │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. Show, Don't Tell（展示而非讲述）                        │
│     → 用动作/细节表达情感，不要直接贴标签                    │
│                                                             │
│  2. 不滥用省略号                                            │
│     → 用动作代替"......"                                    │
│                                                             │
│  3. 不过度煽情                                              │
│     → 最悲伤的时候往往是无声的                              │
│                                                             │
│  4. 不使用网络用语                                          │
│     → 使用符合世界观的语言                                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 一、Show, Don't Tell（展示而非讲述）

### 错误示范

| 错误示范 | 为什么错 |
|----------|----------|
| 他哭了一整夜 | 直接贴标签，缺乏画面感 |
| 他感到心碎 | 告诉读者情感，而不是展示 |
| 他很愤怒 | 直接描述情绪，缺乏感染力 |
| 他很害怕 | 没有具体表现 |

### 正确示范

| 情感 | 正确写法 | 分析 |
|------|----------|------|
| 悲伤 | 他坐在崖边，从天黑坐到天明 | 用动作和时长展示悲伤 |
| 心痛 | 他的手在颤抖，指节发白 | 用身体反应展示痛苦 |
| 愤怒 | 他握紧拳头，指节发白 | 用动作展示愤怒 |
| 恐惧 | 他后退一步，撞到墙上 | 用动作展示恐惧 |

---

### 详细示例

#### 示例1：悲伤

**【错误示范】**
```
师父死了，向德豪非常悲伤。
他哭了一整夜。
```

**【正确示范】**
```
师父倒在他怀里。
身体逐渐冰冷。

向德豪跪在地上。
握着师父的手。

"师父...师父..."

没有人回应。

天黑了。
又亮了。

向德豪依然跪在那里。
一动不动。
```

---

#### 示例2：愤怒

**【错误示范】**
```
向德豪很愤怒。
他要为师父报仇。
```

**【正确示范】**
```
向德豪站起来。
他的手，握紧了拳头。
指节发白。

"黑暗主宰..."
"我要...杀了你..."
```

---

#### 示例3：思念

**【错误示范】**
```
向德豪很思念师父。
他经常想起师父的话。
```

**【正确示范】**
```
向德豪路过酒馆旧址。
他停下脚步。

酒馆已经拆了。
但...弗拉姆的声音仿佛还在耳边。

"兄弟，说好了不见不散..."

向德豪站着。
站了很久。

然后他继续走。
没有回头。
```

## 二、不滥用省略号

### 省略号的正确用法

| 场景 | 可以用 | 不可以用 |
|------|--------|----------|
| 话语中断 | ✅ 可以 | — |
| 思考停顿 | ✅ 可以 | — |
| 情绪激动 | ❌ 改用动作 | "......"→颤抖、哽咽 |
| 悲伤沉默 | ❌ 改用动作 | "......"→低头、转身 |
| 时间流逝 | ❌ 改用描写 | "......"→天黑了、又亮了 |

---

### 错误示范与修正

#### 示例1：情绪激动

**【错误示范】**
```
向德豪："师父......"

师父："德豪......"

两人抱在一起......
```

**【正确示范】**
```
向德豪："师父......"

他的声音哽咽了。

师父："德豪......"

师父拍着他的背。
"好了，好了......师父在......"

向德豪的眼泪终于流了下来。
```

---

#### 示例2：悲伤沉默

**【错误示范】**
```
师父死了。

......

向德豪跪在地上。
```

**【正确示范】**
```
师父倒在他怀里。
身体逐渐冰冷。

向德豪跪在地上。
握着师父的手。

天黑了。
又亮了。

他依然跪在那里。
```

---

#### 示例3：对话停顿

**【可以用省略号的情况】**

```
师父："德豪，你......你长大了。"

向德豪："师父......我......"

师父笑了："傻孩子......"
```

**分析**：这里的省略号表示话语停顿，是正确的用法。
```

## 三、不过度煽情

### 煽情的判断标准

| 煽情程度 | 特征 | 建议 |
|----------|------|------|
| 轻度 | 用了形容词（悲伤、痛苦） | 可以接受，但可改进 |
| 中度 | 用了感叹号和重复 | 需要修改 |
| 重度 | 长篇内心独白+感叹号+重复 | 必须修改 |

---

### 错误示范

**【重度煽情】**
```
向德豪跪在地上，痛哭流涕。
"师父——！！师父——！！"
"我发誓！我一定要找到您！"
"我发誓！我一定要为您报仇！"
"师父——！！"

他哭了一整夜。
他的心碎了。
他永远不会忘记师父的牺牲。
```

---

### 正确示范

**【无声的悲伤】**
```
向德豪跪在地上。
握着师父的手。

"师父......"

师父的手，逐渐冰冷。

向德豪没有哭。
他只是跪在那里。

天黑了。
又亮了。

他站起来。
没有流泪。

但他的眼神......变了。
```

---

### 情感四层结构

```
┌─────────────────────────────────────────────────────────────┐
│              情感表达四层结构                                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【第一层：压抑】                                            │
│  → 默默忍受，不发一言                                       │
│                                                             │
│  【第二层：细节】                                            │
│  → 手抖、眼神变化、动作停顿                                 │
│                                                             │
│  【第三层：爆发】                                            │
│  → 一句话、一个动作                                         │
│                                                             │
│  【第四层：余韵】                                            │
│  → 行为改变、性格转变                                       │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

### 示例：师父牺牲

**【错误示范】**
```
师父牺牲了。
向德豪痛哭流涕。
他发誓要为师父报仇。
他永远不会忘记师父的恩情。
```

**【正确示范】**
```
师父倒在他怀里。
"德豪...你是师父的...骄傲..."

师父的手，垂了下去。

向德豪跪在地上。
握着师父的手。

没有哭。
没有说话。

他只是跪在那里。

天黑了。
又亮了。

第二天，他站起来。
没有流泪。
也没有回头。

只是......他的眼神，变了。
```

## 四、不使用网络用语

### 禁止的网络用语

| 网络用语 | 为什么禁止 | 替代方案 |
|----------|------------|----------|
| 高端操作 | 破坏世界观 | "精妙的战术" |
| 弱鸡 | 破坏世界观 | "弱小" "不堪一击" |
| 萌化了 | 破坏世界观 | "可爱" |
| 破防了 | 破坏世界观 | "失控" "崩溃" |
| 居然... | 破坏世界观 | "竟然..." |
| 就这？ | 破坏世界观 | "就这样？" |
| yyds | 破坏世界观 | "最强" "无双" |

---

### 正确的语言风格

#### 示例1：战斗描写

**【错误示范】**
```
向德豪太强了，这波操作太高端了！
对手直接破防了！
```

**【正确示范】**
```
向德豪抬手。
光芒绽放。

一枪。

对手倒地。

周围一片死寂。
```

---

#### 示例2：赞美描写

**【错误示范】**
```
伊莎贝拉萌化了！
她是伊莎贝拉yyds！
```

**【正确示范】**
```
伊莎贝拉微笑着。
银发飘动。
尖耳微红。

她就像月光中的精灵。
美丽得让人不敢直视。
```

---

#### 示例3：吐槽描写

**【错误示范】**
```
将臣：就这？这点实力也好意思来？
```

**【正确示范】**
```
将臣："啧，弱！太弱了！"
"这点实力也敢来送死？"
```

## 五、对话风格指南

### 角色对话风格表

| 角色 | 风格 | 示例 |
|------|------|------|
| 向德豪 | 简短、内敛、行动派 | "我去做。" |
| 师父向守一 | 威严、温和、长辈感 | "好了，好了..." |
| 伊莎贝拉 | 成熟、理性、偶尔毒舌 | "就这？" |
| 索菲亚 | 直球、活泼、害羞时口吃 | "那...如果我说..." |
| 将臣 | 话痨、吐槽、傲娇 | "弱！太弱了！" |
| 弗拉姆 | 热血、直率 | "兄弟，这事交给我！" |
| 格蕾丝 | 温柔、害羞 | "小心点..." |
| 凯尔 | 正义、沉稳、话少 | "保护...大家..." |
| 艾米莉亚 | 害羞、紧张 | "我...我..." |

---

### 对话写作技巧

#### 技巧1：简短有力

**【错误示范】**
```
向德豪："师父，我一定会为你报仇的！不管对方有多强，我都不会放弃！我一定要杀了黑暗主宰！"
```

**【正确示范】**
```
向德豪："师父，我会杀了它。"
"不管它有多强。"
```

---

#### 技巧2：用动作代替语言

**【错误示范】**
```
向德豪："我很愤怒，我要报仇！"
```

**【正确示范】**
```
向德豪握紧拳头。
指节发白。

"我要杀了它。"
```

---

#### 技巧3：对话要有意义

**【错误示范】**
```
向德豪："师父，您好。"
师父："你好，德豪。"
向德豪："您最近怎么样？"
师父："我挺好的。"
向德豪："那就好。"
```

**【正确示范】**
```
向德豪："师父，您的身体......"

师父沉默了。

向德豪："师父......"

师父："师父没事。"
"真的。"
```

## 六、执行检查表

### 写作前的检查

- [ ] 是否用了"感到......"直接描述情感？→ 改用动作
- [ ] 是否用了大量省略号？→ 改用动作或描写
- [ ] 是否过度煽情（感叹号、重复）？→ 改用无声的表达
- [ ] 是否用了网络用语？→ 改为符合世界的语言

### 写作中的检查

- [ ] 对话是否简短有力？
- [ ] 情感是否通过动作展示？
- [ ] 省略号是否只在必要时使用？
- [ ] 语言是否符合角色风格？

### 写作后的检查

- [ ] 情感是否有感染力？
- [ ] 是否符合"四不原则"？
- [ ] 是否有违和感？
- [ ] 风格是否统一？

## 七、场景模板

### 场景1：牺牲场景

**【模板】**
```
第一层：局势（简短，1-2句）
→ 兽王突破防线。向德豪正在炼尸，无法移动。

第二层：决定（一个眼神）
→ 弗拉姆看向向德豪。那个眼神里没有恐惧，只有坚定。

第三层：对话（简短，不煽情）
→ 弗拉姆："兄弟，专心炼尸。"
→ 向德豪："大哥......"
→ 弗拉姆："这里......交给我。"

第四层：行动（3-5句）
→ 弗拉姆转身冲向兽王。燃烧生命，炎龙爆发。与兽王同归于尽。

第五层：结果（一句话）
→ 火焰吞噬一切。兽王倒地。弗拉姆也......消失了。

第六层：余韵（无声的悲伤）
→ 向德豪僵在原地。将臣蹲在他肩膀上。第一次......它没有说话。
```

---

### 场景2：重逢场景

**【模板】**
```
第一层：相遇（眼神交汇）
→ 两人看到对方。时间仿佛静止。

第二层：迟疑（不敢相信）
→ 向德豪："师父......？"
→ 师父："德豪......？"

第三层：确认（眼泪落下）
→ 向德豪冲过去。师父张开双臂。
→ 两人拥抱。眼泪流下。

第四层：对话（简短有力）
→ 师父："傻孩子......哭什么......"
→ 向德豪："师父......我以为......"
→ 师父："师父在。师父一直都在。"

第五层：余韵（行为改变）
→ 向德豪擦干眼泪。他笑了。
→ 这是师父牺牲后，他第一次笑。
```

---

### 场景3：表白场景

**【模板】**
```
第一层：氛围营造（安静、私密）
→ 两人独处。月光洒下。

第二层：犹豫（不知道怎么说）
→ 索菲亚："德豪，我......"
→ 她低下头，脸红。

第三层：鼓励（对方引导）
→ 向德豪："怎么了？"
→ 索菲亚："我......我有话想对你说......"

第四层：表白（简短、真诚）
→ 索菲亚："我......我喜欢你......"
→ 向德豪愣住。
→ 索菲亚："那......如果我说......我不想只是骗人呢......"

第五层：回应（真诚、温暖）
→ 向德豪："我也喜欢你。"
→ 索菲亚震惊地抬起头。
→ 向德豪笑了："真的。"

第六层：余韵（拥抱、承诺）
→ 两人拥抱。
→ 向德豪："从今天起，我保护你。"
```

## 八、常见错误与修正

### 错误1：过度描写内心

**【错误】**
```
向德豪心想：师父死了，我好难过。我一定要为师父报仇。我要杀了黑暗主宰。我要变得更强。
```

**【正确】**
```
向德豪跪在师父坟前。
没有说话。

他站起来。
眼神冰冷。

"我要杀了它。"
```

---

### 错误2：对话过于冗长

**【错误】**
```
向德豪："师父，您放心，我一定会努力修炼，成为强者，为师父报仇，保护我想保护的所有人！"
```

**【正确】**
```
向德豪："师父，我会杀了它。"
"然后......复活您。"
```

---

### 错误3：省略号滥用

**【错误】**
```
师父牺牲了......
向德豪很伤心......
他哭了......
```

**【正确】**
```
师父倒在他怀里。
身体逐渐冰冷。

向德豪跪在地上。
握着师父的手。

天黑了。
又亮了。
```
