## 现代世界

### 基本信息

| 设定 | 内容 |
|------|------|
| 时代 | 现代都市 |
| 特殊存在 | 道术真实存在，僵尸代代相传 |
| 湘西赶尸派 | 隐秘传承，代代等待僵尸王将臣现世 |

### 湘西赶尸派

| 设定 | 内容 |
|------|------|
| 祖师 | 向氏先祖 |
| 传承 | 赶尸术、炼尸术、道术、炼体术 |
| 信条 | 炼尸先炼己，己强方可炼尸 |
| 禁忌 | 炼制活人、滥杀无辜 |
| 三大神器 | 炼尸大典、八卦道袍、玉佩 |

**赶尸派起源**（简约）：
- 战乱年代，尸体在极阴之地产生尸变
- 吸血传播尸变，危害人间
- 向氏先祖误以为是传说中的"将臣"作祟
- 世代以除"将臣"为己任
- 研究克制僵尸的道具和功法《炼尸大典》
- 代代相传，等待僵尸王将臣的现世

### 赶尸派三大神器

| 神器 | 来历 | 能力 |
|------|------|------|
| **炼尸大典** | 赶尸派世代完善优化的本土产物 | 记载完整炼尸体系，道术加持+人族信仰，能抵御黑暗侵蚀。到异界后得到魔素持续强化，炼制效率和上限大幅提升 |
| **八卦道袍** | 向氏先祖炼制 | 防护+净化，能抵御黑暗污染 |
| **玉佩** | 向德豪父母（光明主宰与生命主宰）炼制 | 护主+传送+封印血脉+封存海量主宰之力 |

### 裹尸袋

**现代世界的功能**：
- 赶尸派祖师炼制
- 外观是普通的牛皮袋
- 世代加强完善
- 只能存储死物
- 类似储物袋，专门用于赶尸时装尸体
- **现代无特殊作用**，就是个实用的工具

**基本功能**：
- 存储尸体，方便搬运
- 防止尸体腐烂（保鲜功能）
- 道术加持，防止尸变
- 空间压缩，能装很多尸体

## 异界发现的功能

**意外发现**：
- 到了异界后，发现特殊的异界能量激活了潜在功能
- 这些功能是祖师炼制时预留的，但在现代无法触发
- 异界的魔素环境让裹尸袋展现了真正的能力

**异界特殊能力**：

| 能力 | 现代状态 | 异界激活 |
|------|----------|----------|
| 存储尸体 | ✅ 可用 | ✅ 可用 |
| 尸体保鲜 | ✅ 可用（弱） | ✅ 增强，尸体永不腐烂 |
| 意识沉睡 | ❌ 无 | ✅ 死者意识进入特殊沉睡 |
| 时间静止 | ❌ 无 | ✅ 袋内时间几乎静止 |
| 抵御黑暗 | ❌ 无 | ✅ 道术+信仰，能抵御黑暗污染 |

**在故事中的作用**：
1. 将臣穿越时被吸入，在袋中沉睡
2. 向德豪血滴认主，将臣苏醒认主
3. 成为向德豪的重要助力和伙伴

**师父穿越后的状态**：
- 师父和将臣一起被吸入空间漩涡
- 但师父没有被吸入裹尸袋，而是穿越到了异界其他地方
- **穿越落点相距遥远**：师父落在异界西部某处，主角落在东部魔兽岭
- **师父的困境**：
  - 穿越后道术气息太强，被异界某些势力盯上
  - 一边躲避追杀，一边寻找徒弟
  - 魔兽岭是危险区域，师父以为徒弟不会在那里，先从安全区域找起
  - 兽潮时被逼到前线参战，终于相遇
- 师父为保护徒弟牺牲，尸体用裹尸袋保存
- 最终被向德豪复活

## 异界——艾兰大陆

### 基本信息

| 设定 | 内容 |
|------|------|
| 世界名称 | 艾兰大陆 |
| 能量体系 | 魔素、元素规则 |
| 核心力量 | 神格、规则之力 |
| 地理位置 | 东部魔兽岭、西部人族国度、北部冰原、南部海族、中部矮人山脉 |

### 货币体系（新增）

艾兰大陆使用三套货币体系，对应不同阶层：

| 货币 | 使用阶层 | 价值 | 来源 |
|------|---------|------|------|
| **银币** | 普通民众 | 基础货币 | 银矿开采 |
| **金币** | 贵族、富商 | 1金币=100银币 | 金矿开采 |
| **魔晶币** | 魔法师 | 1魔晶币=10金币=1000银币 | 魔兽魔晶炼制 |

**货币流通规则**：
- 平民日常交易用银币
- 贵族之间、奢侈品交易用金币
- 魔法师之间、魔法材料交易用魔晶币
- 三种货币可以互相兑换，但有汇率差

**主角的优势**：
- 玉佩空间内有海量金币和魔晶币
- 前期不知道，中后期发现
- 从此财务自由，不用为钱发愁

### 魔兽等级体系（详细）

#### 等级划分

| 等级 | 实力对应 | 肉身强悍 | 产出魔晶 | 尸体用途 |
|------|---------|---------|---------|----------|
| **初阶** | 学徒-法师 | 刀剑可伤 | 碎裂魔晶（白） | 炼制行尸、入药 |
| **中阶** | 法师-大法师 | 刀剑难伤 | 小块魔晶（绿） | 炼制铁尸、炼器材料 |
| **高阶** | 大法师-魔导师 | 法术难伤 | 中块魔晶（蓝） | 炼制铜尸、高级炼器 |
| **王级** | 魔导师-大魔导师 | 禁咒难伤 | 大块魔晶（紫） | 炼制银尸、顶级材料 |
| **皇级** | 大魔导师-法圣 | 法圣难伤 | 完美魔晶（金） | 炼制金尸、稀有材料 |
| **帝级** | 法圣-法神 | 法神难伤 | 极品魔晶（红） | 炼制尸王、神级材料 |

**魔晶用途**：
- 货币：炼制成魔晶币
- 修炼：吸收提升魔素
- 炼器：镶嵌在武器上
- 阵法：作为能量源

**尸体用途**：
- 炼尸：赶尸术炼制战斗工具
- 炼器：兽骨、兽皮制作武器铠甲
- 入药：魔兽血肉炼制药剂

**肉身强悍描述**：
- 初阶：普通刀剑可杀死
- 中阶：需要附魔武器
- 高阶：魔法攻击才有用
- 王级：禁咒才能伤到
- 皇级：法圣全力一击
- 帝级：法神才能抗衡
