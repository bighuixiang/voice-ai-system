# 世界背景

## 现代世界

### 基本信息
- **时代**：现代都市
- **特殊存在**：道术真实存在，僵尸代代相传
- **湘西赶尸派**：隐秘传承，代代等待僵尸王现世

### 湘西赶尸派

| 设定 | 内容 |
|------|------|
| 祖师 | 向氏先祖 |
| 传承 | 赶尸术、炼尸术、道术 |
| 信条 | 炼尸可炼己，炼己方可炼尸 |
| 禁忌 | 炼制活人、滥杀无辜 |
| 三大神器 | 炼尸大典、八卦道袍、护界玉佩 |

**赶尸派起源**（简约）：
- 战乱年代，尸体在极阴之地产生尸变
- 吸血传播尸变，危害人间
- 向氏先祖误以为是传说中的"将臣"作祟
- 世代以除"将臣"为己任
- 研究克制僵尸的道具和功法《炼尸大典》
- 代代相传，等待僵尸王将臣的现世

### 赶尸派三大神器

| 神器 | 来历 | 能力 |
|------|------|------|
| **炼尸大典** | 赶尸派世代完善优化的本土产物 | 记载完整炼尸体系，道术加持+人族信仰，能抵御黑暗侵蚀 |
| **八卦道袍** | 向氏先祖炼制 | 防护+净化，能抵御黑暗污染 |
| **护界玉佩** | 向德豪父母炼制 | 护主+传送，封印血脉 |

**炼尸大典的特殊能力**：
- 赶尸派世代完善优化的本土产物
- 融合道术符文、人族信仰、尸气秘法
- 自带净化之力，能抵御黑暗侵蚀
- 在异界发现：本土道术与异界黑暗的对抗
- 能够净化被黑暗污染的尸体
- 向德豪靠它能在黑暗环境中保持清醒

**八卦道袍的特殊能力**：
- 祖传宝物，代代相传
- 布料中融入符文和净化之力
- 能够自动抵御黑暗污染
- 在黑暗环境中散发淡淡光芒
- 向德豪穿越时穿着，是他在异界初期不受黑暗影响的关键

### 裹尸袋

## 现代世界的功能

**基本设定**：
- 赶尸派祖师炼制
- 外观是普通的牛皮袋
- 世代加强完善
- 只能存储死物
- 类似储物袋，专门用于赶尸时装尸体
- **现代无特殊作用**，就是个实用的工具

**功能**：
- 存储尸体，方便搬运
- 防止尸体腐烂（保鲜功能）
- 道术加持，防止尸变
- 空间压缩，能装很多尸体

## 异界发现的功能

**意外发现**：
- 到了异界后，发现特殊的异界能量激活了潜在功能
- 这些功能是祖师炼制时预留的，但在现代无法触发
- 异界的魔素环境让裹尸袋展现了真正的能力

**异界特殊能力**：

| 能力 | 现代状态 | 异界激活 |
|------|----------|----------|
| **存储尸体** | ✅ 可用 | ✅ 可用 |
| **尸体保鲜** | ✅ 可用（弱） | ✅ 增强，尸体永不腐烂 |
| **意识沉睡** | ❌ 无 | ✅ 死者意识进入特殊沉睡 |
| **时间静止** | ❌ 无 | ✅ 袋内时间几乎静止 |
| **抵御黑暗** | ❌ 无 | ✅ 道术+信仰，能抵御黑暗污染 |

**为什么在异界会有特殊作用**：
1. **异界魔素激活**：异界的能量环境激活了潜在符文
2. **道术共鸣**：与异界的某种能量产生共鸣
3. **信仰加持**：承载了人族对抗黑暗的意志

**在故事中的作用**：
1. 将臣穿越时被吸入，在袋中沉睡
2. 向德豪血滴认主，将臣苏醒认主
3. 成为向德豪的重要助力和伙伴

**师父穿越后的状态**：
- 师父和将臣一起被吸入空间漩涡
- 但师父没有被吸入裹尸袋，而是穿越到了异界其他地方
- 师父独自在异界生存，寻找徒弟
- 兽潮时师徒重逢
- 后来为保护徒弟牺牲，尸体才需要用炼尸大典复活

## 异界——艾兰大陆

### 基本信息

| 设定 | 内容 |
|------|------|
| 世界名称 | 艾兰大陆 |
| 能量体系 | 魔素、元素规则 |
| 核心力量 | 神格、规则之力 |
| 地理位置 | 东部魔兽岭、西部人族国度、北部冰原、南部海族 |

### 势力分布

**人族**
- 数个王国与帝国
- 魔法师公会
- 各大魔法学院

**至高神**
- 最初领悟元素规则，吸收神格成就
- 各自统治一片神域

**主宰**
- 无需神格，自身力量成就
- 实力超越至高神
- 包括：光明主宰、黑暗主宰、生命主宰、死亡主宰

### 主宰之间的关系

**光明主宰·奥瑞尔 & 生命主宰·盖亚**
- 相爱，违反"主宰不近情感"的"规则"
- 诞下向德豪（主宰之子）
- 为保护孩子，将其送往现代世界

**黑暗主宰·莫尔甘**
- 暗中污染所有主宰
- 想要吞噬一切，冲击位面之主
- 最终被向德豪击败

**魔兽**
- 居于东部魔兽岭
- 分为低阶、中阶、高阶、领主、王者级别
- **中期设定**：兽潮来袭时魔兽异常强大
- **至高神限制**：至高神不能插手下界事务，否则会引发位面排斥
- **兽潮强度**：足以摧毁人族国度，向德豪靠点尸成器稳住局面

### 魔素与规则

- **魔素**：天地能量，可被吸收修炼
- **元素规则**：火、水、风、土、光、暗、雷、空间、时间
- **神格**：至高神力量的核心，可被污染
- **位面之主**：超越主宰，位面最高统治者，一草一木皆可创造

## 黑暗污染

### 本质
- 黑暗主宰万年布局，暗中污染整个神界
- 所有主宰都已被轻度污染
- 被污染者提供养料助其突破
- 目标：吞噬一切，冲击位面之主

### 传播方式
| 方式 | 说明 |
|------|------|
| 神格传播 | 神格是黑暗的载体，融合神格即被污染 |
| 直接接触 | 黑暗主宰可直接污染其他主宰 |
| 间接传播 | 通过被污染者传播给亲近的人 |
| 环境侵蚀 | 黑暗浓郁的区域会缓慢侵蚀 |

### 症状
| 阶段 | 症状 | 发作 |
|------|------|------|
| 初期 | 无明显征兆 | 无 |
| 中期 | 情绪偶尔失控 | 短暂失神 |
| 后期 | 浑身黑死气，双目变暗 | 频繁失控 |
| 爆发 | 变成行尸走肉，胡乱攻击 | 完全堕落 |

### 为什么污染如此严重
- **万年布局**：黑暗主宰花了万年时间渗透
- **无处不在**：黑暗存在于位面的每个角落
- **无法察觉**：初期完全无法察觉
- **无法净化**：普通手段无法净化，只有向德豪的光明+生命之力可以

### 神界现状
- **四大主宰**：全部轻度污染
- **至高神**：大部分已被暗中污染
- **神格**：大部分神格被黑暗渗透
- **危局**：整个神界处于崩溃边缘

### 为什么至高神不插手下界
- **位面规则**：至高神插手下界会引发位面排斥
- **排斥后果**：可能导致位面崩溃
- **兽潮特殊**：这次兽潮有黑暗主宰暗中操控
- **人族绝望**：只能靠自己，向德豪挺身而出

## 护界玉佩

### 起源
- **光明主宰·奥瑞尔**与**生命主宰·盖亚**联手炼制
- 耗费大量主宰之力
- 只为保护儿子向德豪
- **不是上古神器，是父母亲手炼制**

### 炼制过程
- 两人相爱，诞下向德豪
- 察觉黑暗主宰的阴谋
- 为保护孩子，炼制护界玉佩
- 融入光明与生命之力
- 注入父母的祝福和保护

### 功能
| 功能 | 说明 |
|------|------|
| **护主** | 致命攻击时自动护体 |
| **传送** | 生死关头传送到安全之地（异界） |
| **封印** | 封印向德豪的主宰之力，避免暴露 |
| **引导** | 在异界引导他觉醒血脉 |
| **认亲** | 觉醒时可引导至父母身边 |

### 启动条件
- 向德豪生死攸关时自动启动
- 穿越之夜：三者能量碰撞，向德豪濒死，玉佩启动
- 吸收天地能量，空间扭曲，传送回异界
- **启动后玉佩消耗殆尽，消失**

### 后期
- 穿越后玉佩消失（已消耗）
- 封印逐渐松动
- 向德豪血脉慢慢觉醒
- 父母之力逐渐显现

## 复活机制（卡bug）

### 常规复活规则
- 至高神可以复活生命
- 但代价巨大：损失神力或生命等价交换
- 复活越强者，代价越大
- 这也是为什么复活术很少使用

### 向德豪的"卡bug"方式
- 用**炼尸大典炼制的高品质尸体**来抵消等价交换的代价
- 原理：炼尸大典炼制的尸体带有特殊印记/价值，可被位面规则认可为"交换物"
- 优势：不需要消耗自己的生命或神力，用炼尸来支付代价
- 这不是真正的"复活术"，而是利用炼尸术的漏洞

### 复活对象
1. **师父（向守一）**：异界6个月时为保护徒弟牺牲，用此方式复活
2. **小伙伴**（弗拉姆、格蕾丝、凯尔）：兽潮牺牲后，用此方式复活

### 复活过程
1. 用炼尸大典炼制高品质尸体（"材料"）
2. 用这些尸体抵消等价交换的代价
3. 用生命之力滋养目标尸体
4. 逐步唤醒意识
5. 最终完全复活
