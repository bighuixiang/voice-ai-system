## 现代世界

### 基本信息

| 设定 | 内容 |
|------|------|
| 时代 | 现代都市 |
| 特殊存在 | 道术真实存在，僵尸代代相传 |
| 湘西赶尸派 | 隐秘传承，代代等待僵尸王将臣现世 |

### 湘西赶尸派

| 设定 | 内容 |
|------|------|
| 祖师 | 向氏先祖 |
| 传承 | 赶尸术、炼尸术、道术、炼体术 |
| 信条 | 炼尸先炼己，己强方可炼尸 |
| 禁忌 | 炼制活人、滥杀无辜 |
| 三大神器 | 炼尸大典、八卦道袍、玉佩 |

**赶尸派起源**（简约）：
- 战乱年代，尸体在极阴之地产生尸变
- 吸血传播尸变，危害人间
- 向氏先祖误以为是传说中的"将臣"作祟
- 世代以除"将臣"为己任
- 研究克制僵尸的道具和功法《炼尸大典》
- 代代相传，等待僵尸王将臣的现世

### 赶尸派三大神器

| 神器 | 来历 | 能力 |
|------|------|------|
| **炼尸大典** | 赶尸派世代完善优化的本土产物 | 记载完整炼尸体系，道术加持+人族信仰，能抵御黑暗侵蚀。到异界后得到魔素持续强化，炼制效率和上限大幅提升 |
| **八卦道袍** | 向氏先祖炼制 | 防护+净化，能抵御黑暗污染 |
| **玉佩** | 向德豪父母（光明主宰与生命主宰）炼制 | 护主+传送+封印血脉+封存海量主宰之力 |

### 裹尸袋

**现代世界的功能**：
- 赶尸派祖师炼制
- 外观是普通的牛皮袋
- 世代加强完善
- 只能存储死物
- 类似储物袋，专门用于赶尸时装尸体
- **现代无特殊作用**，就是个实用的工具

**基本功能**：
- 存储尸体，方便搬运
- 防止尸体腐烂（保鲜功能）
- 道术加持，防止尸变
- 空间压缩，能装很多尸体

## 异界发现的功能

**意外发现**：
- 到了异界后，发现特殊的异界能量激活了潜在功能
- 这些功能是祖师炼制时预留的，但在现代无法触发
- 异界的魔素环境让裹尸袋展现了真正的能力

**异界特殊能力**：

| 能力 | 现代状态 | 异界激活 |
|------|----------|----------|
| 存储尸体 | ✅ 可用 | ✅ 可用 |
| 尸体保鲜 | ✅ 可用（弱） | ✅ 增强，尸体永不腐烂 |
| 意识沉睡 | ❌ 无 | ✅ 死者意识进入特殊沉睡 |
| 时间静止 | ❌ 无 | ✅ 袋内时间几乎静止 |
| 抵御黑暗 | ❌ 无 | ✅ 道术+信仰，能抵御黑暗污染 |

**在故事中的作用**：
1. 将臣穿越时被吸入，在袋中沉睡
2. 向德豪血滴认主，将臣苏醒认主
3. 成为向德豪的重要助力和伙伴

**师父穿越后的状态**：
- 师父和将臣一起被吸入空间漩涡
- 但师父没有被吸入裹尸袋，而是穿越到了异界其他地方
- 师父独自在异界生存，寻找徒弟
- 兽潮时师徒重逢
- 后来为保护徒弟牺牲，尸体用裹尸袋保存
- 最终被向德豪复活

## 异界——艾兰大陆

### 基本信息

| 设定 | 内容 |
|------|------|
| 世界名称 | 艾兰大陆 |
| 能量体系 | 魔素、元素规则 |
| 核心力量 | 神格、规则之力 |
| 地理位置 | 东部魔兽岭、西部人族国度、北部冰原、南部海族 |

### 势力分布

**人族**：
- 数个王国与帝国
- 魔法师公会
- 各大魔法学院

**主宰**：
- 无需神格，自身力量成就
- 实力超越至高神
- 包括：光明主宰、黑暗主宰、生命主宰、死亡主宰
- 其他主宰（火、水、冰、风、雷、土等）：已被污染，成为敌人
- **现状**：光明/生命靠规则之力勉强抵抗，其他主宰已被污染并成为敌人

**至高神**：
- 最初领悟元素规则，吸收神格成就
- 各自统治一片神域
- **现状**：大部分至高神已被暗中污染

**魔兽**：
- 居于东部魔兽岭
- 分为低阶、中阶、高阶、领主、王者级别
- **兽潮设定**：有黑暗主宰暗中操控

### 主宰之间的关系

**光明主宰·奥瑞尔 & 生命主宰·盖亚**：
- 相爱，违反"主宰不近情感"的"规则"
- 诞下向德豪（主宰之子）
- 千年前察觉黑暗主宰阴谋
- 为保护儿子，炼制玉佩送其往现代世界
- 千年来一直在抵御黑暗侵袭
- **现状**：轻度污染，靠规则之力勉强抵抗

**黑暗主宰·莫尔甘**：
- 万年布局，暗中污染整个神界
- 可控制心智，让感染者变成散发黑气的行尸走肉
- 最终感染者会爆炸，方圆十里无一幸免
- 目标：收割所有黑死气，成就位面之主（主宰之上的境界）

## 黑暗污染（优化版）

### 本质

黑暗主宰万年布局，通过黑死气污染所有生灵。被污染者：
- 初期：脑海中听到一丝丝声音，不知不觉影响心智
- 中期：心智被控制，变成散发黑气的行尸走肉
- 后期：爆炸传染，方圆十里无一幸免，成为新的感染源

### 传播方式

| 方式 | 说明 |
|------|------|
| 空间裂缝 | 偶然出现的空间裂缝是主要传播途径 |
| 神格传播 | 神格是黑暗的载体，融合神格即被污染 |
| 直接接触 | 黑暗主宰可直接污染其他主宰 |
| 间接传播 | 通过被污染者传播给亲近的人 |
| 环境侵蚀 | 黑暗浓郁的区域会缓慢侵蚀 |

### 下界规则保护

- 下界有位面规则保护
- 黑暗主宰无法直接降临
- 只能靠偶然的空间裂缝传播黑死气
- 因此侵蚀速度一直不快
- 但千年累积，已经渗透到整个神界

### 症状发展

| 阶段 | 症状 | 发作 |
|------|------|------|
| 初期 | 无明显征兆，偶尔听到脑海中的声音 | 无 |
| 中期 | 情绪偶尔失控，浑身散发淡淡黑气 | 短暂失神 |
| 后期 | 双目变暗，浑身黑死气缭绕 | 频繁失控 |
| 爆发期 | 变成行尸走肉，胡乱攻击，最终爆炸传染 | 完全堕落 |

### 为什么污染如此严重

- **万年布局**：黑暗主宰花了万年时间渗透
- **无处不在**：黑暗存在于位面的每个角落
- **无法察觉**：初期完全无法察觉
- **无法净化**：普通手段无法净化，只有向德豪的光明+生命之力可以
- **神格是载体**：融合神格的至高神几乎无法幸免

### 神界现状

- **四大主宰**：全部轻度污染（光明/生命靠规则之力勉强抵抗）
- **其他主宰**：火、水、冰、风、雷、土等主宰已被污染
- **至高神**：大部分已被暗中污染
- **神格**：大部分神格被黑暗渗透
- **危局**：整个神界处于崩溃边缘

## 玉佩（父母玉佩）

### 起源

- **光明主宰·奥瑞尔**与**生命主宰·盖亚**联手炼制
- 耗费大量主宰之力
- 封存海量主宰之力于其中
- 只为保护儿子向德豪
- **不是上古神器，是父母亲手炼制**

### 炼制过程

- 两人相爱，诞下向德豪
- 察觉黑暗主宰的阴谋
- 为保护孩子，炼制玉佩
- 融入光明与生命之力
- 注入父母的祝福和保护
- **封存海量主宰之力**，供向德豪成长后逐步解锁

### 功能

| 功能 | 说明 |
|------|------|
| **护主** | 致命攻击时自动护体 |
| **传送** | 生死关头传送到安全之地（异界） |
| **封印** | 封印向德豪的主宰之力，避免暴露 |
| **引导** | 在异界引导他觉醒血脉 |
| **认亲** | 觉醒时可引导至父母身边 |
| **力量传承** | 封存的海量主宰之力随境界提升逐步解锁 |

### 启动条件

- 向德豪生死攸关时自动启动
- 穿越之夜：三者能量碰撞，向德豪濒死，玉佩启动
- 吸收天地能量，空间扭曲，传送回异界
- **启动后玉佩消耗殆尽，消失**

### 后期

- 穿越后玉佩消失（已消耗）
- 封印逐渐松动
- 向德豪血脉慢慢觉醒
- 父母之力逐渐显现
- 玉佩中封存的主宰之力成为快速晋级的关键


### 父母等待时间线

| 时间点 | 异界 | 蓝星 | 事件 |
|--------|------|------|------|
| 千年前 | 父母送走刚出生的主角 | — | 炼制玉佩，传送往蓝星 |
| 穿越过程 | 时间偏移开始 | — | 异界开始流逝，蓝星无感 |
| 18年前 | 异界已过约982年 | 婴儿出现 | 向德豪出现在荒山，被师父捡到 |
| 18年间 | 异界继续流逝18年 | 主角长大 | 主角从婴儿长到18岁 |
| 穿越夜 | 父母仍在抵抗 | 主角18岁 | 师徒大战将臣，玉佩启动，传送回异界 |
| 异界2年后 | 父母被污染 | — | 主角成就位面之主，父母现身相认 |

**时间差总结**：
- 从父母送走到主角回归，异界过去了 1000+2 = 1002年
- 从主角出生到穿越，蓝星过去了 18年
- 时间偏移比例：异界约1000年 = 蓝星18年 |

## 复活机制（卡bug）

### 常规复活规则

- 至高神可以复活生命
- 但代价巨大：损失神力或生命等价交换
- 复活越强者，代价越大
- 这也是为什么复活术很少使用

### 向德豪的"卡bug"方式

- 用**炼尸大典炼制的高品质尸体**来抵消等价交换的代价
- 原理：炼尸大典炼制的尸体带有特殊印记/价值，可被位面规则认可为"交换物"
- 优势：不需要消耗自己的生命或神力，用炼尸来支付代价
- 这不是真正的"复活术"，而是利用炼尸术的漏洞

### 复活对象

1. **师父（向守一）**：异界6个月时为保护徒弟牺牲，用此方式复活
2. **小伙伴**（弗拉姆、格蕾丝、凯尔）：兽潮牺牲后，用此方式复活

### 复活过程

1. 用炼尸大典炼制高品质尸体（"材料"）
2. 用这些尸体抵消等价交换的代价
3. 用生命之力滋养目标尸体
4. 逐步唤醒意识
5. 最终完全复活
