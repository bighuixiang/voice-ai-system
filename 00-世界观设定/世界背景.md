# 世界背景

## 现代世界

### 基本信息
- **时代**：现代都市
- **特殊存在**：道术真实存在，僵尸代代相传
- **湘西赶尸派**：隐秘传承，代代等待僵尸王现世

### 湘西赶尸派

| 设定 | 内容 |
|------|------|
| 祖师 | 向氏先祖（异界逃难而来） |
| 传承 | 赶尸术、炼尸术、道术 |
| 信条 | 炼尸可炼己，炼己方可炼尸 |
| 禁忌 | 炼制活人、滥杀无辜 |
| 三大神器 | 炼尸大典、八卦道袍、护界玉佩 |

### 赶尸派三大神器

| 神器 | 来历 | 能力 |
|------|------|------|
| **炼尸大典** | 向氏先祖从异界带来 | 记载完整炼尸体系，能抵御黑暗侵蚀 |
| **八卦道袍** | 向氏先祖炼制 | 防护+净化，能抵御黑暗污染 |
| **护界玉佩** | 向德豪父母炼制 | 护主+传送，封印血脉 |

**炼尸大典的特殊能力**：
- 记载从行尸到尸神的完整炼制方法
- 自带净化之力，能抵御黑暗侵蚀
- 在异界发现：这本"书"其实是某种高科技/魔法结晶
- 能够净化被黑暗污染的尸体
- 向德豪靠它能在黑暗环境中保持清醒

**八卦道袍的特殊能力**：
- 祖传宝物，代代相传
- 布料中融入符文和净化之力
- 能够自动抵御黑暗污染
- 在黑暗环境中散发淡淡光芒
- 向德豪穿越时穿着，是他在异界初期不受黑暗影响的关键

### 裹尸袋

**基本设定**：
- 向氏祖传宝物，外观是普通的牛皮袋
- 实际上是由异界特殊材料制成
- 代代相传，用于赶尸时装尸体

**特殊能力**：
| 能力 | 说明 |
|------|------|
| **尸体不腐** | 袋中尸体永远不会腐烂 |
| **意识沉睡** | 死者的意识会进入特殊沉睡状态 |
| **时间静止** | 袋内时间几乎静止 |
| **空间隔绝** | 外界无法感知袋内情况 |
| **保留意识** | 炼制时可保留死者意识 |

**在故事中的作用**：
1. 师父穿越后死亡，将自己装进裹尸袋
2. 尸体保持完好，意识沉睡
3. 向德豪一直带着，但不敢打开
4. 成为向德豪变强的动力
5. 最终向德豪用炼尸大典"卡bug"复活师父

**向德豪与裹尸袋**：
- 每天带着裹尸袋前行
- 偶尔对着袋子说话
- 像是带着师父的灵魂
- 成为心理上的寄托
- 复活时终于打开

## 异界——艾兰大陆

### 基本信息

| 设定 | 内容 |
|------|------|
| 世界名称 | 艾兰大陆 |
| 能量体系 | 魔素、元素规则 |
| 核心力量 | 神格、规则之力 |
| 地理位置 | 东部魔兽岭、西部人族国度、北部冰原、南部海族 |

### 势力分布

**人族**
- 数个王国与帝国
- 魔法师公会
- 各大魔法学院

**至高神**
- 最初领悟元素规则，吸收神格成就
- 各自统治一片神域

**主宰**
- 无需神格，自身力量成就
- 实力超越至高神
- 包括：光明主宰、黑暗主宰、生命主宰、死亡主宰

### 主宰之间的关系

**光明主宰·奥瑞尔 & 生命主宰·盖亚**
- 相爱，违反"主宰不近情感"的"规则"
- 诞下向德豪（主宰之子）
- 为保护孩子，将其送往现代世界

**黑暗主宰·莫尔甘**
- 暗中污染所有主宰
- 想要吞噬一切，冲击位面之主
- 最终被向德豪击败

**魔兽**
- 居于东部魔兽岭
- 分为低阶、中阶、高阶、领主、王者级别
- **中期设定**：兽潮来袭时魔兽异常强大
- **至高神限制**：至高神不能插手下界事务，否则会引发位面排斥
- **兽潮强度**：足以摧毁人族国度，向德豪靠点尸成器稳住局面

### 魔素与规则

- **魔素**：天地能量，可被吸收修炼
- **元素规则**：火、水、风、土、光、暗、雷、空间、时间
- **神格**：至高神力量的核心，可被污染
- **位面之主**：超越主宰，位面最高统治者，一草一木皆可创造

## 黑暗污染

### 本质
- 黑暗主宰万年布局，暗中污染整个神界
- 所有主宰都已被轻度污染
- 被污染者提供养料助其突破
- 目标：吞噬一切，冲击位面之主

### 传播方式
| 方式 | 说明 |
|------|------|
| 神格传播 | 神格是黑暗的载体，融合神格即被污染 |
| 直接接触 | 黑暗主宰可直接污染其他主宰 |
| 间接传播 | 通过被污染者传播给亲近的人 |
| 环境侵蚀 | 黑暗浓郁的区域会缓慢侵蚀 |

### 症状
| 阶段 | 症状 | 发作 |
|------|------|------|
| 初期 | 无明显征兆 | 偶尔做噩梦 |
| 中期 | 情绪偶尔失控 | 短暂失神 |
| 后期 | 浑身黑死气，双目变暗 | 频繁失控 |
| 爆发 | 变成行尸走肉，胡乱攻击 | 完全堕落 |

### 为什么污染如此严重
- **万年布局**：黑暗主宰花了万年时间渗透
- **无处不在**：黑暗存在于位面的每个角落
- **无法察觉**：初期完全无法察觉
- **无法净化**：普通手段无法净化，只有向德豪的光明+生命之力可以

### 神界现状
- **四大主宰**：全部轻度污染
- **至高神**：大部分已被暗中污染
- **神格**：大部分神格被黑暗渗透
- **危局**：整个神界处于崩溃边缘

### 为什么至高神不插手下界
- **位面规则**：至高神插手下界会引发位面排斥
- **排斥后果**：可能导致位面崩溃
- **兽潮特殊**：这次兽潮有黑暗主宰暗中操控
- **人族绝望**：只能靠自己，向德豪挺身而出

## 护界玉佩

### 起源
- **光明主宰·奥瑞尔**与**生命主宰·盖亚**联手炼制
- 耗费大量主宰之力
- 只为保护儿子向德豪
- **不是上古神器，是父母亲手炼制**

### 炼制过程
- 两人相爱，诞下向德豪
- 察觉黑暗主宰的阴谋
- 为保护孩子，炼制护界玉佩
- 融入光明与生命之力
- 注入父母的祝福和保护

### 功能
| 功能 | 说明 |
|------|------|
| **护主** | 致命攻击时自动护体 |
| **传送** | 生死关头传送到安全之地（异界） |
| **封印** | 封印向德豪的主宰之力，避免暴露 |
| **引导** | 在异界引导他觉醒血脉 |
| **认亲** | 觉醒时可引导至父母身边 |

### 启动条件
- 向德豪生死攸关时自动启动
- 穿越之夜：三者能量碰撞，向德豪濒死，玉佩启动
- 吸收天地能量，空间扭曲，传送回异界
- **启动后玉佩消耗殆尽，消失**

### 后期
- 穿越后玉佩消失（已消耗）
- 封印逐渐松动
- 向德豪血脉慢慢觉醒
- 父母之力逐渐显现

## 向德豪身世之谜

### 表面身份
- 湘西赶尸派第37代传人
- 师父在荒山捡到的孤儿
- 从小学赶尸术，18岁穿越

### 真实身份
- **光明主宰·奥瑞尔**与**生命主宰·盖亚**之子
- 主宰血脉，天赋卓绝
- 被送往现代世界避难
- 玉佩是父母的保护

### 为何送走
- 黑暗主宰暗中布局
- 父母察觉阴谋
- 为保护儿子，将其送走
- 约定：玉佩会在最危险时启动，送回异界

### 血脉觉醒
| 阶段 | 状态 |
|------|------|
| 现代世界 | 封印期，表现为赶尸传人 |
| 穿越初期 | 封印松动，修炼速度快 |
| 师父牺牲后 | 濒死爆发，血脉觉醒 |
| 位面之战 | 完全觉醒，超越父母 |

### 特殊体质
- 尸气与魔素完美双修（血脉原因）
- 极强的恢复能力（生命之力）
- 净化黑暗污染（光明之力）
- 最终超越主宰，成就位面之主
