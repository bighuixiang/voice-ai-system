# 世界背景

## 现代世界

### 基本信息
- **时代**：现代都市
- **特殊存在**：道术真实存在，僵尸代代相传
- **湘西赶尸派**：隐秘传承，代代等待僵尸王现世

### 湘西赶尸派

| 设定 | 内容 |
|------|------|
| 祖师 | 向氏先祖 |
| 传承 | 赶尸术、炼尸术、道术 |
| 信条 | 炼尸可炼己，炼己方可炼尸 |
| 禁忌 | 炼制活人、滥杀无辜 |

## 异界——艾兰大陆

### 基本信息

| 设定 | 内容 |
|------|------|
| 世界名称 | 艾兰大陆 |
| 能量体系 | 魔素、元素规则 |
| 核心力量 | 神格、规则之力 |
| 地理位置 | 东部魔兽岭、西部人族国度、北部冰原、南部海族 |

### 势力分布

**人族**
- 数个王国与帝国
- 魔法师公会
- 各大魔法学院

**至高神**
- 最初领悟元素规则，吸收神格成就
- 各自统治一片神域

**主宰**
- 无需神格，自身力量成就
- 实力超越至高神
- 包括：光明主宰、黑暗主宰、生命主宰、死亡主宰

**魔兽**
- 居于东部魔兽岭
- 分为低阶、中阶、高阶、领主、王者级别

### 魔素与规则

- **魔素**：天地能量，可被吸收修炼
- **元素规则**：火、水、风、土、光、暗、雷、空间、时间
- **神格**：至高神力量的核心，可被污染
- **位面之主**：超越主宰，位面最高统治者，一草一木皆可创造

## 黑暗污染

### 本质
- 黑暗主宰暗中污染所有主宰
- 被污染者提供养料助其突破
- 目标：冲击位面之主

### 症状
- 初期：无明显征兆
- 中期：偶尔情绪失控
- 后期：浑身黑死气缠绕，双目变得黑暗深邃
- 爆发：变成行尸走肉，胡乱攻击

### 危害
- 几乎无法察觉
- 爆发时实力大增但理智尽失
- 被污染的至高神也会堕落
