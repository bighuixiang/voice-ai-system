## 阶段1：误会初现（第16-20章）

### 第16章：索菲亚的传言

**【场景：学院餐厅】**

```
索菲亚和朋友们吃饭。

朋友A："听说院长最近很关注一个新生？"
朋友B："是的，好像叫向德豪。"
朋友C："还听说院长经常去宿舍看他..."

索菲亚愣住了。
"院长...？"

朋友A："对啊，伊莎贝拉院长..."
"听说她对这个学生特别上心。"

索菲亚握紧了拳头。
"伊莎贝拉...院长...？"

朋友B："怎么了，索菲亚？"

索菲亚摇头："没什么。"

但她的心中...
"院长...她...也对向德豪...？"
```

### 第17章：伊莎贝拉的传闻

**【场景：教师办公室】**

```

老师A："听说索菲亚最近经常和向德豪在一起？"
老师B："是的，好像是假扮情侣..."
老师C："嘿嘿，假戏真做？"

伊莎贝拉正在批改作业。
听到这话，笔停顿了一下。

老师A："不过向德豪确实是个优秀的学生..."
"索菲亚看上他也正常。"

伊莎贝拉没有说话。
但她的心...
"索菲亚...她...？"

她合上作业本。
"先休息一下吧。"
```

### 第18章：图书馆偶遇

**【场景：图书馆】**

```

伊莎贝拉也在图书馆。
她拿着几本书，正准备离开。

两人的目光相遇。

索菲亚："...院长。"
伊莎贝拉："...索菲亚同学。"

两人都不知道该说什么。

最终，伊莎贝拉点点头："再见。"
索菲亚："...再见。"
```
