## 一、核心原则

艾兰大陆不是一张冒险地图，而是一套会把人推向选择的压力系统。

- **王国提供利益压力**：税、军权、贵族、补给、舆论。
- **学院提供成长压力**：试炼、评级、监护、样本化、派系竞争。
- **教廷提供信念压力**：什么才算光明，谁有资格定义救赎。
- **暗黑教提供潜伏压力**：它不只杀人，还会利用制度、恐惧和私欲。
- **魔兽岭提供生存压力**：长城外不是刷怪区，而是随时能压垮文明边界的活禁区。

写作禁忌：
- 不要把教廷写成纯坏组织。教廷必须有真善、真牺牲和真腐败并存。
- 不要把暗黑教徒都写成疯子。越高阶的暗黑教徒越理性、越像“秩序修正者”。
- 不要让反派只在后期突然喊口号。每一卷都要有一个可触摸的小反派，背后接一层更大的系统。
- 不要让魔兽岭只提供战斗素材。它必须影响物价、军役、学院任务、贵族政治和民间恐惧。

## 二、艾兰大陆五大人类势力

### 1. 圣辉王国

| 项目 | 设定 |
|------|------|
| 地位 | 人族西部核心王国，光明教廷影响最深 |
| 首都 | 圣辉王都 |
| 标志 | 白金王冠、日轮圣徽 |
| 主要矛盾 | 王权需要教廷背书，教廷需要王权执行 |
| 主线作用 | 学院、教廷、贵族、外廷线主要发生地 |

圣辉王国表面稳定，实则三权互相借力：
- 王室负责征税、军役和边境补给。
- 光明教廷负责合法性、民心和净化仪式。
- 学院联盟负责人才培养、魔法研究和前线技术。

向德豪的冲突点：
- 赶尸术被误判为亡灵术。
- 炼尸救人挑战教廷“死者安眠”教义。
- 主宰血脉一旦暴露，会被王权、教廷、学院同时争夺解释权。

### 2. 罗兰公国

| 项目 | 设定 |
|------|------|
| 地位 | 圣辉王国附庸公国，商业与情报发达 |
| 代表人物 | 索菲亚及其家族 |
| 标志 | 银玫瑰与黑账本 |
| 主要矛盾 | 商业自由与王国监管 |
| 主线作用 | 索菲亚情报线、资金线、舆论线来源 |

罗兰公国不以军力见长，靠商路、借贷、拍卖场和情报网络生存。它天然不信任“绝对正义”，因为任何口号最后都会落成税单、封库和追责。

索菲亚的世界观来源：
- 她知道善意如果没有账本支持，很快会变成空话。
- 她相信救人，但更相信先把资源算清楚。
- 她与向德豪的冲突，不是“爱不爱”，而是“你要全救，钱、证据和后果谁来补”。

### 3. 北境凛冬王国

| 项目 | 设定 |
|------|------|
| 地位 | 北部冰原人类边疆，长期抵御寒灾与魔兽迁徙 |
| 标志 | 蓝钢狼旗 |
| 主要矛盾 | 生存优先导致伦理冷硬 |
| 主线作用 | 冰皇、人兽旧约、战时分诊理念铺垫 |

北境人不擅长讲漂亮话。他们相信活下来就是第一律。北境军官可以救一城，也可以当场放弃一村。格蕾丝的“分诊”观念可以从北境战地医学中获得现实根基。

### 4. 赤炉自治领

| 项目 | 设定 |
|------|------|
| 地位 | 中部矮人山脉与人类工坊城组成的自治区域 |
| 标志 | 铁锤、炉火、山铜齿轮 |
| 主要矛盾 | 技术中立是否等于道德中立 |
| 主线作用 | 瑟莱恩技术线、三合一体系、魔法炮与长城军工 |

赤炉自治领负责长城大量军工维护。它既能帮助向德豪完成尸气、魔素、铭文融合，也可能因为“只看订单不问用途”被暗黑教利用。

### 5. 南湾诸城

| 项目 | 设定 |
|------|------|
| 地位 | 南部海港城邦联盟，贸易、走私、黑市发达 |
| 标志 | 潮汐银帆 |
| 主要矛盾 | 开放带来繁荣，也带来渗透 |
| 主线作用 | 黑市医站、走私补给、暗黑教跨境转运 |

南湾不是邪恶之地，而是规则缝隙最多的地方。向德豪孤狼期的黑市医站、暗黑教的非法材料、外廷的秘密转运，都可以从这里接入。

## 三、学院联盟

### 学院不是象牙塔

学院承担三类职责：
- 培养法师与前线人才。
- 为王国和长城提供技术储备。
- 监测高危天赋者，必要时将其纳入“可控样本”。

这让学院天然矛盾：
- 它保护学生，也使用学生。
- 它追求真理，也维护秩序。
- 它鼓励天才，也害怕不可控天才。

### 主要学院

| 学院 | 定位 | 风格 | 可用冲突 |
|------|------|------|----------|
| 星辰学院 | 主舞台，综合魔法学院 | 温暖与监护并存 | 伊莎贝拉、向德豪、A17观察 |
| 白银塔学院 | 贵族与法术规范派 | 高傲、重程序 | 大比对手、教廷关系密切 |
| 灰塔战院 | 军事学院 | 强硬、效率优先 | 前线听证、牺牲伦理 |
| 圣光神学院 | 教廷直属学院 | 治疗、净化、教义 | 光明教廷碰撞主入口 |
| 赤炉工坊院 | 矮人与工程师联合学院 | 技术至上 | 三合一体系、军工渗透 |
| 潮汐学院 | 南湾城邦学院 | 灵活、交易感强 | 黑市、情报、走私线 |

### 学院篇反派不够的补强方式

前期小反派不要只做“嘲讽男主”的贵族脸谱。应分成三层：

1. **情绪型小反派**
   例：贵族学生艾德里安。目标是面子、资源、索菲亚家族利益。
   作用：提供爽点和即时冲突。

2. **规则型小反派**
   例：白银塔监察生、圣光神学院候补祭司。目标是用规则证明向德豪“不洁”。
   作用：把冲突从打脸升级到合法压迫。

3. **系统型小反派**
   例：A17观察员、档案管理员、军需联络官。目标是记录、剪辑、定性、移交。
   作用：让读者意识到真正的敌人不是某个蠢人，而是一套会吞人的机制。

## 四、光明教廷

### 1. 教廷定位

光明教廷信奉“光明主宰奥瑞尔”，在民间承担净化、救济、葬仪、誓约见证和战时安抚职能。它是艾兰大陆最能给普通人安全感的组织之一。

这也是它危险的原因：
当一个组织长期代表“光明”，它很容易开始相信，只有自己定义的光才是光。

### 2. 核心教义

原初教义：
- 光明不是杀死黑暗，而是让生命看见边界。
- 死者应被尊重，生者应被守护。
- 净化不是惩罚，净化是归还。
- 守护不能剥夺被守护者的意志。

现行教义的偏移：
- “未经教廷认证的净化，皆为亵渎。”
- “亡者不可被驱役，哪怕为了救人。”
- “黑暗术法使用者必须接受隔离审查。”
- “光明血脉属于大陆，不属于个人。”

这组偏移能自然制造向德豪与教廷的碰撞：
- 他炼尸救人，教廷认为他役使亡者。
- 他用道术镇邪，教廷误判为异端亡灵术。
- 他能净化黑暗，教廷既需要他，又害怕他绕过教廷权威。

### 3. 教廷权力结构

| 职位 | 作用 | 写作功能 |
|------|------|----------|
| 教皇 | 教廷最高领袖，解释教义 | 后期价值审判，不宜过早脸谱化 |
| 枢机主教团 | 管理各地教区与神学院 | 政治压力和派系分裂 |
| 圣裁庭 | 处理异端、污染、禁术 | 与主角正面碰撞的执行层 |
| 慈光院 | 救济、医疗、葬仪 | 展现教廷善的一面 |
| 圣光神学院 | 培养祭司与治疗师 | 学院篇小反派和理念冲突入口 |
| 外廷联络处 | 与王权、军方、学院衔接 | 可被暗黑教渗透，连接A17线 |

### 4. 教皇设定

**教皇名号**：尤里安三世
**公开形象**：温和、克制、相信程序，民间威望极高。
**真实矛盾**：他不是坏人，但他太相信“秩序能控制灾难”。

教皇的核心信念：
- 他认为混乱比错误更可怕。
- 他宁可慢救一百人，也不愿让一个不可控神迹成为新主宰。
- 他反对向德豪，不是因为嫉妒，而是因为他看见向德豪可能成为第二个莫尔甘。

教皇与向德豪的价值冲突：
- 教皇问：“你能救人，但谁来限制你？”
- 向德豪答：“如果限制让我看着人死，我做不到。”
- 这不是正邪冲突，是两种守护方式的冲突。

后期转折：
- 教皇不能突然洗白，也不能突然黑化。
- 他应在第141-150章看到外廷与暗黑教合谋证据后，承认教廷被制度傲慢污染。
- 第177-180章参与战后严审，而非被简单处决。

## 五、暗黑教

### 1. 名称与本质

民间称呼：暗黑教。
组织自称：黑渊圣会。
上层代号：静夜司。

暗黑教并不公开宣称“毁灭世界”。它向不同阶层售卖不同承诺：
- 对贫民说：黑暗会让你不再被饥饿折磨。
- 对士兵说：黑暗会让牺牲变得有意义。
- 对贵族说：黑暗会让秩序永远稳定。
- 对法师说：黑暗会突破寿命和天赋上限。
- 对执政者说：黑暗能替你消灭不可控因素。

### 2. 组织结构

| 层级 | 称呼 | 特点 | 写作作用 |
|------|------|------|----------|
| 外围 | 夜祷者 | 普通信徒，很多人并不知道真相 | 前期小反派、民间恐惧 |
| 中层 | 执灯人 | 负责仪式、转运、暗杀、污染节点 | 中期执行反派 |
| 高层 | 静夜司祭 | 能接触主宰化工程，理性且冷静 | 后期价值反派 |
| 顶层 | 黑渊圣子/圣女 | 被塑造成莫尔甘意志代言人 | 位面战争前的半终局反派 |
| 根源 | 莫尔甘污染意志 | 不直接登场，通过声音、梦、黑死气影响 | 最终镜像压力 |

### 3. 暗黑教徒的三类人格

1. **被救赎诱骗者**
   因病、贫穷、战伤、丧亲加入。写他们时要有悲悯，不要只写疯狂。

2. **功利合作者**
   贵族、军需官、商人、学院技术员。他们不一定信黑暗，只是利用黑暗达成目的。

3. **理念型敌人**
   真正相信“绝对控制才能杜绝痛苦”。这类人最适合作为中后期反派，与向德豪形成镜像。

### 4. 暗黑教与教廷的关系

暗黑教最危险的地方，不是藏在黑暗里，而是藏在光明的流程里。

渗透方式：
- 假借教廷净化名单，标记“可处置样本”。
- 利用圣裁庭隔离制度，把目标送入私密转运链。
- 在慈光院中接触濒死者，用“无痛安眠”诱导入教。
- 通过外廷联络处篡改学院档案、军需清单和前线通行印。

写作效果：
- 前期读者以为是教廷保守。
- 中期发现教廷内部有人被利用。
- 后期才确认暗黑教把“光明程序”改造成了黑暗管道。

## 六、绝境长城与魔兽岭压迫感补强

### 1. 长城外不是荒野，是活着的压力

魔兽岭有三圈：

| 区域 | 名称 | 压迫方式 |
|------|------|----------|
| 外环 | 骨草带 | 低阶魔兽密集，夜间地面会响，适合新手但死亡率高 |
| 中环 | 雾牙林 | 方向感失效，魔兽会诱导人走向阵眼和旧碑 |
| 深环 | 四皇领域 | 皇级以上魔兽拥有领地秩序，不主动等同野怪 |

魔兽岭日常异象：
- 夜里长城砖缝会渗出兽血味，第二天却找不到血源。
- 远处兽吼不是一声，而像军鼓一样分层推进。
- 魔兽有时不攻击人，反而啃咬阵眼、魔晶节点、旧石碑。
- 兽潮前，城内家畜会集体朝东跪伏。
- 老兵不怕魔兽吼，怕魔兽岭突然安静。

### 2. 长城压力要进入生活

长城不是一条墙，而是一种税。

- 每户人家都有长城税。
- 每个学院高年级都有前线实习指标。
- 每个王国都要按比例提供魔晶、炮手和治疗师。
- 每次兽潮都会抬高药水、卷轴、粮食价格。
- 贵族可以用钱抵役，平民子弟常被送上城墙。

这会制造大量小冲突：
- 学生为什么怕前线任务。
- 贵族为什么能逃避长城服役。
- 索菲亚为什么重视账本和补给。
- 教廷为什么能用“长城救济”扩大民间影响。
- 暗黑教为什么能在伤兵和遗属中传教。

### 3. 魔兽不是天然反派

前期人类视角：魔兽是灾害。
中期证据视角：魔兽被黑暗驱赶和污染。
后期历史视角：魔兽岭曾经是位面平衡的一部分。
终局共生视角：魔兽不是被征服对象，而是共同体成员。

这一层递进必须慢慢写，不能第20章就讲完。

## 九、每卷执行钩子

### 卷2：学院是试验场
- 加入圣光神学院候补祭司作为规则型小反派。
- 他不必很强，但能用“教义”和“校规”让主角难受。
- 暗黑教只露出误导性痕迹：黑蜡、夜祷片语、重复编号。

### 卷3：北线与师父
- 师父被误认成黑暗术士的压力要来自教廷、军方和普通士兵三方。
- 不能只让敌人追杀他，要让被他救过的人也害怕他。

### 卷4：牺牲与人为证据
- 每次牺牲都留下一个“人类系统参与过”的证据。
- 读者的愤怒要从“黑暗好坏”转向“谁把他们送进这个局”。

### 卷5：孤狼追机制
- 暗黑教高层不急着杀主角，而是想活捉、记录、复刻。
- 小反派从战斗型升级为执行型：门卫、转运人、审讯员、医站老板。

### 卷6：教皇与历史层
- 教皇必须成为有重量的价值对手。
- 他指出主角风险时，读者应觉得“他说得有道理，但太冷”。

### 卷7：教廷分裂
- 一部分教廷人员战死前线，证明教廷不等于反派。
- 一部分教廷保守派仍试图夺回解释权，证明善组织也会有权力惯性。

### 卷8：教义更新
- 战后教廷不崩塌，而是改革。
- 新教义承认：亡者归来不是亵渎，前提是尊重意志、等价代价、公开审查。
- 向德豪不接管教廷，只推动它把“光明”还给普通人。

## 十、写作判断句

写到王国、学院、教廷、暗黑教、长城时，先问五个问题：

1. 这场冲突是否让向德豪付出了制度代价？
2. 这个反派是否有自己的利益或信念，而不是只会找死？
3. 教廷是否同时展现了善意和权力惯性？
4. 暗黑教是否利用了人的恐惧、亏欠或秩序欲？
5. 魔兽岭是否影响了城市生活，而不是只在战斗时出现？

如果五个问题都没有答案，这段世界观就是装饰，应删或重写。
