## 一、经典台词库

### 1. 吐槽类台词

| 台词 | 使用场景 | 示例 |
|------|----------|------|
| "弱！太弱了！" | 战斗点评 | 向德豪击杀初阶魔兽<br>将臣："弱！太弱了！本大爷闭着眼都能捏死一百只！" |
| "啧" | 万能吐槽词 | 向德豪做任何事<br>将臣："啧" |
| "装逼" | 主角装逼时 | 向德豪："我用了三成力"<br>将臣："装逼" |
| "本大爷" | 自称 | 任何自我介绍<br>将臣："本大爷是尸王将臣！" |
| "小鬼/小子" | 称呼主角 | 向德豪做任何事<br>将臣："小子，你行不行啊？" |
| "让开，让本大爷来！" | 战斗时抢怪 | 向德豪被围攻<br>将臣："让开！让本大爷来！" |

### 2. 嘲讽类台词

| 台词 | 使用场景 | 示例 |
|------|----------|------|
| "啧，还需要女人保护..." | 主角被救时 | 伊莎贝拉救下向德豪<br>将臣（小声）："啧，还需要女人保护..." |
| "这点实力也敢来送死？" | 遇到弱敌 | 路人甲向德豪挑战<br>将臣："这点实力也敢来送死？" |
| "啧，这群人真大惊小怪" | 主角展现实力后 | 向德豪一剑制敌<br>将臣："啧，这群人真大惊小怪" |
| "你念得比我爬还慢" | 艾伦念咒语 | 艾伦念错咒语<br>将臣："你念得比我爬还慢" |

### 3. 傲娇类台词

| 台词 | 使用场景 | 示例 |
|------|----------|------|
| "不过...看在你还是个凡人的份上，勉强算你合格吧" | 主角成长时 | 向德豪突破境界<br>将臣："不过...看在你还是个凡人的份上，勉强算你合格吧" |
| "本大爷就帮你这一次" | 帮助主角 | 向德豪遇到困难<br>将臣："啧...本大爷就帮你这一次" |
| "啧，这事还得本大爷来" | 主动帮忙 | 向德豪搞不定<br>将臣："啧，这事还得本大爷来" |

### 4. 严肃类台词（仅恐怖/牺牲章）

| 台词 | 使用场景 | 示例 |
|------|----------|------|
| "小子...小心..." | 危险警告 | 第111章黑暗主宰现身<br>将臣："小子...小心..." |
| "坚持住..." | 鼓励主角 | 主角濒死时<br>将臣："坚持住..." |
| "别听他的..." | 反对诱惑 | 黑暗主宰诱惑主角<br>将臣："别听他的..." |

## 二、场景台词示例

### 场景1：主角装逼

```
向德豪："我用了三成力。"

将臣："装逼。"

向德豪："你闭嘴。"

将臣："啧，本大爷就说实话而已。"
```

---

### 场景2：主角被救

```
伊莎贝拉救下向德豪。
向德豪脸红。

将臣（小声）："啧，还需要女人保护..."
"丢人。"

向德豪："你闭嘴！"

将臣："啧，本大爷又没说错。"
```

---

### 场景3：主角真正成长

```
向德豪突破到神体境。
整个房间金光璀璨。

将臣没有说话。
只是默默点头。

然后它转过身。
嘴角微微上扬。

将臣："...还不赖。"
```

---

### 场景4：孤狼期（完全沉默）

```
第96章：向德豪跪在师父坟前。
将臣蹲在旁边。
没有说话。

第100章：向德豪眼神彻底冷了。
将臣蹲在他肩膀上。
全程沉默。

第110章：向德豪成为孤狼。
将臣依然在。
只是不再说话。
```

---

### 场景5：第111章后-战斗时

```
向德豪一剑斩杀敌人。

将臣："弱！太弱了！"
"本大爷都没看清！"

向德豪："你话太多了。"

将臣："啧，让本大爷来！"
"让开！"

向德豪："一起上。"

将臣："嘿，这还差不多。"
```

---

### 场景6：第111章后-休息时

```
向德豪坐在火堆旁。
伊莎贝拉在他旁边。

将臣蹲在远处的树枝上。
没有说话。
只是默默看着。

偶尔点头或摇头。
```

---

### 场景7：第111章后-感情章

```
向德豪和伊莎贝拉拥抱。
将臣转身，背对他们。
它知道...这时候不该说话。

向德豪："将臣...？"

将臣没有回头。
只是...挥了挥手。

意思：你们继续，本大爷巡逻去了。
```

## 三、台词进化规则

### 第一阶段：主仆关系（第3-20章）

**特点**：嘲讽、抱怨、被迫

| 台词类型 | 示例 |
|----------|------|
| 嘲讽 | "弱！太弱了！" "啧，两千年了，人类怎么越来越弱了？" |
| 抱怨 | "啧，麻烦" "本大爷才不要..." |
| 被迫 | "小鬼你懂个屁！" "本大爷...好吧，听你的" |

---

### 第二阶段：伙伴关系（第21-50章）

**特点**：嘴硬心软、主动配合

| 台词类型 | 示例 |
|----------|------|
| 嘴硬 | "啧，这事还得本大爷来..." "本大爷就帮你这一次" |
| 心软 | "啧...还不赖" "勉强算你合格吧" |
| 配合 | "让开，让本大爷来！" "本大爷来开路" |

---

### 第三阶段：损友关系（第51-70章）

**特点**：吐槽、调侃、关心

| 台词类型 | 示例 |
|----------|------|
| 吐槽 | "装逼" "你念得比我爬还慢" |
| 调侃 | "啧，女院长看你的眼神有点不对" "小鬼动心了" |
| 关心 | "小子，别死了啊..." "小心点..." |

---

### 第四阶段：小伙伴牺牲-沉默（第71-95章）

**特点**：完全沉默、用动作代替语言

| 表达方式 | 示例 |
|----------|------|
| 点头 | 认可主角的成长 |
| 摇头 | 不同意主角的做法 |
| 拍肩 | 安慰主角 |
| 蹲在肩膀 | 默默守护 |

---

### 第五阶段：孤狼期-完全沉默（第96-110章）

**特点**：向德豪完全孤狼状态，将臣全程沉默，只战斗不说话

| 表达方式 | 示例 |
|----------|------|
| 默默蹲在肩膀 | 陪伴主角 |
| 战斗配合 | 不说话，直接行动 |
| 眼神交流 | 与主角的眼神默契 |

---

### 第六阶段：生死之交（第111章后）

**特点**：话少了、更真心、选择性幽默

| 台词类型 | 示例 |
|----------|------|
| 真心 | "小子...坚持住..." "本大爷...不会让你死的..." |
| 选择性幽默 | 战斗时："弱！太弱了！" 休息时：沉默 |
| 成长 | "走吧，让黑暗主宰见识一下..." |

---

### 第七阶段：一体双魂（位面之战后）

**特点**：完全接纳、共同承担

| 台词类型 | 示例 |
|----------|------|
| 接纳 | "能遇到你...是本大爷的运气" |
| 共同承担 | "一起上吧，小子" "本大爷陪你" |
| 最终承认 | "本大爷...认你为主...不亏" |

## 四、台词禁忌

### 禁止使用的台词

| 禁止台词 | 原因 | 替代方案 |
|----------|------|----------|
| "德豪啊..." | 太正式，不符合将臣人设 | "小子/小鬼" |
| "主公/大人" | 太卑微，将臣是傲娇不是仆人 | "小子/小鬼" |
| 长篇大论的说教 | 将臣是话痨但不是说教 | 吐槽式简短点评 |
| 过于煽情的话 | 不符合将臣性格 | 动作代替语言 |
| 网络用语 | 破坏世界观完整性 | 自创吐槽词 |

### 允许的特殊情况

| 情况 | 允许台词 | 说明 |
|------|----------|------|
| 孤狼期 | 完全沉默 | 第81-110章全程不说话 |
| 第111章后-休息时 | 沉默 | 用眼神或动作交流 |
| 第111章后-感情章 | 沉默 | 远处观察，不打扰 |
| 恐怖/牺牲章 | 严肃台词 | "小心..." "坚持住..." |

## 六、执行检查表

### 写作前的检查

- [ ] 当前章节类型是什么？（轻松/战斗/感情/恐怖/孤狼）
- [ ] 将臣应该说话吗？（根据对照表判断）
- [ ] 如果说话，台词风格是什么？（吐槽/调侃/严肃）
- [ ] 如果不说话，用动作代替什么语言？

### 写作中的检查

- [ ] 将臣的台词是否符合当前阶段？
- [ ] 台词长度是否合适？（将臣喜欢短句）
- [ ] 是否有网络用语？（检查并删除）
- [ ] 是否符合将臣的傲娇人设？（嘴硬心软）

### 写作后的检查

- [ ] 将臣的台词是否让角色更鲜活？
- [ ] 是否符合台词规则表？
- [ ] 是否有违和感？
- [ ] 孤狼期将臣是否全程沉默？
