## 前期：第51-60章（怀疑与压制）

### 第51章：师徒重逢·第一眼的不对劲

**【场景：师徒重逢时刻】**

```
向德豪看到了师父。
师父也看到了他。

"师父——"向德豪冲过去。

师父笑了："德豪，你...你长大了。"

两人紧紧拥抱。

但...向德豪感觉到了什么。
师父的背部...有些僵硬。
师父的呼吸...有些急促。

向德豪："师父，你...？"

师父松开手，摇头："没事...只是...太激动了。"

向德豪看着师父的眼睛。
师父的眼中闪过一丝...黑气？

不...可能是错觉吧。

将臣在旁边："...老头，你身上的气息，有点不对劲。"

师父脸色一变。

将臣："啧，那是...黑暗的力量。"

师父沉默了。

向德豪："师父？"

师父："...没事，将臣多虑了。"
```

**【章末留白】**
向德豪回到房间，心中不安。
师父的背影...好像比以前佝偻了。

**【场景：向德豪深夜路过师父房间】**

```
向德豪经过师父房间。
里面传来...压抑的声音。

"呃...啊......"

师父的声音。
听起来很痛苦。

向德豪想推门进去。
但手停在了半空。

"师父...可能有事要处理..."

第二天。
向德豪问："师父，昨晚我听到..."

师父脸色平静："什么都没有。"
"可能是风声吧。"

向德豪想追问。
但看到师父的眼神...不想说的意思。

将臣在旁边，没有说话。
只是...眼神复杂地看着师父。
```

## 中期：第61-70章（隐瞒与寻找）

### 第62章：师父的独自调查

**【场景：师父独自前往图书馆】**

```
深夜。
师父独自来到学院的图书馆。

他在寻找...关于黑暗污染的资料。

"黑死气...黑死气..."
"传播方式...症状..."

师父的手颤抖着翻阅书籍。
他越看，脸色越苍白。

"原来...这就是..."
"原来我在穿越时..."

师父合上书。
他知道了真相。
自己被黑暗污染了。

"怎么办..."
"不能告诉德豪..."
"不能让他担心..."

师父默默离开图书馆。
但他的背影...更加佝偻了。
```

**【场景：师父在修炼时】**

```

他想站起来。
但黑气太重了。

"不能...不能倒下..."
"德豪还在..."

师父咬紧牙关，用尽全部力量压制黑气。

一刻钟。
半小时。
一小时。

终于...黑气被压了回去。

师父浑身是汗。
脸色苍白。

门被敲响："师父？"

师父立刻坐起来："没事，我很好。"
"刚才在...练功。"

向德豪："师父，您真的没事吗？"

师父笑了："师父能有什么事。"
"别担心。"

向德豪离开。

师父倒在地上，大口喘气。
"快了...快了..."
"必须...尽快解决..."
```

## 执行要点

### 1. 师父的三种隐瞒方式

| 方式 | 章节 | 效果 |
|------|------|------|
| **回避话题** | 51-60章 | 向德豪注意到，但被搪塞 |
| **撒谎隐瞒** | 61-70章 | 师父编造理由，独自承担 |
| **主动坦白** | 71-73章 | 无法隐瞒，说出真相 |

### 2. 黑气的三种表现方式

| 阶段 | 表现 | 频率 | 可压制性 |
|------|------|------|----------|
| 前期 | 偶尔闪现，一闪而逝 | 每隔5-8章 | 可压制 |
| 中期 | 明显黑气，发作时痛苦 | 每隔3-5章 | 勉强压制 |
| 后期 | 黑气缭绕，无法压制 | 每章都有 | 无法压制 |

### 3. 向德豪的三种反应

| 阶段 | 反应 | 情绪 |
|------|------|------|
| 前期 | 注意到，但被师父搪塞 | 不安，怀疑 |
| 中期 | 想追问，但师父回避 | 担忧，无奈 |
| 后期 | 发现真相，想救师父 | 悲痛，愤怒 |

## 写作技巧

### 展示而非讲述

**【错误示范】**
```
师父被黑气感染了，但他不想告诉向德豪。
```

**【正确示范】**
```
向德豪："师父，您最近...？"

师父立刻转身："没事。"

太快了。
就像...早就准备好了一样。

向德豪看到了。
师父的手，在微微发抖。

"师父，您在隐瞒什么..."

师父沉默了。

然后他笑了："你想多了。"
"师父真的很好。"

但他的笑容...有些勉强。
```
