### 3. 黑暗污染抗性的平衡

**问题**：
- 炼尸大典、八卦道袍、玉佩、主宰血脉...都能抗黑暗
- 主角抗性太多，威胁性是否降低？

**建议平衡方案**：
```
明确各道具的作用范围：

炼尸大典：
- 只能净化"被污染的尸体"
- 对活人的污染效果有限
- 主要用于炼尸，不是主角护身符

八卦道袍：
- 只能"延缓"污染，不能免疫
- 长期暴露在黑暗中仍会被污染
- 道袍本身也会被逐渐侵蚀

玉佩（在体内）：
- 封印血脉，避免主角被黑暗发现
- 不是主动防护，是被动隐藏
- 觉醒后反而会吸引黑暗主宰的注意

主宰血脉：
- 前期：被封印，没有抗性
- 中期：觉醒后反而成为目标
- 后期：完全觉醒才能净化

结论：
主角前期没有特殊抗性！
- 靠的是炼尸大典的净化能力（针对尸体）
- 靠的是低调不暴露（玉佩封印）
- 主角自身并没有免疫黑暗的能力
```

**需要修改的文件**：
- `01-角色设定/主角/向德豪.md` - 抵御黑暗侵蚀部分

### 4. 父母"无法分身"的逻辑

**问题**：
- 父母是主宰，能跨越空间、感知位面
- 为什么不能去找主角或确保他安全？

**建议补充解释**：
```
原因1：黑暗主宰的监视
- 父母一旦离开神域，黑暗主宰就会察觉
- 如果黑暗主宰发现主角，会直接灭杀
- 父母不敢暴露主角的位置

原因2：玉佩是单程保护
- 玉佩是父母用生命之力炼制的
- 一次性传送，用完即融入主角体内
- 父母无法通过玉佩追踪主角（会留下痕迹）

原因3：位面规则限制
- 父母虽然在异界，但不能随意降临下界
- 下界有位面规则保护，主宰也不能随意突破
- 只能在关键时刻（主角觉醒时）现身

原因4：时间偏移的复杂性
- 穿越涉及时间乱流
- 父母无法精确知道主角何时何地出现
- 玉佩的启动是自动的，父母无法控制
```

**需要补充的文件**：
- `00-世界观设定/世界背景.md` - 父母等待时间线部分

### 7. 主角快速晋级的合理性

**问题**：
- 18岁穿越，1年多就达到位面之主
- 是否太快？读者是否会觉得不合理？

**建议完善说明**：
```
原因1：玉佩中封存的力量不是"白送"
- 这些力量是父母精心准备的
- 每一层解锁都需要主角自己的修炼
- 玉佩只是"催化剂"，不是"外挂"

原因2：双道同修的特殊性
- 尸气与魔素融合，产生1+1>2的效果
- 这是这个世界从未见过的修炼方式
- 所以成长速度超越常人

原因3：炼尸大典的异界强化
- 炼尸大典在异界得到魔素强化
- 炼尸效率提升，间接提升主角实力
- 但需要主角自己去炼制、去战斗

原因4：生死危机的压力
- 兽潮、黑暗侵蚀、小伙伴牺牲
- 每一次危机都是突破的契机
- 压力推动成长

时间线合理化：
- 异界1周：适应期，银尸+学徒
- 异界1月：学院学习，金尸+法师
- 异界3月：兽潮危机，尸王+大法师
- 异界6月：黑暗侵蚀，尸皇+魔导师
- 异界1年：闭关炼制，尸帝+大魔导师
- 异界1年半：融合、觉醒、位面战
→ 总共1年半，但每次突破都是生死之间
→ 不是安逸修炼，而是拼命成长
```

**无需修改**：设定已经相对合理，只需在正文中强化"生死之间突破"的描写

### 8. 师父牺牲的必要性

**问题**：
- 师父好不容易找到，为什么很快就要牺牲？
- 是否为了牺牲而牺牲？

**建议完善动机**：
```
师父牺牲的必要性：
1. 向德豪的保护机制需要打破
   - 之前有师父保护，向德豪依赖性很强
   - 师父牺牲，向德豪被迫独立成长
   - 这是角色成长的必要转折

2. 复活机制的核心动力
   - 向德豪最初的目标：找到师父
   - 找到后的目标：保护师父
   - 师父牺牲后的目标：复活师父
   - 这是一个完整的情感弧光

3. 血脉觉醒的契机
   - 师父牺牲，向德豪濒死爆发
   - 玉佩彻底激活，父母之力觉醒
   - 这是身世揭晓的必要铺垫

4. 师父自己的选择
   - 师父知道向德豪身世不凡
   - 知道自己只是"养父"
   - 牺牲保护徒弟，是他最后的守护
   - 也让他最终被复活时更加感人

关键：师父的牺牲不能"白死"
- 必须推动剧情发展
- 必须促成主角成长
- 最终必须被复活
```

**无需修改**：设定合理，只需在正文中写好师父牺牲的动机和意义
